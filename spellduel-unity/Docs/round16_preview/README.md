# 第十六輪預覽

本目錄全部為離線預覽，非 Unity／AR 截圖。3D 使用實際 C# 程序網格與材質色；頭像／插圖為實際程序像素；首頁以原 DrawHome、LobbyModeArt 與 UiKit 的 GUI 呼叫重建。

- [炎之里](town_0.png)、[森之里](town_1.png)、[潮騷港](town_2.png)、[赤砂城](town_3.png)、[風沙驛](town_4.png)：各四設施，左正面、右 3/4。
- [五位 NPC](npcs.png)：頭像、3D 正面、3D 3/4；塔守依需求只有 2D。
- [炎之里俯視](plaza_top.png)：金圈是固定碰撞半徑，青點是新 NPC，橘點是玩家起點；青線標出中央入村方向。圖中右方為 +X，下方為 +Z。
- [無盡塔](tower.png)、[練習](practice.png)、[設定](settings.png)：程序插圖放大。
- [首頁五卡片](home.png)：1080×2340 GUI 呼叫重建；背景是離線示意底圖，非相機畫面。
- [量測數據](metrics.json)：三角形、Renderer、逐頂點半徑、腳底、設施間距。

文件與數據不取代原生 Unity、手機效能與所有動畫過程的穿模驗收。

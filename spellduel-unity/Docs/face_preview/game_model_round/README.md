# 遊戲 3D 模型對照後的鼻嘴修正

以 Belle、Anby、Nicole、Ellen 的第三方遊戲移植 glTF 作外形參考；來源、轉換限制與觀察記錄在 [需求文件](../../../FACE_3D_BRIEF.md#遊戲-3d-模型對照追加codex-分析)。外部網格與貼圖留在開發暫存，未加入遊戲資源。

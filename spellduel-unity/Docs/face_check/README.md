## 影片髮型與眉睫追加修正

[七位角色與影片實際影格比較](movie_hair_comparison.png)。時間點與各人調整項目見 `FACE_OVAL_BRIEF.md` 最新補充。翠以森林章影片的半開綠眼為準。頭髮使用獨立快取的可見版本，舊版本僅作頭身定位參考；保留圓頂、細束尖端，改為各人的分線、內收側髮、短側鬢、短雙尾與長髮層次。眉毛依角色髮色採灰紫、紅棕、深藍、灰綠、灰藍與白眉；上睫毛改成平順筆畫與短眼尾。

本批尚未推送；本機兩種平台符號條件編譯通過，完整 Unity 手機建置待推送後執行。所有圖都是程序網格軟體投影，非實機截圖。

## 最新：臉部橫向收窄

[影片與收窄前後對照](slim_face_comparison.png)。可見臉殼寬度為上一版 90%，頭高、頭部定位不變。眼睛大小與嘴寬保留，眼睛中心及耳根隨新臉寬校正。最新名義寬高比約 .65～.67，取代先前約 .72～.75 的舊版量測；各角色實測見 checks.json。3D、居民與頭像使用相同規則。

表中的比例以可見髮際到下巴計算；文中名義比例使用固定校準高度，兩者定義不同。表格與 checks.json 均以最新收窄版本為準。

## 最新：艾琳與海斗的帽型／髮寬專修

[影片、前版與本次並排](erin_haido_fit.png)；[投影寬度比例](erin_haido_fit.json)。艾琳髮／臉從 1.96 收至 1.57、帽／臉從 2.59 收至 2.08，兜帽改為尖頂與陡斜前緣。海斗髮／臉從 1.62 收至 1.49、帽／臉從 1.60 收至 1.50，改低帽冠、短帽簷、短外翹髮束，臉寬另收 4% 並收束下顎。其餘角色不變。

2D 頭像已依實際髮束深度遮擋帽後片，不再沿固定高度切掉髮頂。這兩人的投影畫框略放大以容納完整尖頂，對照圖的前後版本使用同一相機。尚未推送。

## 共用與效能

- 程序網格以變種 id／配件名稱快取。同種類的多個實例共用網格；部位顏色、閃光與死亡暗化保留原有登記系統。
- 僅改渲染子物件的輪廓／大小，原始支點的名稱、父子關係與姿勢不改。專屬配件取代重複的通用章節裝飾；通用裝飾原支點保留但停用顯示。
- 原本高面數的 Unity 發光球只在這十隻替換為共用低面數圓球。一般怪及前一批 19–22 不受影響。
- 三條世界座標風帶，各 12 點、最多共 66 三角形。不依移動距離無限制新增頂點。色彩依章節／變種調整，沒有匯入圖片。
- 由兩幀位置差決定是否移動；停止後消退，死亡時即使屍體被移動也不再出現風帶。瞬移超過 3m 重置歷史，停用物件後重用也重置。
- 影犬使用既有 Toon 的 _ArtFade 抖色透明，仍保有明暗與描邊，沒有新增 shader／材質實例。

## 原生驗證與預覽

原生入口：`SpellDuel.EditorTools.Snapshot.RenderSwiftMonsters`。
每隻有舊版、正面、側面、斜後方、奔跑拖尾與攻擊六張；另有五章各兩隻與原怪、玩家的等比例比較，共 65 張原生 PNG。`swift_*_overview.jpg` 是原生圖排版，沒有重新繪製角色。

`swift_audit.json` 的 totalTriangles 計入本體、配件、最大粒子數（每粒 2 三角形）、三條風帶及獨立陰影；上限 2500。原生稽核也檢查網格共用、原關節欄位／路徑／局部變換、受擊／蓄力／死亡變色，及移動、停止、死亡三種拖尾狀態。

驗收命令：`python3 spellduel-unity/Tools/check_swift_monsters.py --require-mobile`。
原生、Android、iOS 的最終執行證據完成後補入本目錄。尚未量測手機實機 AR 幀率。

## 追加：四足獸分段腿型

依本輪回饋，kind 8 荊棘衝鋒獸與其翠豹／影犬變種共用新的前肢、後肢網格：前肢有上臂、肘、前臂和腳掌；後肢有較厚的大腿、向前的膝部、收細小腿、向後的跗部與腳掌。兩者不再是上下等粗的直柱。

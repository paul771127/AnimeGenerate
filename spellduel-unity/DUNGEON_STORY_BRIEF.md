# 副本小劇情 Brief（給 Codex）

## 你要做的事

改寫並新增副本劇本。只動這一個檔案：

`spellduel-unity/Assets/SpellDuel/Resources/dungeons.txt`

**不用改任何程式。** 格式、規則和數值表都在 `spellduel-unity/DUNGEON_FORMAT.md`，請先讀完。特別是 1-2「固定地圖」和 1-3「劇情人物」兩節。

完整的範例是檔案裡第一個副本 `ash_mine`（灰燼礦坑）。它有分岔、寶箱、保護目標、抉擇和任務，請照它的寫法來寫。

## 任務一：把 3 個舊副本改成「地圖＋劇情人物」

這 3 個副本現在還是線性的 `[room]`：

- `rot_temple`（腐根神殿）
- `sunken_throne`（沉沒王座）
- `dawn_gate`（黎明之門）

請把它們改寫成 `[node]` 地圖。要求如下：

- **保留副本的 id、名稱、level、players。** id 會寫進玩家的存檔，不能改。
- **保留原本的劇情方向和主線伏筆**，可以擴寫：
  - 腐根神殿：種子在哭、根會找到水、樹王。
  - 沉沒王座：退潮的城門、白帆號的船徽、三座鐘的壁畫、深海巨妖。
  - 黎明之門：三位守門首領、艾琳在門外敲鐘。
- **地點**：
  - 每個副本 5～7 個地點，至少 1 個分岔，1 個寶箱（`event = chest`）。
  - 最短路線打 3～4 場戰鬥。
  - 終點是首領。
  - `wave` 照 DUNGEON_FORMAT.md 第 2 節的表選。原本跨主題的設計請保留（沉沒王座的熔岩庫房 `theme = volcano`）。
- **黎明之門**：三位首領要依序出現。
  - 前兩位首領是中途的地點（`wave = 40`、`50`，寫 `next`）。
  - 最後一位（`wave = 60`）是終點。
  - 分岔可以放在首領之間。
- **劇情人物**：每個副本 2～3 位。
  - 至少 1 位保護目標（escort）**或**抉擇人物（choice），以及 1 位任務人物（quest）。
  - 3 個副本加起來，escort、choice、quest 三種都要出現至少 2 次。
  - 人物請放在某條岔路上（只有走那條路才會遇到），讓房主選路線時有取捨。
  - 抉擇人物的 3 個結果（ally／enemy／third）都要有台詞，而且結果要合理，例如被懷疑的人會生氣反擊。
  - 任務的 `goal` 三種（kill／collect／reach）都要用到。

## 任務二：新增 2 個副本

加在檔案最後面：

- 一個 **Lv38**（角鬥場主題，wave 31～40）。
- 一個 **Lv50**（黃土山道主題，wave 41～50）。
- 規格同任務一：地圖、寶箱、2～3 位劇情人物。
- 劇情要和主線呼應：晨鐘、鐘舌、黑晶、白帆號、「讓黎明停止的人」。不能和 `Resources/story.txt` 的主線矛盾。角鬥場和山道的城鎮居民可以在 `story.txt` 裡找到。

## 寫作要求

- **每句 60 字以內**，手機直式的字幕卡放不下長句。長的請拆成兩句。
- 戰鬥中玩家沒空讀長文：`<enter>` 寫 1～3 句，`<clear>`、`<boss_half>`、`<meet>` 各寫 1～3 句。
- 不要假設主角的性別或職業，用 `{玩家}` 稱呼。
- 說話的人用現有城鎮的居民，會自動有頭像。新角色也可以，會套預設頭像。首領的台詞寫成 `名字（boss）：……`。
- 對話窗會把所有台詞留下來，玩家回頭看得到。所以伏筆可以分散在不同的岔路上，走不同的路線會看到不同的線索。

## 完成前

```
python3 spellduel-unity/Tools/check_dungeons.py
```

一定要 **0 個錯誤** 才提交。這支腳本和遊戲裡的解析器規則相同，也會檢查每句的字數。

提交訊息請寫：改了哪些副本、新增哪些副本，以及每個副本的劇情人物各是什麼角色。

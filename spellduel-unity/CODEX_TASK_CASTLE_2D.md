# Codex 任務：月影古堡（測試副本）的 2D 美術——8 方向 Q 版敵人＋2D 化的城堡場景

## 使用者的要求

> 幫我改一版測試用：做一關副本，場景仍是 3D，但敵人變成用 8 方向 2D 圖片，製作日式 Q 版的敵人（各個動作都做 8 方向），副本敵人先做 8 種，讓我進去試試。副本場景是歐式城堡內部。
>
> 副本的 3D 場景也試著都改用 2D 來表現。2D 部分讓 Codex 做。

範圍：先只做測試副本 `castle_test`（月影古堡），也就是 `dungeons.txt` 裡寫了 `style = castle` 的副本。其他副本不動。

## 請 Codex 做的

### A. 8 種敵人的 2D 圖（照下面的格式，覆蓋同名檔案）

**格式必須和 `SpriteEnemyView.cs` 一致，不然方向、動作會錯**

- **檔案**：`Assets/SpellDuel/Resources/SpriteEnemies/{sheet}.png`，2048×2048，透明背景。
- **格子**：每格 128×128，16×16 格。
- **格子編號**：`slot = (動作的第一張 + 第幾張) × 8 + 方向`，從左上往右數，滿 16 格換下一列。

| 動作 | 張數 | 第一張 | 說明 |
|---|---|---|---|
| idle 待機 | 4 | 0 | 呼吸、輕晃，循環 |
| walk 走路 | 6 | 4 | 循環。蝙蝠、幽靈是飛行或飄移 |
| windup 預備 | 2 | 10 | 第 0 張剛開始，第 1 張蓄到滿（第 1 張會停住，直到出手） |
| attack 出手 | 3 | 12 | 揮出、到底、收招 |
| hurt 受擊 | 2 | 15 | 往後仰、閉眼（> <） |
| die 倒下 | 4 | 17 | 第 3 張是最後的樣子（之後程式會淡出） |

共 21 張 × 8 方向 = 168 格，其餘格子留透明。

**方向**：0～7，是敵人面向相對鏡頭的角度，每 45° 一個。

| 方向 | 角色面向 |
|---|---|
| 0 | 正面（面向鏡頭） |
| 1 | 面向右前（畫面右邊偏向鏡頭） |
| 2 | 面向畫面右邊 |
| 3 | 右後 |
| 4 | 背面 |
| 5 | 左後 |
| 6 | 面向畫面左邊 |
| 7 | 左前 |

**位置和大小**
- 角色的腳底在格子底邊往上 6%（約 8px）的地方，水平置中。
- 一格的高度對應上表的「一格的高度」。例如骷髏劍兵：128px = 1.6m，Q 版身高大約 1.1～1.3m。
- 飛行的蝙蝠、飄浮的幽靈：圖裡的身體離格子底邊高一點，程式也會再把蝙蝠抬到空中。

**畫風**
- 日式 Q 版，大約 2～2.5 頭身。
- 粗外框、平塗加一層陰影和高光，大眼睛。
- 8 方向必須是同一隻、同樣的比例。背面看不到臉，左右對稱的方向動作要對應。

**角色設定**（可以照暫用圖的概念，畫得更好看）

| 敵人 | 外觀 | 動作 |
|---|---|---|
| 骷髏劍兵 | 骷髏、小頭盔、紅圍巾，生鏽短劍加小圓盾 | 舉劍 → 往前下方砍 |
| 空殼騎士 | 銀色盔甲、紅羽飾，頭盔縫裡亮著藍光，雙手大劍 | 高舉 → 往下砸 |
| 骷髏弓手 | 骷髏、綠兜帽，弓 | 拉弓 → 放箭 |
| 提燈幽靈 | 白色圓幽靈、小尾巴，提著紫色燈籠 | 燈籠舉高發光 → 放出 |
| 吸血小蝙蝠 | 圓滾滾的紫色蝙蝠、大耳朵、小尖牙 | 一直拍翅膀；預備是張嘴，出手是俯衝 |
| 南瓜炸彈 | 刻臉的南瓜頭，發光的眼和嘴，頭上的引信冒火花，小斗篷和短腿 | 預備時整顆鼓脹發亮 |
| 小石像鬼 | 灰石小惡魔，角、尖耳、小翅膀、尾巴 | 把石塊舉過頭 → 往前丟 |
| 見習黑魔導 | 大尖帽、黃帽帶，帽簷下只看得到兩隻黃色發光眼，藍長袍，法杖頂端紅寶珠 | 舉杖 → 寶珠發光 → 射出 |

**做法**
- 用什麼工具做都可以：程式繪製、自己的生圖流程都行。
- 最後輸出成上面的格式就好。
- 可以參考 `Tools/sprite_enemies/gen_castle_sprites.py` 的排版程式。

### B. 2D 化的城堡場景（只有 `map.theme == "castle"`）

**使用者想要的效果**：副本場景也用 2D 表現。地圖的格子、走道、牆的位置照舊（3D 空間、玩家照樣走），但看到的東西改成 2D 手繪風格，類似 HD-2D。

- **牆**：一格一片或幾片平面，貼上手繪的城堡牆面圖。
  - 石磚牆、拱窗加彩繪玻璃、紅金旗幟、壁掛火把、肖像畫、書架。
  - 依地點換主題：大廳、畫廊、圖書館、寶物庫、王座廳。
- **地面**：手繪貼圖。大理石棋盤格，沿著走道鋪紅地毯；區域邊緣有金色的框。
- **景物**：跟敵人一樣是永遠正對鏡頭的 2D 圖片。
  - 盔甲擺設、燭台、水晶吊燈（掛高處）、花瓶、王座、寶箱、書堆。
  - 不用 8 方向，單張就好。要動的（燭火、吊燈搖晃）可以做 2～4 張循環。
- **遠景**：室內，不要看到天空。
  - 高聳的石牆、柱子、拱頂的 2D 剪影圖，色調是昏暗的暖色。
  - 請一併確認地平線以下不會透出現實背景，參考 `ExploreArt.Atmosphere.cs` 的 `GroundBowl`。
- **門**：區域的閘門也換成 2D 圖。例如鐵柵門，打開的動畫可以是幾張圖。

**要改的地方**

`"castle"` 目前沒有專屬外觀，會被當成峽谷主題（4）。所以 Codex 要接上 castle 的分支：
- `ExploreArt.Dungeons.cs`：`DungeonThemeAt`、`DungeonBaseGround`、`CreateDungeonWall`、`DungeonWallBody`、`DungeonProp`、`DungeonWallGlow`
- `ExploreArt.DungeonSurfaces.cs`：`DressDungeonPath`、`CreateDungeonGate`、`CreateDungeonBackdrop` 開頭的主題對照
- `ExploreArt.Atmosphere.cs`：`HorizonColors`、`CreateBackdrop`
- 地板 shader：`Resources/Shaders/DungeonExploreFloor.shader` 的 `_Theme`，可以新增一個值給城堡

建議 castle 用新的主題編號 6。

**注意**
- 只改外觀，不要動地圖資料、區域、門的邏輯，也不要動戰鬥和連線。
- 2D 圖片的資源放在 `Assets/SpellDuel/Resources/CastleScene/`（或你覺得合適的資料夾）。
- 要考慮手機效能：
  - 材質、網格盡量共用。
  - 圖集不要超過 2048。
  - 景物數量照現有的翠蔭迷林。
- 預覽圖放 `Docs/castle_2d_preview/`。

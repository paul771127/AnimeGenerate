# 月影古堡：2D 場景

本輪依最新任務單 A 節保留 Claude 已交付的八種敵人圖集；驗證 8 × 168 個動作／方向格，並補 Unity 匯入設定。未重新繪製敵人。

場景新增三張共用圖集（1254 × 1254，最大匯入 2048、關 mipmap、禁止 NPOT 縮放）：牆面、透明景物、地板與室內遠景。五間房分別為玄關、畫廊、圖書館、寶庫、王座廳。獨立 castle 主題 6，不改其他副本、地圖資料、碰撞、戰鬥或連線。

牆面採平面貼畫；凹壁擺設保持在牆格內；景物只水平朝向相機。天花板與遠景封閉室內，下半球沿用 GroundBowl。鐵閘沿用 DungeonGateArt 與既有開門判定。網格與材質共用，不在 Update 建材質或網格。

## 生成方式與提示詞紀錄

使用內建 image_gen 生成／編輯；沒有外部 API 或下載圖片。以下為提示詞規格摘要（不是逐字工具紀錄）。選定結果原樣複製到 Resources/CastleScene，透明景物以 UV 矩形取樣，不改生成像素。

- walls.png：日式奇幻 HD-2D 手繪歐式城堡室內，紫灰石磚、暖燭光、紅絨與古金。嚴格 4 欄 × 2 列貼圖表，依序石牆、月光彩窗、紅金旗與火把、肖像畫、藏書架、寶庫金庫、王座帷幕、鐵閘石框。正面平視，無人、無字、無標籤、各格填滿。
- props.png：相同畫風，透明背景、4 欄 × 2 列，依序盔甲擺設、燭台、水晶吊燈、花瓶、紅金王座、寶箱、書堆、鐵柵門。正面立繪，完整輪廓，不互相重疊。第二次編輯縮回每格並加透明留白，鐵條間保持透明，保留原物件設計。
- surfaces.png：相同畫風，無人無字、2 欄 × 2 列。依序奶白／紫灰棋盤大理石、紅金織紋地毯、暗暖色室內高柱拱廊、肋拱石天花板。前兩格為平面俯視材質，後兩格供室內背景與拱頂貼畫。

## 驗證

Tools/check_castle_art.py 檢查圖集、匯入設定及既有敵人原始資料。Editor/CastleArtPreview.cs 輸出五室第一人稱／俯視、上下視野、閘門三態，並在 Unity 檢查路線、牆界、碰撞元件、快取與地圖資料不變。原生與行動平台結果以本目錄後續 CI 證據為準。

## 原生檢視後修正

- 凹壁內加大理石底板，避免原本地圖底面綠色露出。
- 王座帷幕集中於中央特徵牆；其餘牆交替石磚、旗幟與彩窗，畫廊交替肖像與石牆。
- SpriteEnemyView 僅修改待機相位的 Instance ID 部分：先取有界餘數再絕對值，避免負 ID 算出負影格／圖集外 UV。PNG、方向、動作格數、出招／受擊／死亡與戰鬥時序都不變。檢查腳本逐位元比對，確認該檔只有這一處修改。
- 原生預覽直接呼叫動畫取樣，避免 Editor 非播放模式的 SendMessage 斷言；新增 slot 0～167 檢查。閘門三態是獨立模型展示，用深灰背景；上／下視野才使用洋紅清屏來偵測漏底。
- 俯視圖刻意隱藏房間天花板，保留牆頂；外側綠色為未開放牆格底面，非可行走室內。實際第一人稱保留完整天花板。

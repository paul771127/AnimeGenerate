# 大地圖（世界地圖）重做（給 Codex）

## 使用者的要求
- 進入「🗺 大地圖」時，改成一張**由左到右的冒險路線圖**。
- 順序：**炎之里 → 1-1～1-4 → 森之里 → 2-1～2-4 → 潮騷港 → 3-1～3-4 → 赤砂城 → 4-1～4-4 → 風沙驛 → 5-1～5-4**。
- **每個區域的風景不同**，照章節主題：熔岩、森林、海上、角鬥場、黃土山道。
- **每一個地點都要在地圖上標出來**：城鎮、關卡、無盡塔。
- **一關一關開**：過完 1-1，右邊才出現 1-2，依序下去。
  - 還沒開的路被雲霧蓋住，看不到後面。
- **無盡塔**：在 2-4 的下方多一條岔路，通到無盡塔。
  - 使用者原本說「2-5」，但目前每章只有 4 關（第 4 關是 Boss），所以先接在 2-4。
  - 以後每章擴成 5 關的話，岔路改到 2-5，所以每章請多留一個關卡點位的空間。
- **主角縮圖**：主角以 Q 版小人顯示在大地圖上「目前的位置」。
  - 點哪一關，主角就沿著路走到那一關的點位。
  - 到了之後畫面往那個點**縮放放大（zoom in）**進入關卡（出發前的整備畫面）。

這張單請做：**美術素材**＋**座標資料**＋**版面示意**。
程式由我這邊接（`Runtime/WorldUI.cs` 的 `DrawMap`），動畫（主角走路、縮放轉場、雲霧散開）也由程式做。

## 一、地圖本體

### 方向與尺寸
- 手機是**直式**（1080×1920）。地圖做成**橫向長卷**：高度＝畫面高，可以左右拖曳。
- 分成 **5 張區域圖**，每張 **2160×1920**，左右邊緣要能**無縫接起來**（路、河、地形連續）。
  - 檔案：`Assets/SpellDuel/Resources/WorldMap/region_{1..5}.jpg`
  - 1 炎之里與熔岩山區
  - 2 森之里與古樹森林
  - 3 潮騷港與海岸、海上
  - 4 赤砂城與角鬥場
  - 5 風沙驛與黃土山道
- 另外附一張縮小的全景預覽：`Docs/worldmap/full_preview.jpg`（5 張接起來，寬 5400 左右即可），給我檢查銜接。

### 畫風與內容
- 畫風：和城鎮俯瞰圖（Village2D）一致，日系手繪奇幻地圖。視角可以是 45 度俯瞰，或「繪本風的斜上方地圖」。
- **一條主要道路**由左到右貫穿 5 個區域，把城鎮和所有關卡串起來。路要清楚，程式會在路上畫行走路線。
- **每個區域的開頭是城鎮**（小鎮的縮小版建築群）。
- **城鎮之後是 4 個關卡點**（＋1 個預留位置），沿著路排開。
  - 每個關卡點是一個小地標，例如：
    - 1-1 灰燼中的歸途：焦黑的山路
    - 1-2 赤爐裡的斷鐘：熔爐廢墟
    - 1-3 守鐘人的沉默：鐘塔遺跡
    - 1-4 熔岩巨像：火山口
  - 關卡名與劇情在 `Resources/story.txt`，每一關的地標請照關卡名設計。
- **第 4 關是 Boss**：地標要明顯大一號、有壓迫感，例如熔岩巨像的火山口、腐化樹王的巨樹、深海巨妖的漩渦。
- **無盡塔**：2-4 下方分出一條岔路，通到一座高聳入雲的塔，塔頂看不到。
- **地圖上不要寫字**，地點名稱由程式畫。

### 座標資料
`WorldMap/nodes.json`：所有座標以「5 張圖接起來的整張圖」為準（寬 10800、高 1920、左上原點）。

```json
{
  "nodes": {
    "town:0": {"x": 300, "y": 1100},
    "1-1": {"x": 700, "y": 1000, "label_x": 700, "label_y": 880},
    "1-2": {...}, "1-3": {...}, "1-4": {...}, "1-5": {...},
    "town:1": {...}, "2-1": {...}, "...": {},
    "tower": {"x": ..., "y": ...}
  },
  "paths": [
    {"from": "town:0", "to": "1-1", "points": [[300,1100],[420,1060],[560,1020],[700,1000]]}
  ]
}
```

- **nodes**：每個地點的中心（主角站的位置）＋名牌位置。
  - `town:0`～`town:4` 是城鎮。
  - `x-5` 是預留點位，目前不顯示。
- **paths**：相鄰兩點之間沿著路的折線，給主角走路、給程式畫「已開放的路」用，每段 3～8 個點。
  - 2-4 → tower 的岔路也要。
  - 4-5 → town:4 這種跨區域的路也要。

## 二、程式會疊上去的小素材

放 `Assets/SpellDuel/Resources/WorldMap/ui/`，透明 PNG：

| 檔案 | 尺寸 | 說明 |
|---|---|---|
| `node_locked.png` | 128×128 | 還沒開的關卡（鎖、灰） |
| `node_open.png` | 128×128 | 可以打的關卡（發光的旗子或火炬） |
| `node_clear.png` | 128×128 | 打過的關卡（插著勝利旗） |
| `node_boss.png` | 160×160 | Boss 關（骷髏或王冠，打過可以換成 `node_boss_clear.png`） |
| `node_town.png` | 160×160 | 城鎮標記 |
| `node_tower.png` | 160×160 | 無盡塔標記 |
| `label_plate.png` | 9-slice | 地點名牌底 |
| `fog_{0..2}.png` | 約 1024×1024 | 雲霧（還沒開的區域蓋住用），邊緣柔和、可以疊、會慢慢飄 |
| `stars_{0..3}.png` | 96×32 | 這一關在簡單／普通／困難通關過幾顆星（0～3） |

### 主角 Q 版小人
- 檔案：`WorldMap/hero_{class}_{dir}_{frame}.png`
  - class：`novice`、`swordsman`、`archer`、`mage`、`assassin`、`priest`（進階職業先用基本職業的）
  - dir：`side`（往右走；往左由程式翻轉）
  - frame：`0..3`（走路 4 格）
  - 另外 `idle_0..1`（站著輕輕晃）
- 尺寸 192×256，透明背景，腳底在下緣中央。
- 長相照 `Story2D/classes/` 的職業頭像（同一個主角），頭身比 2～2.5。

## 三、版面示意（請附 mockup）
1. 剛開始（只開 1-1）：炎之里與 1-1 清楚，右邊被雲霧蓋住，主角站在炎之里。
2. 打到 2-4（有岔路）：無盡塔的岔路出現。
3. 點了 1-3：主角沿路走到 1-3，名牌亮起，下方出現關卡卡片（關卡名、推薦等級、「⚔ 出發」）。
- 上方：「🗺 大地圖」標題、金幣、難度切換。
- 下方：「📜 角色」「🏘 回城鎮」。

**按鈕文字請保留**「⚔ 出發」「📖 看故事」「🗺 大地圖」，新手指引用這些文字找按鈕。

## 四、建議（我的想法，使用者確認後再做）
1. **關卡點旁顯示星星**：簡單、普通、困難各通關一次得一顆，一眼看出哪裡還能挑戰。
2. **城鎮也是可以點的點位**：主角走過去 → 進到那個城鎮的 2D 城鎮圖（取代原本大地圖上的城鎮按鈕）。
3. **新開一關時的演出**：雲霧散開、路一段一段亮起來、新的旗子插下去（程式做，素材用上面的 fog 和 node）。
4. **主角走路最多 1.5 秒**：太遠就加速，不讓玩家等。
5. **Boss 關前面的路顏色變暗紅**，提示前面是強敵。

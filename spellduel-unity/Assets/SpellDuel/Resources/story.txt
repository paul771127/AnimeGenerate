# 主線：獻給黎明的三重奏
# 鐘舌、名冊、種子與歌聲僅用於敘事；沒有額外物品或操作要求。

[chapter 1] 第一章　請讓鐘聲再響一次
晨鐘啞了。炎之里等著礦工回家，山腹卻傳來另一種敲門聲。

[stage 1-1] 灰燼中的歸途
清出礦道口，讓受困的採礦隊回到炎之里。
theme = volcano
waves = 1-3
xp = 100
req = none
<before>
旁白：灰燼落滿空飯桌。炎之里的晨鐘，已經三天沒有響過。
老焰：{玩家}，採礦隊還在山上。拜託你，替他們清出一條路。
艾琳（mage）：我是來抄鐘文的艾琳。礦道圖我讀得懂，我帶你找人。
老焰：看見紅頭巾的少年，別讓他再往裡跑。那是小鐵。
艾琳（mage）：小鬼堵住了避難洞。打退牠們，我就能帶傷員下山。
旁白：洞裡傳來敲擊聲。三下，停一拍，又是三下。
<after>
旁白：洞口安靜下來，小鐵背著受傷的師父，一步步走進光裡。
小鐵：我沒亂跑……師父走不動，我不能把他留在那裡。
艾琳（mage）：你等到了。{玩家}，村裡的人已經抬著擔架來了。
小鐵：這片銅是在廢礦撿的，剩下那截還埋在赤爐裡。
艾琳（mage）：上面有古鐘文。先送他們回村，我想再去查一趟。

[stage 1-2] 赤爐裡的斷鐘
找回另一截鐘舌，查明礦坑與停響的晨鐘有何關聯。
theme = volcano
waves = 4-6
xp = 150
req = 1-1
<before>
旁白：師父的傷已包好，小鐵卻還攥著那片燙紅的銅。
小鐵：這不是礦石，是鐘舌。師父說，斷口像被人敲開的。
米菈：我見老焰半夜推車進廢礦。他只叫我別問載著什麼。
艾琳（mage）：鐘文缺了後半句，得找到另一截才讀得通。
艾琳（mage）：火焰射手守住赤爐口。{玩家}，請替我打開入口。
<after>
旁白：碎石下露出半截鐘舌，旁邊是繡著「焰」的舊手套。
艾琳（mage）：「火照路，木記名，潮送人歸」……三地的鐘原來相連。
米菈：我替你們守住回程。帶著證物回村，當面問他吧。
旁白：回到炎之里，小鐵把兩截鐘舌放到老焰面前。
老焰：是我折斷的。鐘裡有人喊救命，我怕得不敢再聽。

[stage 1-3] 守鐘人的沉默
把修好的鐘舌送上祭道，阻止熔岩逼近村莊。
theme = volcano
waves = 7-9
xp = 250
req = 1-2
<before>
老焰：真正的火之鐘在山腹。村裡這口，只傳它的回音。
老焰：呼救聲叫著四十年前的名字。我把鐘舌折斷，埋進廢礦。
艾琳（mage）：鐘沒響，山卻醒了。你想藏住的事，正在傷害村子。
小鐵：鐘舌補好了。師父說，修東西得先承認哪裡裂了。
老焰：我留下疏散村民，也託米菈送信給森之里的翠。她知道那些名字。
艾琳（mage）：{玩家}，清開祭道吧。把鐘舌送回去，還有機會擋住熔岩。
<after>
旁白：祭道打通，石閘後露出巨大的手掌。巨像正抵住湧來的熔岩。
艾琳（mage）：牠一直在護著山下……可胸前的黑晶正在往手臂蔓延。
熔岩巨像（boss）：潮門……不可開……求救者……不許通行……
艾琳（mage）：牠分不清求救與入侵了。我們得打碎黑晶，讓牠放下拳頭。

[stage 1-4] 熔岩巨像・守門人的拳
擊碎黑晶，讓火之鐘喚回守護者的意識。
theme = volcano
waves = 10
xp = 500
req = 1-3
<before>
熔岩巨像（boss）：放過一人……洪潮便會進來……山下的人，會死……
艾琳（mage）：{玩家}，牠不是要佔領村子。牠被困在一次沒結束的守門裡。
旁白：黑晶猛然收緊，巨像鬆開石閘，朝兩人舉起雙拳。
熔岩巨像（boss）：封住……所有的路！
艾琳（mage）：攔住牠！等黑晶碎開，我就把鐘舌送進鐘架。
<after>
旁白：巨像跪下。艾琳扣回鐘舌，鐘聲引著熔岩轉入地下。
熔岩巨像（boss）：這一次……鐘裡的聲音，不是敵人……
熔岩巨像（boss）：去找木之鐘……它還記得……白帆號……
艾琳（mage）：山下也響了！他們安全了，老焰終於能向大家報平安。
艾琳（mage）：翠收的是老焰的信。我們帶上鐘文去森之里，問清白帆號的事。

[chapter 2] 第二章　霧不該帶走名字
守鐘人的信先到了森之里。記名林裡，古樹還在替一艘船守候。

[stage 2-1] 葉燈照著來時路
清除聚落外的毒花，找回通向記名林的路。
theme = forest
waves = 1-3
xp = 400
req = 1-4
<before>
翠：老焰的信，米菈送到了。想查白帆號，得去記名林。
楓（archer）：毒花把路封了。你們清開花叢，我來掛回帶路的葉燈。
小葉：樹王也講過白帆號！牠說，那是載著星星的小船。
艾琳（mage）：故事裡的人回家了嗎？
小葉：不知道。每次說到港口，牠就停下來。
楓（archer）：{玩家}，先把這條路打通。村裡等著去採藥的人也能出門了。
<after>
旁白：毒花枯伏，採藥人沿著重新點亮的葉燈走出聚落。
楓（archer）：到了。樹根下這些木牌，替沒回來的人留著位置。
艾琳（mage）：「澪，白帆號領唱」……小葉說的星星，是人的名字。
楓（archer）：帶這塊鬆落的牌去找翠吧。她守著古碑，卻總不肯讀完它。

[stage 2-2] 碑文缺去的半行
打退盤踞古碑的魔物，讀出被掩藏的封印記錄。
theme = forest
waves = 4-6
xp = 600
req = 2-1
<before>
旁白：翠摸著「澪」的刻痕，帶兩人停在一座滿是鑿痕的古碑前。
翠：四十年前，白帆號用歌聲引開巨妖。三鐘原要替它照亮歸航的路。
艾琳（mage）：可我讀的封印史說，那一天沒有人犧牲。
翠：因為剩下的話，被我們的先人鑿掉了。
艾琳（mage）：{玩家}，請清開碑前的藤蔓。這一次，我們把記錄讀完。
<after>
旁白：藤蔓鬆開。碑底留下最後一行：「潮門先閉，白帆未歸。」
翠：守鐘人怕巨妖回頭，提早封住潮門。整艘船都被留在外海。
艾琳（mage）：我還把「無人犧牲」念給孩子們聽……我要當面更正它。
翠：如今大返潮鬆了封印。巨妖把那些呼救送進三鐘，侵蝕了守護者。
艾琳（mage）：火之鐘醒了，木之鐘還在受苦。我們得趕在名字消失前到樹心。

[stage 2-3] 接住快要散去的字
打通樹心祭道，把倖存的名牌送到樹王面前。
theme = forest
waves = 7-9
xp = 800
req = 2-2
<before>
楓（archer）：樹王把名字刻進樹根，黑晶卻正沿著刻痕長進樹心。
艾琳（mage）：牠記住越多，傷得越深。難怪牠不讓任何人靠近。
翠：這些是剩下的木牌。請告訴牠，森之里也會分擔這份記憶。
艾琳（mage）：我帶了名冊。{玩家}，清開祭道，我們把名字送進去。
楓（archer）：我守住回程的葉燈，你們不必擔心找不到家。
<after>
旁白：祭道盡頭，一根失控的枝條撕開背包。艾琳伸手接住散落的木牌。
艾琳（mage）：嘶……手還能用。牌沒碎，快看，上面還有字。
腐化樹王（boss）：不許拿走……人會忘記……我不能停……
艾琳（mage）：不是拿走。我們把澪和所有人的名字，帶回來給你聽。
腐化樹王（boss）：澪……可是，紙也會……燒盡……

[stage 2-4] 腐化樹王・不肯入睡的心
打碎束縛樹心的黑晶，讓記憶有人接手。
theme = forest
waves = 10
xp = 1200
req = 2-3
<before>
腐化樹王（boss）：我若睡去……再也沒有人，等他們回來……
艾琳（mage）：翠會重刻木牌，小葉會讀名冊。你不必獨自記住所有人。
旁白：黑晶發出尖響，樹根將祭壇圍成一圈。毒霧裡，只剩斷續的喘息。
艾琳（mage）：{玩家}，先打碎黑晶。讓牠聽見的，不再只有海底的求救。
腐化樹王（boss）：別讓……最後一個名字……消失！
<after>
旁白：黑晶裂開，樹根緩緩展平。木之鐘輕響，一顆種子落在名冊上。
腐化樹王（boss）：澪說……港燈亮了，才唱最後一段……帶它去海邊……
艾琳（mage）：種子留下了鐘的餘響。你的故事，我們會帶到潮騷港。
翠：森之里留一份名冊。我請米菈先送另一份給海斗，他是白帆號船長的後人。
艾琳（mage）：手包好了。{玩家}，我們去找海斗，把那盞燈重新點起來。

[chapter 3] 第三章　這一次，岸上有人回答
白帆號的名字抵達潮騷港。舊燈塔下，船長的後人等著一個遲到的答案。

[stage 3-1] 航圖終點是家
清出港外礁岸，讓船隊撤往內港，打開登塔的退潮道。
theme = sea
waves = 1-3
xp = 600
req = 2-4
<before>
旁白：米菈送來的名冊攤在海圖上。海斗一直用手壓著「白帆號」三個字。
海斗：我祖父是船長。家裡只留下航圖，和一首不准在港邊唱的歌。
艾琳（mage）：樹王說，領唱的澪還在等港燈。
阿潮：海怪堵住外礁，漁船撤不回來。先清開礁岸，我再帶你們走退潮道。
海斗：{玩家}，請幫我把大家接進港。這次，我也要去替祖父點燈。
<after>
旁白：最後一艘漁船駛進內港。阿潮從礁縫撿起一枚刻著「白帆」的銅扣。
海斗：航圖上畫過這個記號。祖父的船，就在舊燈塔前方。
艾琳（mage）：種子也朝那裡發芽了。木之鐘還在替我們帶路。
阿潮：退潮道露出來了。回港拿足燈油，再晚就上不了礁。

[stage 3-2] 窗邊留著的半首歌
護送港口的燈火穿過礁群，重亮面向白帆號的舊塔。
theme = sea
waves = 4-6
xp = 900
req = 3-1
<before>
旁白：出發前，凪把一盞添滿油的燈，放進你的手裡。
凪：海斗，你祖母每年都坐在我家窗邊，望著舊塔唱歌。
海斗：她只唱到一半。我小時候嫌難聽，後來卻不敢問為什麼。
凪：後半首，我母親教過。「岸有燈，杯有茶，你的名字有人答。」
艾琳（mage）：{玩家}，礁群裡的魔物在等我們。守住燈，海斗就能登塔。
海斗：不必替我找原諒。先讓海上的人知道，岸上聽見了。
<after>
旁白：海斗推開塔門，轉動鏽輪。燈光越過黑浪，照到一片破碎的白帆。
海斗：岸有燈，杯有茶……你的名字，有人答。
澪：那盞燈……是給我們的嗎？
艾琳（mage）：是。澪，我們帶了你們的名字，沒有把任何一個劃掉。
澪：我以為岸上的人，已經不會再叫我了。

[stage 3-3] 白帆不再獨行
打通沉船礁，護住歸航曲抵達潮之鐘的路。
theme = sea
waves = 7-9
xp = 1200
req = 3-2
<before>
澪：潮門關上後，巨妖便逼我們反覆唱求救的那一句。
澪：怨聲讓牠醒來，牠就更不肯放我們走。
海斗：我想見祖父。但如果你們不願回來，也不用再替我們做什麼。
澪：我想把歌唱完。只是守住沉船礁的魔物，不讓我靠近潮之鐘。
艾琳（mage）：{玩家}，清開礁群吧。這一段航路，換活著的人來守。
<after>

深海巨妖（boss）：沒有怨恨，你們便什麼也不剩！不准靠近我的鐘！
艾琳（mage）：牠攔在最後一段航路上。{玩家}，我們一起守到天亮。

[stage 3-4] 深海巨妖・黎明的三重奏
擊碎巨妖胸前的黑晶，讓潮之鐘把未完的歌送回岸邊。
theme = sea
waves = 10
xp = 1700
req = 3-3
<before>
旁白：巨妖攀上礁石。胸前的潮之鐘，被刻滿名字的黑晶牢牢鎖住。
深海巨妖（boss）：再留一個活人的聲音！我就讓你們的港口平安！
澪：別把活人的名字給牠。我們等的不是另一個人沉下去。
艾琳（mage）：這次不關潮門。{玩家}，擊碎黑晶，我和海斗把歌接下去。
海斗：凪還在岸上守著燈。我們也不退。
深海巨妖（boss）：燈會熄！你們終究會忘記！
<after>
旁白：巨妖墜回深海，黑晶崩散。三鐘隔著山、林與海，終於一同響起。
深海巨妖（boss）：把鐘停下……我的海，不准天亮……
澪：岸有燈，杯有茶……海斗，船長說，你把家守得很好。
旁白：白帆化入晨光。此後，炎之里報曉，森之里重刻木牌，港口立起歸航者名碑。
艾琳（mage）：{玩家}，這次我寫下了所有名字。等我們回家，把紀行念給大家聽吧。

# 首頁與連線畫面的美術（給 Codex）

使用者的要求：**一開始的主頁面跟連線頁面也要更簡單、美觀，風格要和其他選單統一。**
內容與流程 Claude 已經簡化好了，畫面集中在 **`Assets/SpellDuel/Runtime/GameRoot.Lobby.cs`**，請只改這個檔（可以在 `UiKit.cs` 新增共用的小工具）。風格沿用 [`UI_ART_BRIEF.md`](UI_ART_BRIEF.md) 已經做好的 UiKit 主題：魔晶面板、金屬邊框、寶石點綴、日式賽璐珞奇幻。

## 1. 首頁 `DrawHome`
- 現在的內容：
  - Logo 徽章
  - 「SpellDuel」標題和一句副標
  - 三張大卡片：單人冒險／和身邊的朋友對戰／和遠方的朋友連線
  - 下方一個小按鈕：「進階：標記圖模式」
  - 最底下的版本號
- 要做的：
  - **遊戲 Logo**：「SpellDuel」字樣做成有設計感的標題，例如金屬字、魔法光暈、符文環繞。
  - **三張卡片要像遊戲的主選單**：每張有自己的插圖感圖示和主題色（單人＝藍、身邊＝橘、遠方＝紫），按下有回饋。
  - **背景**：可以有緩慢流動的魔法粒子或符文（用 `Time.time` 動畫），但不要蓋過相機畫面太多；AR 開著時，背景是真實房間。
  - 標記圖模式是進階功能，保持低調的小按鈕。

## 2. 連線／場地畫面 `DrawLobby`
- 現在的內容：
  - 上方一張卡片，最上面是模式標題。
  - 下面是**步驟清單**：每一步有三種狀態，✅ 完成、▶ 現在這一步（附一行提示）、○ 還沒。
  - 現在這一步的按鈕放在清單下面。
  - 最下面是「換模式」與「ℹ 詳細」；除錯資訊收在詳細裡。
- 各模式的步驟：

  | 模式 | 步驟 |
  |---|---|
  | 單人 | 找到地板 → 建立 10m 場地（自動） |
  | 身邊的朋友 | 找到地板 → 連線（房間代碼） → 📱 並排對齊 → 10m 場地 → 選職業 |
  | 遠方的朋友 | 找到地板＋場地 → 連線（建立／貼上代碼） → 選職業 |
  | 標記圖 | 連線（IP） → 掃描標記圖 → 選職業 |

- 要做的：
  - **步驟清單做成「任務進度」的樣子**：
    - 左邊是編號寶石或圓章，完成會亮起打勾。
    - 現在這一步要醒目，例如發光、微微脈動。
    - 步驟之間用細線連起來，像一條路線。
  - **房間代碼**：要大、好讀，像刻在石板或魔法卷軸上。複製按鈕放在旁邊。
  - **輸入代碼的欄位**（`GUI.TextField`）：用 `field` 樣式，可以重新設計外框，但要保留 `GUI.TextField` 才能打字。
  - **卡片高度**：卡片只佔畫面上方，下面要看得到相機畫面（掃地板、場地框都在相機畫面上）。卡片高度依內容自動調整（`panelBottom`）。
  - **「詳細」展開的除錯資訊**：用比較小、比較淡的字，看起來像「工程模式」，和主要步驟有區隔。

## 規則
- **只改外觀與排版**：每個 `if (UiKit.Button(...)) { … }` 大括號裡的程式碼、按鈕出現的條件、步驟的完成條件（`S(...)` 的參數）都不能改。
- `panelBottom` 要設成卡片的下緣（下面是遊戲區，點畫面會用到）。
- 純程式繪製，不能用圖檔；手機直式，注意 `Screen.safeArea`。
- 不要改 `GameRoot.cs`（連線、對齊、AR 的邏輯）、`SoloBattle.cs`、戰鬥與網路程式。
- iOS／Android 都要能編譯（Claude 會再檢查與建置）。

## 驗收
如果有工具，產生 `docs/lobby_ui.png`，包含三張畫面：
- 首頁
- 「身邊的朋友」進行到第 3 步（並排對齊）
- 「遠方的朋友」的房主顯示房間代碼

# 第二輪：首頁配色與背景（使用者：首頁美化一下配色，做點背景）

首頁現在有六張卡片，從上到下：

1. 📖 故事模式
2. 👥 附近對戰
3. 🌐 遠距對戰
4. 🎯 練習模式
5. 👀 觀戰
6. ⚙ 設定

卡片上方是 Logo 和副標，最底下是版本號。

目前首頁背景是半透明的 `UiKit.Backdrop`，後面透出相機畫面，加上 `LobbyDust` 的點點，看起來很空、偏暗。

**這一輪請把首頁做成有氛圍的遊戲主畫面。只改 `DrawHome` 的畫法，以及它用到的 `LobbyDust`、`LobbyLogo`、`LobbyModeArt`。**

## 1. 背景（不透明，蓋住相機畫面）

**主視覺**，二選一：
- **(a) 影片影格**：從 `Docs/story_video/frames/` 挑一張適合當主畫面的。例如炎之里的晨鐘、迷霧森林，選構圖適合直式裁切的。
  - 複製到 `Assets/SpellDuel/Resources/ui/home_bg.jpg`。
  - 縮到寬 1080 以內，JPG 300KB 以內。
  - 用 `Resources.Load<Texture2D>` 讀，`ScaleMode.ScaleAndCrop` 鋪滿全畫面。
- **(b) 純程式畫的場景**：黃昏漸層天空、遠山剪影（五章的地形：火山、森林、海、角鬥場、黃土山）、炎之里的鐘樓剪影、地平線的光。

**疊在主視覺上的東西：**
- **動態**：緩慢飄動的光點、螢火或火星；一兩道很淡的符文環慢慢旋轉。用 `Time.time`，不要逐幀建立貼圖。
- **可讀性**：卡片後面加一層由下往上變暗的漸層，卡片上的字要清楚。

## 2. 配色

六張卡片的主題色要更協調，現在顏色各自為政：

|卡片|主題色|
|---|---|
|故事|暖金|
|附近|橘紅|
|遠距|紫|
|練習|青藍|
|觀戰|天藍|
|設定|灰銀|

- 主題色要整理成同一組彩度、明度，像同一套遊戲 UI。
- 卡片底色用深色半透明的魔晶面板，邊框用主題色細線＋金屬角飾。
- 標題用白色或淡金，說明文字用淡色。
- Logo 和背景的光要呼應主色，暖金配深藍紫的夜空。

## 3. 其他

- 「📖 故事模式」是主要入口，可以比其他卡片大一點，或有主題光暈。
- 首頁的「⚙ 設定」卡片和畫面右側常駐的 ⚙ 按鈕會同時出現，可以接受；不要動 `SettingsMenu`。
- 版本號維持在最底下、小而淡。
- **規則同第一輪**：
  - 每個 `if (UiKit.Button(...)) { … }` 裡的程式不能改，卡片的順序、文字不能改。
  - 手機直式，注意 `Screen.safeArea`，小螢幕上六張卡片要放得下。
  - iOS／Android 都要能編譯。

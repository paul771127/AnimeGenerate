# 生成器工單 007：重新生成「炎之里」城鎮（賽璐璐火山風，NPC 進屋）

- **發單**：SpellDuel 遊戲端（雲端 Claude Code session）
- **執行**：本機的場景生成器 session（城鎮生成器、`cel_kit_control.py` 或你認為適合的接口）
- **工單資料夾**：`scenegen/jobs/spellduel-cloud/007-town-ember-village/`
- **成果放到**：`spellduel-unity/Assets/SpellDuel/Resources/TownKit/town0_cel_v1/`（新資料夾）

## 使用者的要求

> 請場景生成器重新生成「炎之里」的城鎮。NPC 該擺到房子裡的，就擺進房子。

「炎之里」是第一章的村子（遊戲裡的城鎮 0）。現在的 3D 村子是程式拼出來的（`TownArt.*.cs`）：
- 房子是封閉的小方塊。
- 所有 NPC 都站在建築物外面的廣場上，連鐵匠、店員也站在門口。

請重新生成整個村子，風格跟第一大關的火山零件一致（`SceneKit/volcano_cel_v3`，工單 006）。重點是**有室內空間的房子**：該在室內工作的 NPC 要站在屋裡，玩家可以走進去找他。

## 村子的設定（故事）

- 晨鐘與鍛爐相伴的山村，在火山腳下，地上有火山灰。
- 村民大多是礦工和鐵匠。
- **晨鐘**：村子的象徵，掛在鐘樓上。
  - 故事裡晨鐘啞了三天，第一大關打完才重新響起。
  - 鐘樓要醒目，但不要做成能進去的建築。
- **鍛爐**：鐵匠鋪裡的爐火是主要的暖光來源。
- **礦坑入口**：村外山壁上有礦道口（第一大關的入口方向），可以只做外觀。
- 旅行商人米菈有一台載貨的車。

## 遊戲的硬性規則（一定要照）

### 座標

- 單位公尺，Y 朝上，+Z 是前方（同 001～006）。
- 原點 `(0, 0)` 是玩家進村時站的位置，面向 +Z。
- 廣場中心在 `(0, 5)`。

### 範圍

- 村子是半徑 **13m** 的圓（中心 `(0, 5)`），外圍一圈柵欄或石牆。
- **東邊出口**（往第一章關卡）在 `(13, 5)`，缺口寬 **2.8m**（半寬 1.4m）。
- 村子外面可以有山壁、礦道口、遠景火山（只看不走）。

### AR 的限制

- 這是 AR 遊戲，玩家用身體走路。
- 室內要夠寬，不然會撞牆或覺得擠：
  - 門寬 **≥ 1.8m**。
  - 室內可走的空間 **≥ 4m × 4m**。
  - 天花板 **≥ 3m**。
- 建議做成「正面整片敞開」的工坊／店面式建築（像有屋頂的攤位，或拉起捲簾的店面），不要只有一扇窄門的封閉房間。
- 玩家眼睛高度約 1.5m。

- 路面要明顯（石板或踩實的路），跟不能走的地方分得清楚。

## 畫風

- 跟 `SceneKit/volcano_cel_v3` 同一套：
  - 賽璐璐兩階上色、大筆觸手繪貼圖。
  - 岩石冷色（`#2c3842`～`#6f6f6b`），熔岩和火光暖色。
- 村子要比副本**溫暖、有人味**：
  - 木頭、紅褐色的屋瓦、布篷、暖色燈籠、鍛爐的火光。
  - 跟冷色的火山岩形成對比。
- 天空照遊戲現在的設定：地平線附近暖色薄霧 `#cca894`，上方青藍 `#5c94ad`。
- 只學畫風，不要做出任何現有遊戲裡特定的建築、地標或標誌。
- 光影烘進貼圖（遊戲用不打光的材質），不要附 URP 材質、`.meta`、`.mat`。

## 要交的東西

### 1. 模型

放在 `Resources/TownKit/town0_cel_v1/`：
- 每棟建築一個 FBX，例如 `bld_smith.fbx`、`bld_shop.fbx`、`bld_guild.fbx`、`bld_house_chief.fbx`、`bld_belltower.fbx`。
  - 原點在建築地面中心，敞開面（門）朝 +Z。
- 擺設用共用模型：`prop_lantern.fbx`、`prop_crate.fbx` 等。
- 地面（村子的路、廣場、草地或灰地）：一個或幾個 FBX。
- 外圍：柵欄或石牆、東邊出口的門、外面的山壁和遠景。

### 2. 配置檔 `town_layout.json`

遊戲照這個檔擺放和判斷碰撞：

```json
{
  "version": 1,
  "plaza": [0, 5], "radius": 13, "spawn": [0, 0], "spawnYaw": 0,
  "exits": [ { "id": "east", "pos": [13, 5], "halfWidth": 1.4 } ],
  "warp": [5, 0.5],
  "buildings": [
    { "id": "smith", "file": "bld_smith.fbx", "pos": [-7, 8], "yaw": 0,
      "solid": [[x,z], ...],
      "walkable": [[x,z], ...],
      "door": { "pos": [x,z], "width": 2.4 },
      "sign": [x, y, z] }
  ],
  "props": [ { "file": "prop_lantern.fbx", "pos": [x,z], "yaw": 0, "solid": 0.3 } ],
  "npcs": [
    { "role": "smith", "name": "鐵匠", "pos": [x,z], "yaw": 180, "inside": "smith" },
    { "role": "story:小鐵", "pos": [x,z], "yaw": 0, "inside": "smith" },
    { "role": "story:老焰", "pos": [x,z], "yaw": 0, "inside": "house_chief" },
    { "role": "story:米菈", "pos": [x,z], "yaw": 0, "inside": null }
  ],
  "paths": [ [[x,z], ...] ]
}
```

欄位說明：
- `solid`：擋住玩家的範圍（多邊形，牆、櫃台、鐵砧、爐子），全部用村子座標。
- `walkable`：室內可以走的範圍。
- `npcs`：每個 NPC 的站位和面向（yaw 是度數，0 是 +Z）；`inside` 寫在哪一棟裡面，室外寫 `null`。
  - NPC 要站在櫃台、鐵砧等的**後面**，面向門口。
  - 玩家站在櫃台前面可以跟他說話，距離 1.2～2.2m。
- `role` 對應的 NPC：
  - 設施：`smith` `shop` `guild` `dungeon` `training` `bounty` `watch`
  - 故事人物：`story:老焰` `story:小鐵` `story:米菈`

### 3. 預覽（`previews/`）

1. `overview.png`：從上方斜看整個村子，標出每個設施和 NPC 站位。
2. `spawn_view.png`：從原點 `(0, 0)`、眼睛 1.5m 往 +Z 看。
3. `smith_inside.png`、`shop_inside.png`、`guild_inside.png`：站在門口往裡看，NPC 位置用人形標記。
4. `east_exit.png`：從廣場看東邊出口。

### 4. 其他

- 工單資料夾寫回 `generator_request.json`、`response.json`、`inspect.json`。
- `inspect.json` 要有：
  - 總面數、每棟面數。
  - 每棟的門寬、室內可走面積。
  - 每個 NPC 到門口的距離。
  - 路寬的最窄處。

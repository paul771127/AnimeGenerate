# Codex 任務：翠蔭迷林——走得到的路要一眼看出來、湖改圓弧

使用者實際玩過故事探索後的回饋：

> 能走的路地板要明顯不一樣。
> 水做的很好看，但要避免方形，湖應該是要圓弧的，方形跟銳角很假。
> 走路很容易卡住，經過樹或障礙物就卡住。

**Claude 已經做的（不用重做）**
- `ExploreMap.CellSize` 從 3m 改成 **4m**（走道加寬）。競技場半徑跟著放大 4/3 倍。
- 衝刺擦到牆角、樹時會沿著邊滑過去，不會整個停住。
- 你的美術有兩處寫死 3m，我先改成跟著格子大小：
  - `ExploreArt.Landmarks.cs` 湖面的方塊：±1.5 → ±`CellSize/2`。
  - 競技場的 `RimSet` 位置：第二競技場的東移 3 → `CellSize`，往外的距離 ×`CellSize/3`。
  - 請確認其他地方（地標裝飾的位移、`ClampCell(1.42f)`、預覽與驗證腳本裡的 3m 假設）在 4m 格子下也對，有寫死的一併改。

## 1. 走得到的路要明顯不同

現在的 `CreateGround` 是很淡的地貼，在 AR 裡跟真實地板混在一起，玩家分不出哪裡是路。

- 走道（`ExCell.Floor`）要有一條**連續、清楚的小徑**：例如踩實的泥土路、碎石路，中間比兩側亮或顏色明顯不同，邊緣有草叢或石塊收邊。
  - 跟相鄰的 Floor 格連起來（看上下左右哪邊也是 Floor，路就往那邊接），轉角是圓弧，不要每格一塊方磚。
  - 介面建議：`CreateGround(ExGround g, int x, int z, float cell, int openMask)`。openMask 用 1 東、2 西、4 北、8 南。你也可以直接讀 map；不想改簽名的話，另外加一個 `CreatePath(ExploreMap map, int x, int z)` 也可以。
- 透明度要夠：在一般室內地板（木地板、磁磚、地毯）上也要一眼看得出來。請用 AR 合成的參考圖驗證（之前那張中性地板圖）。
- 營地、城寨、洞窟、古殿這幾種地面可以保留各自的材質，但「路」的部分一樣要比牆邊明顯。
- 牆（`CreateWall`）的樹叢、岩石、樹冠**不要伸出到走道上方或旁邊**，看起來要跟碰撞邊界一致。現在玩家「看起來還有空間，卻被擋住」，就會覺得卡住。
  - 碰撞是：格子邊界往內 0.35m 就算撞到。
- 景物（`CreateProp`）的外型也一樣，實心部分不要比 `radius` 大。

## 2. 湖改圓弧

湖的碰撞還是一格一格（`ExTerrain.Water` 格），但**看起來**要是自然的圓弧湖岸：

- `LakeSurface` 不要用每格一個正方形，改成沿著整片 Water 格的外框產生平滑的輪廓（例如 marching squares 加平滑，或每個凸角用半徑 1.5m 以上的圓弧）。
- 凸角要圓；凹進去的角也要用圓弧填順。不能看到 90° 直角或鋸齒。
- 湖岸（`Shore_*`、蘆葦、石頭）沿著圓弧輪廓排，不要排成直線。
- 水面可以比碰撞範圍**稍微往內縮**（最多 0.4m），讓岸邊的草和石頭蓋住格子的直線邊。
- 同樣的圓弧處理也適用在地圖其他「整片同一種地形」的邊緣（岩壁、洞窟），至少湖一定要做。

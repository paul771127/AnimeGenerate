本批只重製 kind 19–22。所有圖片由 Unity 原生渲染；不是概念圖、AI 圖或軟體模擬。

- `rare_19` 古根撼地獸、`rare_20` 潮鞭鰻、`rare_21` 鏈錘鬥奴、`rare_22` 裂岩甲蜥。

- `rare_before_after.jpg` 為新舊正面總覽；`rare_19_overview.jpg` 等為各自五視角總覽。

## 造型與效能

根獸的主體為九條交纏根束，帶樹皮稜線、根爪、枝角、掛藤及背上植物；鰻身／尾為連續曲線截面，腹部獨立淺色層、帆鰭雙面膜與鰭條；鬥奴為收腰肌肉軀幹、單肩甲、面具格柵與九枚交錯鐵環；甲蜥為低伏軀幹、十片背板、側面砂鱗、碎岩與發光裂縫。

幾何按種類／關節／色層快取。實心共用既有卡通描邊材質，發光沿用既有透明材質；鰻魚另共用一張執行時建立的 32×2 漸層貼圖，沒有匯入圖檔。沒有逐幀網格生成或材質複製。

## 原生驗證

執行 `SpellDuel.EditorTools.Snapshot.RenderRareMonsters`，或 GitHub Actions 的 `SpellDuel rare monster validation`。`rare_audit.json` 記錄模型（含帆鰭、光點等效果）的三角形數、Renderer 數、新舊包圍盒、快取、舊支點路徑、顏色登記與實際蓄力／受擊／死亡變色。

支點名稱與父子關係由編輯器內的舊版建構函式逐項比對。舊版檔案整份包在 UNITY_EDITOR，只在上述預覽時取用；遊戲執行使用新造型。模型中心與關節位置維持舊版，沒有改 Combat、碰撞半徑、數值或 SoloBattle。執行時的獨立接觸陰影另加 2 個三角形，仍在 4000 上限內。鏈錘及尾巴保留原來的視覺伸展範圍，不以伸展端點冒充角色碰撞半徑。

原生與雙平台證據會在本目錄的 native_ci.json、platform_ci.json 補齊。手機實機效能尚未量測。

19–22 使用已整合的專屬章節構件，因此不再額外套用舊通用項圈／圍巾；其他小怪的章節裝飾不變。原生流程包含正式的 SetDress 呼叫，避免只測裸模型。

交付後可執行 `python3 spellduel-unity/Tools/check_rare_monsters.py --require-mobile`，複查 42 張原生圖與原生／手機證據是否對應同一個程式版本。source_scope.json 列出本次美術提交；同時拉入的遠端玩法提交不屬於本次修改。

## 場地示意（俯視）

```text
                 敵人／固定射線來源
                         ↓
  校準邊界   ┌─────────────────────┐
             │      紅線 ║          │
             │   玩家 P ║ → S      │
             │          ║ 安全點   │
             └─────────────────────┘
  P→S ≤0.8m；危險線先按人體半徑膨脹；S也必須留在邊界內。
  若其他敵人的危險範圍蓋到S：延後／取消，而非再畫一個矛盾箭頭。
```

## 效果讀法與清理

- 跳／蹲有箭頭與時序，側步有危險邊框；即使看不清顏色仍可辨識。
- 雨、霧和粒子畫在提示之下；禁止相機全屏白閃／黑幕。震動是選配補助，不是唯一提示。
- 支援成功、被打斷、目標死亡、時間到、場景退出五條清理路徑都要驗證。
- 特效只消費已判定結果；身體、武器、假身、光環都不建立新的傷害判定。

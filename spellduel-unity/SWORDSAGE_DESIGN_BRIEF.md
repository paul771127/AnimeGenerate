# 劍仙設計 Brief（給 Codex）：外型、動作、技能表現

## 背景

劍士 30 級進階有兩個職業：**聖騎士**、**劍仙**。劍仙取代了原本的狂戰士，定位是「以氣御劍」的輸出職業，技能樹分三個流派：

- 輸出：劍來、御劍術、萬劍歸宗
- 防禦：劍罡護體
- 輔助：劍陣

遊戲規則已經寫好、可以玩，但外型、技能圖示、特效都還沿用狂戰士或預設樣子：

- 外型：刺刺頭、無袖皮夾克、紅色系。
- 圖示：預設光球。
- 飛劍：一般的投射物光球。

**請重新設計劍仙的外型、動作和技能表現**。要一眼看得出是「御劍飛行的劍仙」：

- 飄逸、清冷，以藍白、青色為主。
- 和聖騎士（金色重甲、盾）明顯不同。

## 不要動的地方

- **職業 id 維持 `berserker`**：存檔、外觀表都用這個 id。顯示名稱是「劍仙」（在 `Advanced.cs`）。
- **技能 id 不能改**：`jianlai`、`yujian`、`wanjian`、`jiangang`、`jianzhen`、`yj_blade`（御劍術射出的飛劍）。這些 id 寫在存檔、技能樹和語音辨識裡。
- **放招手勢不能改**（在 `HandGesture.cs`）：
  - 劍來：握拳→張開
  - 御劍術：往前推
  - 萬劍歸宗：往下壓
  - 劍罡護體、劍陣：握拳→張開
- **規則與數值不要改**：`Combat.cs`、`Skills.cs`、`Progression.cs` 的劍仙部分。只改外觀。
- **不要加外部資源**（圖片、模型檔），全部用程式產生，跟現有職業一樣。

## 設計方向（建議，可以發揮）

- **外型**：
  - 長袍或交領劍袍，配飄帶、束髮或長髮，可以加髮冠。
  - 背後或腰間掛劍鞘。
  - 不要重甲。
  - 武器是細長的直劍，可以帶淡淡的藍光。
- **動作**：
  - 站姿挺拔、輕盈。
  - 出招手勢偏指訣，例如劍指（食指、中指併攏）往前點出。
- **技能表現**：
  - 劍來：一把光劍在手中凝聚成形，持續期間劍身有流光。
  - 御劍術：飛劍從手邊連續射出，每把都有細長的殘影。
  - 萬劍歸宗：數把巨劍從空中直落，落地時有劍氣衝擊。
  - 劍罡護體：身體周圍環繞淡藍色的劍氣護罩。
  - 劍陣：數把小劍在角色周圍繞成圓陣，緩慢旋轉。
- **圖示**：五招各自一個圖示，風格和 `SkillIcons.cs` 現有的一致（用程式畫的徽章）。

# 主線：獻給黎明的三重奏
# 格式：spellduel-unity/STORY_FORMAT.md
# 三章各四關；每章依序涵蓋 1–3、4–6、7–9、10 波。
# 鐘舌、種子與歌聲皆為敘事元素，不要求額外的物品或操作。

[chapter 1] 第一章　不再報曉的鐘
炎之里的晨鐘啞了，沉睡山腹的守護者卻開始敲打大地。

[stage 1-1] 灰燼中的歸途
護住通往炎之里的山道，尋找失蹤的採礦隊。
theme = volcano
waves = 1-3
xp = 80
req = none
<before>
旁白：火山灰像遲來的雪，落在炎之里緊閉的窗前。
老焰：{玩家}，拜託你清出山道。採礦隊還沒回來。
艾琳（mage）：我也去。我是來抄錄古鐘銘文的，認得礦道上的路標。
老焰：看見一個戴紅頭巾的孩子，就把他拉回來。那是小鐵。
旁白：{玩家}說：「帶路吧。天黑以前，我們得讓大家回家。」
艾琳（mage）：等等，聽……那些小鬼的腳步，像在跟著什麼節拍。
<after>
旁白：最後一隻熔岩小鬼退入岩縫，礦工從避難洞裡探出頭。
小鐵：我才不是迷路！我在等師父……他的腿受傷了。
旁白：{玩家}說：「先扶他回去。還走得動的人，幫忙照顧傷員。」
艾琳（mage）：這塊銅片是晨鐘的碎片？你在哪裡找到的？
小鐵：赤爐礦道。鐘明明在村裡，碎片卻從山裡掉出來。

[stage 1-2] 赤爐的回音
沿著鐘片的痕跡進入礦道，查明震動的來源。
theme = volcano
waves = 4-6
xp = 120
req = 1-1
<before>
旁白：撤離的礦工已走遠，空礦車仍隨地底的震動輕輕搖晃。
艾琳（mage）：小鐵找到的不是鐘壁，是鐘舌。斷口還很新。
米菈：前幾天我見有人把它運上山。披著灰斗篷，推車上蓋著村長的布。
旁白：{玩家}說：「老焰知道這件事？」
艾琳（mage）：先找回鐘舌，再回去問他。礦道快被熔岩堵住了。
旁白：岩壁後響起三下悶聲，火焰射手抬起青白色的火球。
<after>
旁白：碎石下壓著半截鐘舌，旁邊是一副燒裂的舊手套。
艾琳（mage）：銘文是「火照路，木記名，潮送人歸」。三地的古鐘原是一套。
旁白：{玩家}說：「這手套上繡著「焰」……先把鐘舌帶回去。」
旁白：兩人回到炎之里。老焰看見手套，慢慢坐了下來。
老焰：是我拆的鐘。我以為只要讓它別響，那聲音就找不到這裡。

[stage 1-3] 守鐘人的謊言
穿過斷裂的祭道，阻止失控的熔岩流向村莊。
theme = volcano
waves = 7-9
xp = 180
req = 1-2
<before>
老焰：村裡的鐘只是回音鐘，真正的火之鐘在山腹。
老焰：每晚都有聲音從鐘裡傳來，叫著四十年前出海的人的名字。
老焰：我把鐘舌送回祭壇，求山神收走它。隔天，火山就醒了。
艾琳（mage）：祭壇的拓片也被你燒了？我只找到一角焦紙。
老焰：是。我只想讓孩子們安穩睡覺。可山下那條熔岩……是我害的。
旁白：{玩家}說：「帶大家撤到高處。等我們回來，你得把知道的事都說出來。」
小鐵：鐘舌接好了。裂口是師父補的，這次肯定敲得響。
艾琳（mage）：我帶鐘舌走祭道。{玩家}，請替我清出一條路。
<after>
旁白：祭道盡頭，熔岩被古老的石閘擋住，閘後有巨大的手印。
艾琳（mage）：不是巨像把熔岩推向村子……牠一直在擋。
旁白：{玩家}說：「可牠的手開始鬆了。」
熔岩巨像（boss）：鐘……歸位……不許……越過……
艾琳（mage）：黑色結晶卡在牠胸口。那不是這座火山的礦石。
旁白：{玩家}說：「牠快撐不住了。我們得先讓牠停下來。」

[stage 1-4] 熔岩巨像・最後的守門人

req = 1-3
<before>

熔岩巨像（boss）：守住……封印……連同……你們……
艾琳（mage）：牠把所有靠近的人都當成威脅了！
旁白：{玩家}說：「我會攔住牠。你把鐘舌送進祭壇的鐘架！」
艾琳（mage）：鐘架離得太近……好，等牠倒下的那一刻。
旁白：火光照亮巨像胸口，也照出黑晶中一道深藍的波紋。
<after>
旁白：巨像跪下，胸前黑晶碎裂。艾琳將鐘舌扣回山腹的鐘架。
旁白：晨鐘低鳴，石閘緩緩合攏，奔流的熔岩轉入地下。
熔岩巨像：木之鐘……還記得……去找……未被抹去的名字……
旁白：巨像伏成一座石丘，裂縫裡仍透著穩定的暖光。
旁白：回到村裡，老焰在鐘下等著，手中握著一張泛黃的船票。
老焰：我年幼時，見過一艘沒能回港的船。船名叫「白帆」。
老焰：那天以後，大人不准我們再唱送船的歌。我也照做了。
艾琳（mage）：老師的封印史裡沒有這艘船。我要去森之里查原始碑文。
旁白：{玩家}說：「先把採礦隊回來的消息敲給大家聽。這次，別再藏了。」

[chapter 2] 第二章　霧裡沒有寫完的名字
森之里的樹根存著舊日記憶，腐化卻正吞噬最後一份見證。

[stage 2-1] 借一盞葉燈
沿著獵人的葉燈進入霧林，打通聚落外的道路。
theme = forest
waves = 1-3
xp = 150
req = 1-4
<before>
旁白：森之里的屋簷掛滿葉燈，霧中卻沒有一聲鳥鳴。
翠：老焰的信送到了。可記名林已被毒花封住，連獵人也難以接近。
楓（archer）：跟著我的葉燈走，聞到甜香就掩住口鼻。
小葉：你們要去找樹王嗎？替我問問，牠還記不記得那個故事。
旁白：{玩家}說：「什麼故事？」
小葉：一艘小船載著星星出海。每次說到回家的地方，牠就不說了。
<after>
旁白：毒花垂下花囊，封路的藤蔓間露出一排刻字的小木牌。
艾琳（mage）：這是出海者的名牌？有些連年紀都刻著。
楓（archer）：不是祈福牌。這是森之里替沒回來的人留下的位置。
旁白：{玩家}說：「其中一塊掉了。先收好，別讓它被泥水沖走。」
艾琳（mage）：上面寫著「澪，領唱」。那首送船的歌，原來有領唱者。

[stage 2-2] 被刪去的那一頁
穿越盤踞記名林的藤蔓，尋找被掩藏的封印碑文。
theme = forest
waves = 4-6
xp = 200
req = 2-1
<before>
旁白：樹根將古碑纏成巨繭，碑頂刻著與三地鐘架相同的紋樣。
翠：四十年前，巨潮將至。三地約定敲響古鐘，把船引回港口。
艾琳（mage）：可教本說，三鐘是用來封住深海巨妖的。
翠：兩件事都發生了。只是後來的書，只留下其中一件。
旁白：{玩家}說：「那艘白帆號呢？」
翠：把碑文讀完吧。這一次，我不替先人遮住它。
<after>
旁白：藤蔓退開，露出一行被鑿傷的字：「引潮入淵，歸航之燈勿熄。」
翠：白帆號的歌聲把巨妖引離港口，守鐘人卻提前封死了歸路。
艾琳（mage）：他們把還在海上的人……一起關在裡面？
翠：是。有人說別無選擇，有人不肯聽呼救。最後，大家一起沉默。
艾琳（mage）：我還在炎之里，把「無人犧牲的封印」念給孩子們聽過。
旁白：{玩家}說：「現在知道了，就把真正的那一頁寫回去。」

[stage 2-3] 聽見樹心的人

楓（archer）：樹王不肯忘掉那些人，黑晶便從牠記著名字的地方長出來。
艾琳（mage）：如果燒掉記名林，也許能斷開侵蝕……
旁白：{玩家}說：「那麼等海平靜，又只剩下一本說沒人犧牲的書。」
艾琳（mage）：……對不起。我剛才只想著怎麼最快結束。
楓（archer）：帶上木牌。我替你們看住回程的路。
<after>

腐化樹王（boss）：不許……帶走……他們最後的名字……
旁白：{玩家}說：「我們帶來了一個。澪，白帆號的領唱者。」
旁白：一根枝條伸向木牌，又突然抽回，將祭壇擊得粉碎。
艾琳（mage）：牠聽到了，可黑晶還在逼牠攻擊。

[stage 2-4] 腐化樹王・記名之根

旁白：一顆未受腐化的種子，滾到那塊領唱者的名牌旁。
艾琳（mage）：你想讓我們把它帶去海邊？

艾琳（mage）：抄本交給你。我帶另一份去潮騷港，找那首歌的結尾。
旁白：{玩家}說：「也替小葉留一份。等樹王醒來，換她說故事給牠聽。」

[chapter 3] 第三章　願所有歌聲抵達黎明
潮騷港的舊燈塔面向無人的海；一首未唱完的歸航曲，等了四十年。

[stage 3-1] 沒有船的潮聲
清出港外礁岸，為重亮舊燈塔尋找登礁的路。
theme = sea
waves = 1-3
xp = 180
req = 2-4
<before>
旁白：潮騷港的船全繫在岸邊。浪聲傳來時，繩索卻一起朝海面繃緊。
海斗：我收到了翠的抄本。白帆號的船長，是我祖父。
艾琳（mage）：你知道他們被封在外海？
海斗：以前不知道。家裡只留下一張航圖，和半首不准在港邊唱的歌。
阿潮：先上礁岸吧。舊燈塔的路被海怪堵了，我帶你們走退潮道。
旁白：{玩家}說：「那就從那盞沒亮的燈開始。」
<after>
旁白：礁池裡的跳躍魚散去，一枚刻著「白帆」的銅扣卡在石縫間。
海斗：和航圖上的記號一樣。沉船就在燈塔正前方。
艾琳（mage）：種子朝那邊發芽了……木之鐘的聲音還在它裡面。
阿潮：這條路下次漲潮就會淹。要去燈塔，趁現在。
旁白：{玩家}說：「走吧。這次不能再讓歸航的人看不見岸。」

[stage 3-2] 留在酒館的半首歌

waves = 4-6

req = 3-1
<before>

海斗：你怎麼知道我們要去舊塔？
凪：你祖母每年都坐在酒館窗邊，朝那裡唱同一首歌。
艾琳（mage）：你記得歌詞嗎？
凪：後半首，我母親教過我。「岸有燈，杯有茶，你的名字有人答。」
旁白：{玩家}說：「那盞燈，我們送得到。」
<after>
旁白：燈塔的門終於推開。海斗轉動鏽輪，燈光越過外海的黑浪。
海斗：我祖父出航時，我父親還沒出生。他一直想知道自己該恨誰。
艾琳（mage）：我不知道這首歌能不能讓他們原諒我們。
旁白：{玩家}說：「先讓他們知道，我們聽見了。」
旁白：海斗輕聲唱出後半首。遠處浪間，傳來一個女人的歌聲。
澪：岸上的燈……是給我們的嗎？

[stage 3-3] 白帆歸來的方向
沿燈光走向沉船礁，讓被怨聲吞沒的歌抵達岸邊。
theme = sea

艾琳（mage）：老焰拆鐘，是因為聽見你們；我們卻又讓你們等了一次。

深海巨妖（boss）：他們關過一次門，就會再關一次！你們回不去了！

[stage 3-4] 深海巨妖・黎明的三重奏
迎戰吞噬歸航曲的巨妖，為白帆號守住最後一段航路。
theme = sea
waves = 10
xp = 500
req = 3-3
<before>

深海巨妖（boss）：再獻一個活人的聲音，我便讓你們的港口平安！
艾琳（mage）：如果只要一個人……

海斗：你的名字有人答。澪，還有白帆號上的大家，歡迎回來。

艾琳（mage）：我們還沒問，他們願不願意原諒。
旁白：{玩家}說：「那不是我們能替他們寫的結局。把發生過的事留下來吧。」
旁白：入春後，炎之里的晨鐘重新報時。老焰在鐘下講起白帆號。
旁白：森之里多了一排新木牌。小葉坐在樹王身旁，念著還不熟悉的名字。
旁白：潮騷港的酒館添了一壺熱茶，門外立起完整的歸航者名碑。

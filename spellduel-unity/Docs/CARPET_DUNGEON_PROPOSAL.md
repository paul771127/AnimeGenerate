# 天穹飛毯副本設計提案

狀態：待使用者確認；2026-10-28。依 `CODEX_TASK_CARPET_PETS.md` 第 A 部分。這輪僅交設計，不新增場景、模型、圖示、腳本或 dungeons 資料。所有數值是初版調校建議，非已實作功能。示意內嵌於本文件；下一輪確認後的圖稿放 `Docs/pending_preview/carpet/`。

## 體驗與美術方向

副本暫名「天穹航路・逐風奪舵」，提案 id `sky_carpet`，建議 Lv30、1～4 人、通關 3-6 後開放。空賊截走港口的航路羅盤，{玩家} 搭飛毯穿越浮島追回；獨立支線，不改寫白帆號與晨鐘主線結局。

飛毯是酒紅織面、象牙色航線紋、青綠外緣、金線流蘇。所有花紋都代表航路、四角繫帶或加固縫線。敵人另設全新骨架、模型、動作與配色組合，不拿現有怪物、Boss 或場景換皮。沿用 Village2D 的溫暖幻想建築、Story2D 的乾淨動畫造型，以及 Supplies 圖示的深藍黑外輪廓、兩階明暗、大色面與少量奶油色高光。

                        ↓
       左載具 → ┌── 飛毯前緣預警 ──┐ ← 右載具
                │ 左安全點 中 右安全點 │
                │      玩家活動區      │
                └──── 校準邊界 ─────┘
             景物沿 -Z 後退，玩家地板不移動

以開戰面向鎖定前方，不跟隨轉頭旋轉。可用寬 W、深 D 都取校準場地扣除邊緣 0.2m 後的範圍；不擴大真實可走區。側步目的點為中心左右各 min(0.4m, W/4)，兩端移動最多 0.8m。缺口包住目的點，寬至少 0.65m；場地不足以容納兩個不同安全區時，不發側步／缺口題，改發跳蹲題並提示小場地模式（需 Claude 接）。不要求向前衝刺或走出校準範圍。

## 五站流程

時間為目標戰鬥時間，不含校準、讀取、對話；前四站完成遭遇後才切站，超時暫停增援，不能以計時跳過敵人。Boss 時間為估計，必須擊倒才通關。障礙比例按「低／高／半邊／缺口」計算，次數是整個可躲序列，不是彈丸數。

|---|---|---|---|---|

| 2 懸鏈浮島 | 90秒 | 每6秒1次，30/30/40/0 | 4波：盜賊2、騎兵1、魔偶1、盜賊1＋魔偶1 | 青綠浮島、斷橋與懸鏈，中景起伏 |
| 3 風蝕天隘 | 100秒 | 每5.5秒1次，20/20/30/30 | 4波：滑翔翼兵2、翼兵2、騎兵1＋翼兵1、魔偶1＋翼兵2 | 赭紅窄峽谷、青色天空裂縫，壁面快速後退 |

排程硬限制：同種跳或蹲的有效抵達時刻至少隔1.5秒；不同姿勢之間也建議至少1.5秒。禁止同時要求跳與蹲、左右互斥安全區、落點覆蓋唯一缺口。密度提升靠視覺彈數，不突破動作間隔。

## Boss「逐風號」

新設計寬船首、雙層黃銅砲門、短胖紅白氣囊、可見小型甲板人物與側跳台，不能借現有 Boss。建議26H0；船寬約8m、長12m，常態距前緣10～14m。面向一直朝飛毯；遠程可全程命中。接觸窗口以船首低位錨台作近戰命中部位，避免要求玩家走出邊界。

| 招式 | 預警與表演 | 躲法 | 傷害／間隔 |
|---|---|---|---|
| 掠地砲列 | 下排砲蓋掀開、橘光蓄1.8秒，扁圓彈拖兩條橘尾 | 跳 | 0.9D0；四招輪替，每5秒一次 |
| 橫空雷索 | 上排兩砲張開、藍線連接1.8秒，長菱形彈藍尾 | 蹲 | 0.9D0；同上 |
| 舷側封鎖 | 左或右砲組轉向2秒，半毯斜紋 | 側步 | 1.1D0；同上 |
| 航道封門 | 整排砲門亮2.2秒，安全砲門保持關閉、對應綠框 | 站缺口 | 1.1D0；同上 |

每24秒壓低一次，前2秒以金色錨印與「靠近了，快打！」提示，停3.5秒；錨台到前緣內側可及距離。進入與退出各1.5秒。窗口中停止大招與新登毯，已上場敵人保留；不以後續彈幕封死近戰輸出。遠程同樣可打錨台，但不另加雙重傷害。

50%HP 進二階：側煙囪冒煙、所有前砲門展開，砲座後座→退殼火星→回正。每6秒彈幕組含 t=0、1.8、3.6秒三個子波，各子波只能要求一種高度動作，左右彈列保留可行安全區。三輪漸進為每子波4／6／8枚，飛行展示速度10／12／14m/s，仍提前至少1.8秒給提示；達上限不再加密。高低前後錯開，不把兩種互斥動作放在同一接觸時刻。每組最後2.4秒可安排一名登毯；撞到同一子波最多結算一次建議由 Claude 保證。近戰窗口優先，延後彈幕而非補射。

死亡：砲門熄火→船首傾斜下墜→分段爆炸→煙幕裂出亮航道→飛毯穿出。表演約5秒，停止判定與增援，無全螢幕強閃；獎勵只結算一次。

## 場景、速度與手機預算

飛毯布面中央基本穩定，角與流蘇隨速度增加擺幅，不移動玩家碰撞面。近景雲絮／羽片／碎石移速1倍，中景島／岩柱0.35倍，遠景地平線0.02倍。三層不是複用舊關卡場景。常態展示速度12m/s、衝刺18、近戰靠近6（均建議），與物理安全區無關。

`CarpetScene.Speed` 只控制視覺後退與風線密度；不可偷偷改判定時間。預計由 Claude 傳場景站別、速度、障礙種類／位置／進度、載具進度、Boss狀態。`Create`、`SetVariant`、`ObstacleView` 為需求介面名稱提案，本輪沒有新增 API。

預算目標：池化近景24、中景12、遠景6；同時實體障礙4、載具3、小怪3。新小怪每隻≤6000三角、載具≤4000、Boss≤18000、場景可見≤60000；共用材質／網格，效果粒子總上限256。優先風線代替徑向模糊；不新增即時反射或後處理。60fps是中階手機驗收目標，尚未量測。下一輪須測Android/iOS、AR開啟時CPU/GPU幀時與透明疊層，低效能先降景物與粒子，不能減預警可見度。

每顆只一項效果；禁止普攻集氣加速、閃避率、爆擊率。掉落率按本次 brief 建議，不改現有精魄掉率。新條件用「新效果」標明，不能宣稱 SoulOp 已支援。

|---|---|---|---|---|
| 風箏盜賊・逐風結 | 飾品 | 成功側步閃過標記障礙後，技能冷卻恢復速度＋10%，3秒，內冷8秒（新效果） | 0.5% | 紅繩風結包青色晶核 |

效果不要求更快真實移動；成功躲避以一次攻擊序列為觸發單位，不能每枚彈重複獲益。多人各自判斷、房主結算；同效果多孔不疊加觸發，只取最高值的提案需 Claude 確認。

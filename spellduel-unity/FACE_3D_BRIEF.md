# 3D 人物臉部立體化：《絕區零》風格（給 Codex）

## 使用者的要求

人物的臉要更有立體感。現在看起來像一顆球，希望風格類似《絕區零》（Zenless Zone Zero）。

請先**分析該怎麼做**，再動手實作。分析寫在本檔最後的「Codex 分析」段落，跟程式一起提交。

## 《絕區零》風格的重點（請分析並落實到程式）

下面是方向，請自己研究判斷，可以補充或修正。

1. **頭骨與臉的形狀**：不要是球。
   - 後腦勺圓、臉部是一個比較平的面。
   - 下巴是尖的 V 形，有明確的下顎線。顴骨有轉折面。
   - 側面看時，額頭到鼻尖到下巴有清楚的輪廓：鼻梁微微隆起，嘴的部位往後收。
2. **臉部陰影要乾淨、像手繪**：不能是球面法線算出來的圓形色塊。
   - 業界常見的做法是「臉部 SDF 陰影圖」：依光源方向取門檻，得到鼻子下方、臉頰側邊等形狀固定的陰影。另一種是修改臉部法線，把法線轉移成接近平面或橢球。
   - 請選一個在手機上做得到的方法。只能用程式產生貼圖或頂點資料，**不能用圖檔**。
3. **眼睛**：
   - 大而細緻，是畫出來的眼睛，不是小球：有上眼線（粗）、虹膜漸層、多個高光。
   - 要貼合臉的曲面，從斜側面看也不能穿出臉外。
4. **鼻子和嘴極簡**：
   - 鼻子只用鼻尖的小陰影或高光表現。
   - 嘴是短線；張嘴時才出現形狀。
5. **外框**：
   - 臉的內側和下巴，外框要細，甚至不畫；頭髮和身體的外框比較粗。可以用頂點色控制外框粗細。
   - 外框顏色不要純黑，改用各部位底色的深色版本。
6. **頭髮**：
   - 要有成束的塊狀體積，加一條「天使環」高光。
   - 瀏海在額頭投下一條陰影帶，這是臉看起來立體的關鍵之一。
7. **皮膚的暗部偏暖粉色**：不要和衣服一樣偏藍紫。邊緣亮光要乾淨明亮。
8. **比例**：《絕區零》比較接近真人頭身，約 6.5～7 頭身。目前的頭身比例請評估要不要調，但不能影響戰鬥判定（見下面的限制）。

## 限制（一定要遵守）

- **純程式繪製**：可以在執行時產生 `Texture2D`、Mesh、頂點色，不能加入圖檔或模型檔。
- **手機效能**：
  - 一個角色的三角形數，在目前的基礎上最多增加 50%。
  - 場上最多 6 個角色加上 Boss，不能明顯掉幀。
  - Shader 要能在 iOS（Metal）和 Android（OpenGL ES 3／Vulkan）上跑。
- **不能改遊戲邏輯**：
  - `CharacterRig` 的公開 API 不能改：`Create`、`SetPose`、`PlayCast`、`PlayHit`、`SetDead`、`SetVisible`、`MoveSpeed`、`Charge`、`Guarding`、`ClassId`、`AdvancedId`。
  - 眨眼、張嘴（`mouthOpen`）、受擊和施法動畫要照常運作。
  - 角色站立高度、腳底位置不能變，戰鬥的身體判定是用玩家位置算的。
- **保留每個角色的個性**：
  - 上一輪 `CHARACTER_PERSONA_BRIEF.md` 做的臉型、眼神、眉型、嘴型差異要保留，換成新風格之後依然看得出誰是誰。
  - 包含 5 個基本職業、10 個進階職業、城鎮居民、2D 頭像。
- **全域風格參數**：其他物件（小怪、Boss、城鎮）也共用 `SpellDuel/Toon`。臉部的特殊處理請用獨立的 shader 或材質關鍵字，不要讓 Boss 和小怪的外觀變掉。
- 程式註解用繁體中文，風格跟周圍的程式一致。

## Codex 分析

### 風格拆解與取捨

參考 [《絕區零》官方角色展示](https://zenless.hoyoverse.com/en-us/main) 的視覺方向：重點是清晰的剪影、成束頭髮、平整臉面上的圖形化明暗，以及能從側面讀懂的鼻尖／唇部／下顎輪廓。以下是本專案的美術轉譯，並非對官方未公開技術的推定。

目前球形頭模和凸出眼球會互相強化「圓球貼五官」的印象，只換配色或加鼻子不夠。改用明確分層的截面頭模：保留後腦體積，前額與雙頰形成較平面，顴骨後收、下顎折向 V 形下巴；鼻梁與鼻尖直接融入頭模，嘴周往後收。沿用 Persona 的寬度、下顎、長度及表情參數，不把所有人做成同一個尖下巴。

### 實作方案

- 新增共用程序臉部工具，供戰鬥角色與居民使用同一頭型、貼合曲面的眼線／虹膜／眉嘴。眼睛用曲面薄片與頂點漸層，取代小球；保留 eyePaint、UpperLid、mouthOpen 動畫樞紐。
- 在既有 Toon 增加 **SD_HUMAN 本地材質變體**，預設變體的屬性名稱與運算維持原樣。人類材質才啟用暖膚陰影、部位深色描邊；臉部由頭部朝向與主光方向計算解析式遮罩，UV 定義側頰、鼻下和瀏海陰影，不讀取圖檔、不新增逐幀貼圖或額外陰影攝影機。
- 頭模頂點色 R 控制描邊（下巴／前臉較細），G 區分前臉；眼睛薄片用頂點色漸層與無描邊材質。輪廓仍用幾何法線，陰影不再使用球面 N·L 畫圓斑。
- 居民頭部與軀幹分組合批，讓頭部轉向後，解析陰影仍跟隨正確的臉部座標；保留現有呼吸與配件、髮色和各人姿勢。
- 頭髮補上有前脊的程序髮束與斷續高光帶，避免整顆圓帽式頭髮；不替換職業裝備。2D 頭像同步加入顴骨、V 形下顎、暖色側頰和瀏海陰影，保留角色服裝及表情；怪物頭像不套用人類處理。
- 不改骨架高度、腳底或判定。現有成年角色約 5.5 頭身，這次保留尺寸，優先改善臉面與材質，避免直接縮頭造成頭盔、面罩、飾品及動作對不齊；輪廓以較明確的下顎與頸部銜接呈現修長感。

### 效能與驗證計畫

原頭模約 952 三角形，改用約 500～600 三角形截面網格；曲面眼片每層約 16～24 三角形，取代多顆 80 三角形小球。髮束與高光預算約 200～400 三角形，整體應接近或低於現況；逐職業比較實測，不允許超過原本 1.5 倍。網格與材質依角色／顏色快取，不在 Update 建立。

維持 **2 個 Pass：本體＋描邊**，不增加深度或投影 Pass、不新增貼圖取樣；人類變體使用頂點資料和少量算術。對 6 個角色檢查三角形、Renderer 數與材質快取；這是靜態成本估計，實際 Metal／GLES3／Vulkan 幀率與著色器編譯仍須 Unity 裝置建置確認。測試將覆蓋公開介面、施法張嘴、受擊瞇眼／閃白、倒地、頭部正側面與居民合批。


### 實作後檢查結果

- 共用頭模為 576 三角形；髮束與天使環合成兩個 Renderer。眼片與曲面線取樣實際三角面，避免理想曲面與低面數網格的差距讓眉嘴陷入皮膚。
- 15 個職業（含隱藏動畫部件）的總三角形數：劍士 6772→5408、獵人 6272→4908、法師 6292→4928、刺客 5660→4296、牧師 8116→6752；聖騎士 7496→6132、狂戰士 6528→5108、神射手 6380→5016、遊俠 6856→5436、大魔導士 6512→5148、召喚師 6672→5252、忍者 5964→4600、影舞者 6036→4672、主教 8416→7052、審判者 7228→5864。每個職業的可見 Renderer 比原本少 2 個。
- 12 位居民合批後為 3668～4316 三角形、13～17 個 Renderer，全部低於各自舊版三角形數。頭部與身體分批，但保留姿勢、呼吸與配件。
- 以 Unity API 測試替身編譯實際 C# 原始碼，檢查全部職業及居民的網格索引、有限座標、法線、50% 上限；施法張嘴、受擊瞇眼／閃白與恢復、移動、防禦、倒地及舊版 Create 呼叫均通過。重複建立 6 個相同職業，臉部網格／材質快取數不增加。
- 原始碼比對確認公開操作及所有動畫方法不變；Toon 未啟用 SD_HUMAN 時的運算與原版一致。三章 Boss 頭像及海妖別名逐像素一致，Boss／小怪外觀原始碼未改。
- 本體與外框各一個 Pass；眼片／眉嘴／高光仍用既有 Sprites/Default 的單 Pass。Shader 指定 target 3.0，使用既有建置已保留的 Toon 與 multi_compile_local 變體，不新增圖片、模型或 shader 資源依賴。
- 已檢視正面、斜側與側面程序網格投影。以上不是 Unity Editor／真機的渲染與效能測試；目前環境無 Unity Editor，Metal／GLES3／Vulkan 著色器編譯及實際幀率交由後續 Unity 建置確認。

### 目標比例（以頭高 H、眼睛中心到下巴的距離 D 表示）

請以下面這組比例為**基準**，再依個性做小幅偏移：

- **眼睛中心高度**：從頭頂往下約 0.46H，現在的 y≈0.013 可以保留。
- **眼睛寬度**：約為臉寬（太陽穴之間）的 20～22%，也就是 0.054～0.060。眼高約為眼寬的 0.6～0.7。
- **兩眼間距**：內眼角之間約一個眼寬。眼睛中心大約在 x=±0.056。
- **眉毛**：在眼睛上緣再往上約 0.6 個眼高。長度約 1.1 個眼寬，內側端在內眼角正上方，傾斜不超過 ±15°。
- **鼻底（鼻尖下緣）**：在眼睛中心往下 0.50D，y≈−0.072。
- **嘴（中線）**：在眼睛中心往下 0.68～0.72D，y≈−0.106。嘴寬約等於兩瞳孔間距的 0.55 倍。
- **下巴**：嘴到下巴底約 0.3D。下巴底部寬度約等於嘴寬，V 形下顎從嘴角高度的下顎角往下收。
- **耳朵**：上緣與眉毛同高，下緣與鼻底同高，位置在頭寬側面、頭部前後中線稍微往後。
- **顴骨最寬處**：在眼睛高度略下方。
- **側面**：
  - 額頭微微後傾。眼睛在眉骨平面後方約 0.008。
  - 鼻尖比臉平面突出約 0.02。嘴唇往後收。
  - 下巴在下唇正下方，不能往後縮，也不能往前戽。
- **脖子**：寬約頭寬的 45%，接在下巴中心偏後的位置，不是正對下巴。
- **頭身**：保留約 5.5 頭身沒關係，但臉的比例一定要先對。

### 個性化參數要收斂（避免「不像人類」）

- Eye 縮放範圍：0.85～1.15。眼神差異改用眼型、眼皮遮蓋、瞳孔大小、上眼線形狀來做，不要靠整顆眼睛縮放。

- 頭部姿勢 Pitch／Yaw／Roll：±6° 以內。個性用身體姿勢和表情表現。

## 第三輪修正：眼睛與髮型（使用者回饋）

> 比例有好一點了。再來改髮型跟眼睛：眼睛本身的畫法很奇怪，而且現在幾乎每個人的眼睛都長一樣。

我看過 `Docs/face_preview/` 的圖（劍士、牧師、刺客、法師），問題如下。

### 眼睛：現在的問題

1. **畫法像「描邊的橄欖球」**：眼白是一個完整的橢圓，四周一圈細黑線，虹膜是一顆小圓放在中央。動畫眼睛不是這樣畫的。
2. **虹膜太小**：只佔眼高的一半，眼白露太多，看起來呆滯、驚嚇。
3. **上眼線太細**：上眼線和下眼線幾乎一樣粗，缺少動畫眼睛最重要的「粗上眼線＋眼尾」。
4. **每個人都一樣**：眼型、眼線、虹膜大小、高光位置全部相同，只差顏色。

### 眼睛：《絕區零》式畫法（每一隻眼睛都要照這個結構）

由後往前疊：

1. **眼白**：
   - 不要整圈描邊，上緣直接被上眼線蓋住。
   - 上方 1/3 有一條上眼皮投下的淡藍灰陰影。
2. **虹膜**：
   - 大且偏高的橢圓，寬約為眼寬的 45～55%，高約為眼高的 90～110%。
   - 上緣被上眼線切掉一截，這是「有神」的關鍵。
   - 漸層：上方深（接近眼線色），下方亮（虹膜色＋提亮），加一圈較深的外環。
   - 下方 1/3 可以有一道月牙形反光。
3. **瞳孔**：
   - 直的橢圓，約為虹膜寬的 35～45%。
   - 偏上，因為上半部被眼線陰影融合。
4. **高光**：
   - 一大一小：大的在虹膜左上（跟主光方向一致），小的在右下。
   - 兩眼的高光位置要一致（同一個光源），不要鏡像。
5. **上眼線**（最重要）：
   - 粗，約為眼高的 18～25%，形狀是「中間粗、兩端收尖」的一道弧。
   - 外眼角有往外延伸的眼尾，可以上挑或下垂。
   - 內眼角收細。
   - 顏色是深棕或深紫，不要純黑。
6. **下眼線**：
   - 只畫外側 1/3～1/2 的一小段，細、淡，不要和上眼線連成一圈。
7. **雙眼皮線**（選用）：上眼線上方一條細短線，表現成熟、溫柔的角色。
8. **眨眼和瞇眼**：
   - 眨眼時上眼線往下蓋，虹膜和眼白跟著被遮。
   - 現有的 `UpperLid` 和眨眼動畫要繼續能用。

3D 角色要做到這個效果，可以把眼睛畫成一張程式產生的小 `Texture2D`，依角色快取，貼在貼合臉部曲面的薄片上。這樣比現在用好幾層頂點色薄片疊起來容易做出筆觸。效能請自行評估。2D 頭像用同一套畫法。

### 眼睛：每個角色要不一樣

建立一個「眼型」類型表，每個角色從裡面選一種，再搭配不同的虹膜色和瞳孔大小。至少要有這 8 種：

| 眼型 | 特徵 | 適合 |
|---|---|---|
| 吊眼（つり目） | 眼尾上挑、上眼線外側加粗 | 自信、好勝、高傲 |
| 垂眼（たれ目） | 眼尾下垂、虹膜偏下 | 溫柔、膽小、慵懶 |
| 杏眼 | 標準杏仁形，最平衡 | 主角型、開朗 |
| 圓眼 | 眼高較大、虹膜大、高光大 | 天真、活潑 |
| 細長眼 | 眼高小、上眼線平直 | 冷靜、精明 |
| 半閉眼 | 上眼皮蓋住虹膜上方 40% | 慵懶、看穿一切、不屑 |
| 銳眼 | 瞳孔小、虹膜小、下眼線明顯 | 兇狠、殺手、戰士 |
| 下三白／上三白 | 虹膜偏上或偏下，露出較多眼白 | 狡猾、瘋狂、反派 |

- 在本檔列出「角色 → 眼型、虹膜色、瞳孔大小、眼尾方向」對照表，涵蓋 15 個職業和 12 位居民。
- 同一個畫面常同時出現的角色（5 個基本職業之間、同一個城鎮的居民之間），眼型不能重複。

### 髮型：現在的問題

1. **髮束像紙板三角錐**：瀏海是 6 片一樣的扁平三角形，平均排在額頭前方，翹起來跟臉沒有貼合，看起來像王冠或鋸齒。
2. **沒有頭髮的體積**：頭頂、側面、後腦不是平面頭罩，就是被帽子蓋住。髮際線也看不出來。
3. **每個人髮型都一樣**：只差顏色。
4. **額頭陰影是一條直帶**：沒有跟著瀏海髮尖的形狀走。

### 髮型：《絕區零》式做法

1. **頭髮外殼**：
   - 先做一個比頭骨大約 6～10% 的髮量外殼，蓋住頭頂、側面和後腦。
   - 前緣是髮際線（額頭上方、太陽穴往後彎）。
   - 外殼要有幾道大分線和髮旋，不是光滑球面。
2. **瀏海**：
   - 用彎曲、有厚度的髮束（截面是扁的月牙形），順著額頭曲面往下彎，尖端收細。
   - 長短不一，有層次（前面一層、後面一層），不是 6 片等長。
   - 要有明確的分線方向：中分、旁分、斜瀏海、齊瀏海、往後梳。
3. **側髮**：臉兩側要有包住臉頰的髮束，長度到顴骨、下巴或肩膀，用來修飾臉型。
4. **後髮**：依髮型做短髮、及肩、長髮、馬尾、雙馬尾、包頭、辮子。
5. **著色**：
   - 髮根到髮尾的漸層（髮根略深）。
   - 一條沿著頭型彎曲、斷續的天使環高光。
   - 暗部偏髮色的深色版本。
6. **額頭陰影**：要沿著瀏海髮尖的鋸齒形狀投影，不是直帶。
7. **帽子、頭盔、頭巾**：戴帽子的職業，帽緣下面也要露出瀏海和側髮，帽子是戴在頭髮上面的。

### 髮型：每個角色要不一樣

和眼型一樣，在本檔列出「角色 → 髮型、分線、長度、髮色」對照表。至少包含這幾種髮型：

- 短碎髮
- 刺蝟頭
- 旁分短髮
- 鮑伯頭
- 齊瀏海長直髮
- 高馬尾
- 低馬尾
- 雙馬尾
- 包頭
- 後梳油頭
- 狼尾
- 光頭或極短髮（年長、剛毅型）

5 個基本職業之間、同一個城鎮的居民之間，髮型不能重複，**剪影就要分得出是誰**。

## 第三輪結果：眼睛與髮型（2026-10-18）

### 實作與維持的比例

保留第二輪 `FacePlan`、頭模截面、鼻嘴／耳廓位置及 Persona 比例表。`CharacterLook.cs` 集中 8 種眼型、14 種髮型家族與各角色的虹膜／瞳孔／眼尾／分線／長度／髮色；戰鬥角色、居民及頭像讀取同一張表。五個基本職業、每座城鎮的三位居民，眼型和髮型皆不重複。

眼睛由 `EyeArt` 以 2×2 子像素抗鋸齒產生，兩眼合為 256×96 RGBA 圖集，再貼到貼合 `Surface()` 的曲面眼片。上眼線加粗、外眼尾收尖，眼白上方淡藍灰，偏高的大虹膜被上緣切開，虹膜上暗下亮並有深色外環／月牙反光，瞳孔直橢圓；兩眼大高光都位於畫面左上，小高光在右下。下眼線只保留外側短段。半閉眼及三白眼改變虹膜的露出方式，不改眼片的基準位置。

## 第四輪修正：髮型與服飾（使用者回饋）

> 眼睛還可以，但髮型與服飾跟《絕區零》差太多了。

**眼睛維持第三輪的做法，不要再動。** 這一輪只改**髮型**和**服飾**，範圍是全身。

### 我看預覽圖發現的問題

**髮型：**
1. 短髮角色的剪影幾乎都是一顆圓球。法師、聖騎士、主教、審判者、老焰、海斗、阿潮、鐵匠、公會長只看剪影完全分不出來。
2. 髮束數量少、形狀單調，大多是扁平的三角片或硬塊。看不出《絕區零》那種「一束一束、有弧度、髮尾收尖、互相交疊」的髮束。
3. 頭頂沒有蓬鬆的分量，髮量外殼貼在頭骨上。
4. 頭髮的明暗只有一兩階，沒有大塊的暗部形狀，看起來像塑膠帽。

**服飾：**
1. 全身大多還是 Unity 原生的方塊、圓柱、球（`CharacterRig.cs` 裡有 124 處 `PrimitiveType`）。肩甲是好幾層方塊疊起來，手腳是粗細均勻的圓柱，看起來像積木。
2. **頭部配件擋在臉前面**：劍士的藍色、聖騎士的白色「T 字形」頭帶／護鼻，從額頭一路蓋到鼻子，像臉上貼了一條膠帶。要嘛做成真的頭盔護鼻（有厚度、貼合頭型），要嘛拿掉。
3. 衣服沒有布料的感覺：沒有皺褶、下擺、層次、滾邊、縫線。顏色是大片單色塊。
4. 每個職業的輪廓差異主要靠武器，衣服本身的剪影太像。

### 《絕區零》服飾設計的重點（請研究官方角色立繪與 3D 模型）

1. **輪廓清楚、有層次**：
   - 外套、內搭、配件分成好幾層，每層有明確的邊緣和厚度。
   - 例如短夾克加長下擺、高領內搭、寬鬆袖口配緊身手套。
2. **不對稱設計**：單邊肩甲、單邊長手套、斜背帶、一隻褲管捲起、側邊垂下的布條或腰帶。
3. **配色規則**：
   - 一個主色（約 60%）、一個輔色（30%）、一個點綴色（10%）。
   - 點綴色用在滾邊、拉鍊、扣環、發光線條。
4. **細節線條**：
   - 滾邊、縫線、口袋、拉鍊、皮帶扣、鉚釘、徽章、條紋、號碼或標誌。
   - 可以用程式產生的小貼圖（`Texture2D`）或頂點色來畫。
5. **布料形狀**：
   - 袖子和褲管有寬窄變化，例如上寬下窄、袖口反摺。
   - 下擺、披風、圍巾、長布條有下垂的弧度和尖角。
   - 布料轉折處要有大塊的暗部形狀，用來表現皺褶。
6. **身體比例與線條**：
   - 四肢要有粗細變化，例如大腿到膝蓋收窄、小腿到腳踝收窄、上臂到手肘收窄。
   - 軀幹有胸、腰的收放。不要用粗細一致的圓柱。
7. **鞋子和手套**：是設計的重點之一。可以做厚底靴、高筒靴、運動鞋、露指手套、護腕。
8. **奇幻職業要融入《絕區零》的潮流感**：
   - 劍士：機能風外套＋輕裝甲片。
   - 法師：寬大連帽外套＋發光符文線條。
   - 獵人：戰術背心＋箭袋背帶。
   - 刺客：高領緊身衣＋圍巾＋綁帶。
   - 牧師：白色長外套＋金色滾邊＋聖徽。
   - 進階職業依此類推，把幻想職業做成「有街頭感的現代戰鬥服」。

### 髮型做法

1. **髮束用掃掠網格（sweep mesh）**：沿著一條曲線掃一個扁平的截面（月牙形或扁橢圓），從髮根往髮尾逐漸收細，可以彎曲、扭轉。每個髮型用 20～40 束組合，長短、角度、粗細都不一樣，互相交疊。
2. **頭頂要有分量**：髮量外殼比頭骨大 10～15%，頭頂往上蓬。分線處要有凹陷。
3. **短髮也要有特色**，剪影要分得出來：
   - 翹起的呆毛
   - 外翹的髮尾
   - 側邊推短（undercut）
   - 往後梳的高度
   - 一側長、一側短
   - 蓋住一隻眼睛的長瀏海
   - 耳後的小辮子
   - 髮夾、髮帶等飾品
4. **明暗**：
   - 至少三階：亮部、暗部、最深的內側或下層。
   - 天使環高光要斷續，並跟著髮束走。
   - 髮束之間交疊處要有陰影。
5. **髮色**：可以有挑染、漸層、髮尾變色，各角色不同。

### 預算（放寬）

- **每個角色的三角形數**：上限調為第一輪之前原版的 **2 倍**。現在比原版少約 20%，所以空間不少。
  - 頭髮可用 1500～3000 三角形。
  - 服飾可用原版的 1.5 倍。
- **效能**：場上 6 個角色加 Boss，要維持手機流暢。Renderer 盡量合併，相同材質合批。
- **素材**：仍然純程式繪製，可以產生 `Texture2D`。不能用圖檔或模型檔。

### 驗證方式

1. **全身三視圖**：每個職業和居民都要正面、3/4 側、背面。放在 `Docs/outfit_preview/`。
2. **全員並排總覽**：
   - 一張全身彩色並排圖。
   - 一張全身剪影並排圖，只看剪影就要分得出每個人。
3. **頭髮剪影總覽**：重新輸出，短髮角色也要分得出來。
4. 在本檔補寫「第四輪結果」：
   - 每個職業的服飾設計說明：主色、輔色、點綴色、層次、不對稱元素。
   - 每個角色的髮型說明。
   - 三角形數、Renderer 數。

### 不變的限制

- 不改 `CharacterRig` 公開 API 與遊戲邏輯。
- 動畫要照常運作：施法、受擊、倒地、防禦、走路、張嘴、眨眼。
- 角色腳底位置與身高不變，戰鬥判定不受影響。
- 武器要繼續握在手上，跟著手部動畫。
- 不影響 Boss 和小怪。
- 3D 戰鬥角色、城鎮居民、2D 頭像三處一致。頭像也要更新髮型和衣領。
- 眼睛和第二輪的五官比例維持不動。

## 鼻嘴追加修正：Codex 分析

另比對 Nicole《Price of Hope》、Ellen《Oh Ellen, Please!》、Anby《Thunderbolt Silhouette》封面，以及 Belle／Wise 官方角色宣傳圖。這些圖片有不同表情與透視，不能當作同倍率正側面工程圖；本次不宣稱測得官方模型比例。共同可採用的造型觀察是：正面鼻底標記很短、鼻尖高光細小、閉嘴輪廓柔和，嘴周與下巴靠面體轉折而非粗黑線分開。

現況：2D 鼻子是亮色三角形加橫線，嘴部張口還固定疊白色齒條；3D 鼻子使用寬廣高斯隆起，鼻底到人中沒有獨立截面，嘴周整體內凹，側面難以讀成鼻尖／鼻底／唇／頦的連續輪廓。先保留第二輪鼻底與嘴線高度，修正形狀與前後深度，避免在造型尚未正確前反覆移動五官。眼睛、Persona、耳位、下巴長度與動畫契約保持不變。

實作方向：增加下半臉截面，在同一頭模上收窄鼻梁、形成鼻尖與鼻下回折、少量唇部體積；正面只留短暖色鼻底。2D 取消尖三角與粗橫線，改小鼻尖亮部、短鼻底及較柔和的唇線，張嘴採暖暗色與窄齒部。戰鬥角色與居民都透過 AnimeFace 共用；2D 使用同一 FacePlan。

## 第五輪修正：身體、手、2D 頭像、配色（使用者選擇再修一輪）

第四輪的服飾層次、髮型分量、剪影辨識都有明顯進步，**請保留**，眼睛也不要動。這一輪只修下面 4 點。

### 1. 身體還是方塊感 → 改成圓潤的人體

**問題**：手臂、腿、軀幹的轉角都是直角，像紙箱拼起來的，沒有肌肉線條和腰身。

**做法**：
- 軀幹、上臂、前臂、大腿、小腿、腳都改用有圓角截面的掃掠或車床網格（lathe）。截面至少 8～12 邊，不要 4 邊方塊。
- 每一段四肢都要有粗細輪廓：
  - 上臂：三角肌處較粗，到手肘收窄。
  - 前臂：靠近手肘處較粗，到手腕收窄。
  - 大腿：上粗下細，膝蓋略收。
  - 小腿：小腿肚隆起，到腳踝收窄。
- 軀幹要有胸廓、腰身、骨盆的起伏。側面看時，胸往前、腰往後、臀往後有曲線。
- 關節處（肩、肘、膝、髖）要接得平順，不能看到方塊交界或縫隙。
- 衣服是蓋在身體上的「外殼」，要比身體略大，也要有圓角和布料的弧度。外套下擺、袖口、褲管邊緣可以保留俐落的轉角，但整體不能是方塊。
- 法線要平滑，或照第一輪的做法用平均法線，讓賽璐珞明暗形成乾淨的大塊陰影，不是一塊塊的面。

### 2. 手很醜 → 做出手的形狀

**問題**：手是一團方塊，沒有手指。

**做法**：
- 手掌是扁平、略帶弧度的塊。四根手指可以合成兩組（食指＋中指、無名指＋小指）或一整片，大拇指要分開。
- 依動畫狀態切換兩三種手型：握拳（握武器）、張開（施法）、放鬆。
- 戴手套的職業用手套的形狀，例如露指手套、護腕。
- 三角形預算：每隻手 150～300。

### 3. 2D 頭像 → 修正兩個明顯問題

**問題**：
- 臉被切成左右兩半，一半膚色、一半橘色，像被塗了一條。
- 頭髮有明顯的像素鋸齒，比 3D 版粗糙很多。

**做法**：
- 臉的陰影改成跟 3D 一樣的形狀：只有臉頰外側和鼻子下方一小塊，邊緣柔和，顏色是淡粉橘，不能蓋住半張臉。
- 頭像要做抗鋸齒，例如超取樣 2～4 倍再縮小，或在邊緣算覆蓋率。頭髮、輪廓、眼睛都不能有鋸齒。
- 頭髮的明暗、天使環、髮束形狀要和 3D 版一致。

### 4. 配色偏暗、偏灰 → 提高彩度與對比

**問題**：絕區零的配色鮮豔、對比強，現在整體灰濛濛的。

**做法**：
- 每個角色的主色、輔色彩度提高，避免灰藍、灰紫這類混濁色。
- 點綴色要亮，例如螢光黃、亮青、洋紅、亮橘，用在滾邊、拉鍊、發光線條，面積約 5～10%。
- 亮部和暗部的明度差加大。暗部用帶色相的深色，例如藍紫、深紅，不要灰黑。
- 黑、白、灰的衣服也要有一個鮮豔的點綴色。
- 全員並排圖要看起來繽紛，但每個人有自己的主色調。
- `ToonStyle.cs` 的全域參數（暗部顏色、邊緣亮光）可以一起調。但是要確認 Boss、小怪、城鎮看起來沒有變差，如果有影響要附對照圖。

## 第六輪修正：帽子、無意義色塊、手臂肌肉、肩膀（使用者看全身圖後的回饋）

> 帽子太高了，根本沒貼到頭。衣服有一堆奇怪的色塊，看起來根本不知道是什麼，不要有沒意義的色塊。腳的肌肉還可以，手也要有肌肉線條。肩膀不用每隻都直到幾乎直角，真實的肩膀應該稍微往下一點點。

**第五輪（身體圓潤、手、2D 頭像、配色）還沒做，請和這一輪一起完成。** 兩輪的要求都要符合。

### 1. 帽子、頭飾要戴在頭上

**問題**（見 `Docs/outfit_preview/` 的全身圖）：
- 米菈的高帽、海斗的船長帽、牧師和主教的高冠、召喚師的尖帽、阿潮的斗笠，都浮在頭頂上方，跟頭髮之間有空隙。
- 帽子也太高。

**做法**：
- **帽子內側要貼合頭型**：
  - 帽圈內緣要緊貼頭髮外殼，帽緣下面看得到頭髮被壓住。
  - 帽子底部要包住頭頂，大約到額頭上緣和耳朵上方。
  - 不能只放在頭頂一個點上。
- **帽子位置跟著髮量算**：
  - 用髮量外殼的實際高度計算，不是用頭骨高度。
  - 頭髮比較蓬的角色，帽子要往下壓，頭髮從帽緣下露出來。
- **高度降低**：
  - 帽冠高度約為頭高的 0.3～0.6 倍。
  - 主教、牧師的高冠可以到 0.8 倍，但要是禮帽或聖冠的比例，不是煙囪。
- **頭飾**（髮夾、耳飾、角、護目鏡）也要貼著頭髮或頭，不能浮空。
- **驗證**：輸出每個戴帽角色的頭部正面、側面特寫，確認帽子和頭髮之間沒有空隙。

### 2. 拿掉沒有意義的色塊

**問題**：
- 衣服、褲子上有很多方形、梯形的雜色塊，例如膝蓋、大腿、袖子、胸口上的小方塊和斜塊。
- 這些不是口袋、護甲、補丁或任何看得懂的東西，看起來像貼圖壞掉。

**做法**：
- **每一塊不同顏色的區域都要對應一個真實的服裝構件**：口袋、護膝、護甲片、拉鍊、滾邊、皮帶、扣環、徽章、布料拼接、領口、袖口、手套、鞋子。
- **不能說出是什麼的色塊，全部刪掉**，那塊回到底色。
- 保留的構件要做得像那個東西：
  - 口袋要有袋蓋或開口線。
  - 護膝要有厚度和弧度，貼著膝蓋。
  - 拼接要沿著衣服的剪裁線，例如肩線、側縫、腰線，不是隨便亂放。
- 褲子、袖子大部分應該是乾淨的單一布料，只在有理由的地方加東西。
- **在本檔補一張「構件清單」**：每個職業的每個色塊是什麼構件。清單上沒有的色塊就不該存在。

### 3. 手臂要有肌肉線條

腳的肌肉現在可以了。手臂請用同樣的方式處理：
- **上臂**：
  - 三角肌讓肩膀外側圓起來。
  - 二頭肌在前、三頭肌在後，形成上臂中段略粗、接近手肘收窄的輪廓。
- **前臂**：
  - 靠近手肘的肌肉較粗，往手腕明顯收細。
  - 手腕是扁的，寬大於厚。
- **差異**：
  - 男女、職業、體型可以不同：劍士、狂戰士較壯，法師、牧師、居民較纖細。
  - 但都要看得出肌肉起伏，不能是直筒。
- **穿長袖的角色**：袖子要順著手臂的輪廓，手肘處有一點皺褶。

### 4. 肩膀往下斜

**問題**：每個角色的肩膀從脖子水平往外延伸，到肩頭幾乎是直角，像衣架。

**做法**：
- **斜方肌斜線**：從脖子根部到肩頭是一條往下斜的線，約下降 10～20°，大約下降頭高的 0.15～0.25 倍。肩頭再自然地圓弧轉到上臂。
- **脖子和肩膀的交界**要有一個平順的弧，不是直角轉折。
- **肩寬**：
  - 男性約 2～2.3 個頭寬，女性約 1.8～2 個頭寬。
  - 肩甲、墊肩可以加寬輪廓，但下面的身體肩線還是要斜。
- **外套肩線**跟著身體肩線往下斜，不要做成水平的箱型。
- **驗證**：附一張「肩線對照」，畫出新舊正面輪廓。

  - 眼睛、五官比例、鼻嘴修正。

## 第七輪修正：奇怪的角、無意義色塊、臉側深橘色條（使用者回饋）

> 衣服上還是有很多奇怪的角（尤其肩膀與褲子）與色塊。不要有任何無意義的色塊，都要是配件與結構。另外，臉側邊還是有奇怪的深橘色色條。

第五、六輪的帽子貼合、手臂肌肉、手型、配色**有進步，請保留**。這一輪只修下面三件事。**這次是第三次提出同樣的色塊問題，請照下面的清單逐項刪除或改正，不要只做部分。**

### 1. 臉側的深橘色條（從第一輪就存在，必須根除）

**原因**（我查過程式）：`Shaders/Toon.shader` 的 `SD_HUMAN` 臉部分支（約第 93～112 行）用臉部 UV 的 x 加上光線方向算出 `cheek` 門檻。邊緣只有 ±0.025，幾乎是硬邊，暗部顏色又是較深的 `_HumanSkinShade`。結果臉的一側固定出現一條寬、硬、深橘色的直條。軟體預覽和 2D 頭像（`Portraits.cs`）也照抄了這個效果。

**改法**：
- **主光從正面或 45° 以內照來時，臉上不要有側邊陰影**：皮膚維持亮部，只保留鼻下小陰影和瀏海投影。
- **光從側面超過約 60° 時才出現側臉陰影**，而且：
  - 邊緣柔和，過渡寬度至少 0.15。
  - 形狀沿顴骨、下顎線彎曲，不是一條直帶。
  - 顏色只比膚色暗一點、偏粉，例如膚色 × (0.93, 0.85, 0.85)，不能是深橘色。
- **下巴下方、脖子**可以有一塊柔和的陰影，用來分開臉和脖子。這是唯一常駐的臉部陰影。
- **瀏海投影**也要柔和、淡，不能是一條橫的深色帶。
- **3D shader、軟體預覽、2D 頭像三處要用同一套規則。**
- **驗證**：輸出 `face_light.png`，同一張臉在光從正面、45°、90° 三種情況下的樣子。正面和 45° 時臉上不能有任何直條。

### 2. 無意義色塊：逐項刪除清單

我在這次 `outfit_preview` 的全身圖上看到以下問題，**每一項都要處理**：

| 位置 | 現況 | 要改成 |
|---|---|---|
| 大腿、膝蓋上的短橫線（金色、橘色、亮色，幾乎每個職業都有） | 不知道是什麼 | **刪除**。褲子回到乾淨的單一布料 |
| 膝蓋、小腿上的深色小方塊、斜塊 | 不知道是什麼 | **刪除**。真的要護膝，就做成有厚度、包住膝蓋的弧形護具，而且只放在需要的職業（劍士、聖騎士） |
| 胸前正中央的深色直條（每個職業都有，像一條領帶） | 看不出是什麼 | 做成**看得出的拉鍊或排扣**：細的金屬線加拉鍊頭，或一排扣子。不然就刪除，只用衣服本身的前襟線表現 |
| 胸口右側的短線、小色塊 | 不知道是什麼 | 要嘛做成有袋蓋的口袋，要嘛刪除 |
| 鞋子上的多條橫線 | 不知道是什麼 | 改成鞋帶、鞋底邊、或一條鞋面滾邊，最多一種 |
| 腰帶下方左右的小亮塊 | 不知道是什麼 | 皮帶扣只在正中間一個，其餘刪除 |
| 袖口、手腕的雜色小段 | 不知道是什麼 | 統一做成袖口反摺或手套邊緣，一圈完整的環，不是幾段色塊 |

**通用規則**：
- **只有底色、輔色、點綴色三種顏色**。點綴色只能用在：滾邊（沿著衣服邊緣的連續線）、拉鍊或扣子、皮帶扣、徽章、發光符文、武器。
- **每個色塊必須是連續、完整的構件**，例如沿著整個下擺的滾邊、整圈的袖口。不能是浮在布料中間的短線或小方塊。
- **「我不確定這是什麼」就刪掉。** 少一點細節沒關係，乾淨最重要。
- **驗證**：`components.json` 要對應到圖。新增 `component_callouts.png`：五個基本職業的正面圖，每個非底色區域都用引線標出構件名稱。圖上沒有標註的色塊不能存在。

### 3. 奇怪的角（肩膀、褲子、衣襬）

**問題**：
- **肩膀**：肩頭還是有尖角和凸出的方形邊，像墊肩翹起來。
- **褲子**：大腿內側、膝蓋、小腿有很多三角形的深色折面和突出的尖角，看起來像碎玻璃。
- **衣襬**：外套下擺的鋸齒、三角形尖片太多。

**做法**：
- **肩膀**：
  - 衣服肩部改成圓滑的弧，沿著第六輪的斜肩線包住三角肌。
  - 不能有任何尖角或翹起的平板。
  - 肩甲只有劍士、聖騎士、狂戰士需要，也要做成有弧度的殼。
- **褲子**：
  - 截面至少 10～12 邊，頂點法線平滑。
  - 不能有單獨突出的三角面。
  - 膝蓋只用輪廓的粗細變化表現，不加尖角。
  - 褲管在腳踝收口或蓋住鞋面。
- **衣襬**：
  - 下擺用平順的曲線。只有明確設計的燕尾、開衩可以有角，每件衣服最多一處。
  - 不要有一排小鋸齒。
- **整體**：
  - 檢查所有布料網格，任何轉角小於 120° 的尖點，除非是刻意設計的領尖、燕尾、帽尖，否則都要倒圓角。
  - 不能出現法線翻轉、Z-fighting 造成的碎面。

### 臉側深橘條的根因與新規則

- 移除 `SD_HUMAN` 的硬門檻 `threshold ±0.025` 與將側緣混回球面 N·L 的做法。人類臉面現在整體使用解析遮蔽，不會在臉頰外側退回深橘色球面暗部。
- 主光先投影至頭部的前／右軸，取水平角度。正面至 60° 的 `sideGate` 為零；超過 60° 後才平滑增加側頰遮蔽。遮蔽邊界為 `0.20 + 0.80*(v-0.46)^2` 的曲線，轉換寬度 0.20 UV，沿顴骨及下顎彎曲，左右側光對稱。
- 臉部暗色固定為膚色 × `(0.93, 0.85, 0.85)`；人類皮膚預設暗部也改成此淡粉倍率。鼻下維持小橢圓遮蔽，最大權重 0.24；瀏海使用既有分線／種子，羽化寬度 0.08、權重 0.32；下巴底部僅留權重 0.45 的柔影。正面和 45° 都沒有側頰直條。
- `Portraits.Canvas.Face()` 刪除固定外頰橢圓，改由新增的 `HumanFaceLight.Occlusion()` 依相同 UV、參數、公式繪製；頭像主光為正面。軟體預覽也使用相同方程及每個角色實際材質的分線／瀏海參數。
- Shader 屬性名稱不變；上述邏輯只在 `SD_HUMAN` 啟用時執行。未啟用時的 shader 本體／描邊程式與修改前一致，因此 Boss、小怪與城鎮場景不會套用人臉柔影。

**做法**：
- 輸出 `head_ratio.json`：每個角色「頭高（含頭髮，不含帽子）／身高」和頭寬。
- **成人**：
  - 統一在 **6.5～7 頭身**：頭稍微縮小，或身體、腿稍微加長。

### 2. 嘴巴太小、表情要依性格變化

**嘴巴大小**：
- 目前閉嘴寬度約 0.048（臉寬的 18%），太小。
- 改成約等於兩瞳孔間距的 0.6～0.7 倍，也就是 0.065～0.078。嘴角可以有一點深度和陰影。
- 張嘴（施法、喊叫）時可以張得更明顯。高度最多約到嘴寬的 0.6 倍，要看得到上排牙齒和口腔暗色。

**依性格的預設表情**（每個角色在 `CharacterLook` 或 Persona 裡指定）：

| 性格 | 嘴型 | 眼神與眉毛 |
|---|---|---|
| 自信、好勝 | 單邊嘴角上揚（壞笑） | 眉尾上揚，上眼皮略壓 |
| 開朗、天真 | 張口笑，露一點上排牙 | 眼睛稍微瞇成笑眼，眉毛放鬆上揚 |
| 冷靜、精明 | 平直、嘴角略往下 | 半閉眼，眉毛平 |
| 溫柔 | 淺淺微笑、嘴角柔和上揚 | 垂眼，眉毛八字微彎 |
| 兇狠、戰士 | 嘴角下壓，或咬牙露齒 | 眉頭往下壓、皺眉，瞳孔縮小 |
| 狡猾 | 歪嘴笑（一邊高一邊低） | 斜眼看人，一眉高一眉低 |
| 膽小 | 小嘴微張，嘴角下垂 | 八字眉，視線往旁邊飄 |
| 年長、穩重 | 被鬍子半遮，嘴角平穩 | 眼皮較重，眉毛粗 |

**表情要會動**，3D 角色與居民都適用：
- **待機時**：
  - 每 2～6 秒隨機眨眼。
  - 偶爾（8～15 秒）視線往旁邊看一下再回來。
  - 偶爾換一個微表情，例如微笑加深、挑眉，1～2 秒後回到預設表情。

- 做法建議：
  - 嘴型用幾個預先建好的形狀，例如閉嘴、微笑、壞笑、咬牙、張嘴，用 blend 切換或直接換 mesh。

## 第九輪：居民（NPC）的手、腳、身體形狀（使用者回饋）

> NPC 的手腳身體形狀很怪。

這一輪**只處理 12 位居民**（`TownArt.CreateNpc`、`DressResident`、`HumanResidentMotion`、`HumanProportions` 對居民的部分）。
臉、眼睛、髮型、帽子、表情已經 OK，不要動。

對照 `Docs/round8_preview/npc*_idle.png`、`poses.png` 與正面全身圖，具體問題如下。

### 1. 手臂和身體沒有接在一起

- 第八輪的居民待機姿勢（交叉手、手叉腰、收臂）讓上臂、前臂變成**浮在身體外面的獨立方塊**：
  - 翠：前臂水平插在胸前，拳頭像釘在衣服上。
  - 鐵匠：右上臂水平往外伸，手肘懸空。
- 肩膀與軀幹之間有縫，或肩頭像外加的墊肩方塊（尤其公會長、海斗、老焰）。
- **做法**：
  - 肩關節要埋進軀幹的肩線裡，從任何角度都看不到縫或錯位。
  - 手臂放下時要貼著身體側面，不要往外張成 A 字。
  - 交叉手、叉腰這類姿勢如果做不到不穿模、不斷開，**就不要做**。改成自然下垂、手在身前輕握、拿著道具這種簡單姿勢。
  - 寧可簡單自然，不要怪。

### 2. 身體是平板或梯形的方塊

- 軀幹正面像一塊上寬下窄的平板，側面看很薄，沒有胸、腰、臀的起伏。
- 長衣（米菈、翠、公會長、海斗）的下擺是硬邊的方形裙片，轉身時角很明顯。
- **做法**：
  - 軀幹截面用橢圓或圓角形，有胸廓到腰的收窄，以及臀部的弧度。
  - 長衣下擺用圓滑的筒形或喇叭形，有輕微的皺褶起伏，不要平板裙片。

### 3. 腿像兩根直筒

- 大腿到腳踝一樣粗、沒有膝蓋。腳是一片很小的薄板。
- **做法**：
  - 腿要有大腿粗、膝蓋略細、小腿肚、腳踝細的輪廓。
  - 鞋子要有足弓到鞋頭的長度：成人腳長約 0.24 m，要看得出往前的鞋頭。
  - 站姿雙腳略分開，腳尖微外八，不要兩根平行柱子。

### 4. 手太小、像爪子

- 手掌目前只有小小一團加幾根細刺。
- **做法**：
  - 手長約臉長的 0.75 倍。
  - 手指併攏成一體的手掌形（日系卡通常見做法），拇指分開即可。不需要五根分開的手指。

### 5. 脖子

- 鐵匠、老焰的脖子太長、太粗，像一根柱子，頭往前歪掛在上面。
- **做法**：
  - 脖子長度約頭高的 1/3，和頭、肩自然銜接。
  - 第八輪縮頭後是「延長胸廓、頸部去填空間」，結果頸部太長。請改成**縮短頸部、把肩線抬高**來補。

### 6. 參考比例（只看，不放進專案）

- 絕區零的路人 NPC：
  - 身體是簡化的圓滑筒形，關節處有自然收窄。
  - 衣服用大塊乾淨的形狀，配件少而清楚。
- 剪影要乾淨：在 AR 裡從 3～5 公尺外看，**一眼看得出是「人」**，不會被奇怪的角或錯位分散注意力。

### 驗證

- 附 `Docs/round9_preview/`：12 位居民各一張**正面、側面、3/4 背面**全身圖，以及 `residents_lineup.png` 全員正面並排。

  - 手臂與軀幹、腿與骨盆沒有縫或穿模（列出每位居民的最小間隙／穿透量）。
  - 雙腳貼地。
  - 三角形數仍在原版 2 倍以內。

  - 臉、眼睛、髮型、帽子、表情、性格。
  - 玩家角色與職業角色（`CharacterRig`、`CharacterRig.Body.cs`、骨架長度與名稱）。

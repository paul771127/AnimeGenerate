# 角色臉型改成影片裡的鵝蛋臉（給 Codex）

遊戲裡角色的臉，要**貼近劇情影片的鵝蛋臉**，五官的位置、比例也要像影片，整體優美一些。

## 影片裡的臉的特徵（以艾琳為準，其他人照各自定裝圖）

**臉型：鵝蛋臉**
- 長寬比約 1 : 0.72～0.75（下巴到髮際線 : 顴骨寬）。最寬的地方在顴骨、眼睛下緣附近，不是在臉頰中段。
- 從顴骨往下，兩側是**平順的弧線**慢慢收到下巴。下巴略尖、帶一點圓，不是 V 字尖下巴，也不是方下巴。
- 腮幫子、下顎線不要有折角。側面看：額頭微微圓、鼻梁很低、嘴巴往後收、下巴有一點點往前。

**五官位置**（臉的高度＝下巴到髮際線＝1，由下往上量）
- 眼睛中線在約 0.45～0.48，就是臉的正中間略低。日系動畫的眼睛很低，不要放在上半部。
- 兩眼間距約一個眼寬；眼寬約臉寬的 0.25。
- 眼睛大、橢圓、上眼線粗而上揚，外眼角略翹。虹膜大，佔眼睛高度約 80%，有 2 個高光（大的在上、小的在下）。
- 眉毛細，在眼睛上方約 0.07；眉尾略低於眉頭。
- 鼻子在約 0.30，只用鼻尖的一點陰影或小線表示。
- 嘴巴在約 0.17，寬約眼寬的 0.6，短線，微笑時嘴角輕輕上揚。
- 下巴到嘴的距離短，人中短。
- 臉頰可以有淡淡的腮紅（粉色，半透明）。

**男性**（海斗）：下巴稍寬、一樣是平順弧線；眼睛較細長、眉毛較粗直。
**老人**（老焰）：同樣的臉型基礎，加法令紋、眼下紋、較長的鬍子和濃眉；眼睛較小、眼皮下垂。

## 要做的事
1. 調整 `AnimeFace` 的截面表，讓正面輪廓變成上面說的鵝蛋形：顴骨最寬、往下平順收到略圓的下巴。目前 `p.Story` 角色在 y < −0.03 時用冪函數硬收下巴，容易變成尖下巴，請改掉。
2. 依上面的比例重新擺放眼睛、眉毛、鼻、嘴（含大小、間距、高度），所有人類角色都套用；男性、老人用各自的參數變化。
3. 2D 頭像（`Portraits.cs`）的臉型與五官比例同步修改。
4. 每個角色（艾琳、澪、凪、翠、海斗、老焰、玩家角色、城鎮居民）都要對照定裝圖或截圖確認，正面與斜 45° 都不能穿模（眼睛不能浮出臉外、嘴不能陷進去）。
5. 盡量不要增加每幀的運算；網格、材質維持快取。

## Codex 說明（2026-10-24）

基底為 `99847c3`。先看 Erin／Mio／Nagi／Cui／Haido／Laoyan 六張定裝圖，以及 `v0_s05`、`v3_s04` 等影片幀，再改共用臉型；沒有匯入任何參考圖作為遊戲材質。完整 [正面／45°／頭像檢查與數值](Docs/face_check/README.md)、[六人參考對照](Docs/face_check/reference_comparison.png)。

### 參數與同步方式

- `AnimeFace` 的可見截面不再走 `p.Story` 的冪函數收尖。顴骨最高半寬約 0.103，在 y ≈ −0.030；以下採圓弧取樣、單調三次插值及密化截面，底端半寬 0.009，形成略圓的下巴，沒有 V 尖或方顎折角。頭頂／下巴高度仍為 ±0.157 × Length，後腦體積保留。
- 髮際線 y = 0.123 × Length，臉高為 0.280 × Length。Width 的差異收為 0.984～1.012 倍；保留 Jaw 的小幅男性差異。原骨架的頭部縮放並不等向，故在完成既有尺寸校正後，只對臉部子物件做一次 x 軸補償；實際 41 組臉寬／臉高約 **0.721～0.748**，而非只讓未縮放的頭模符合比例。
- `FacePlan` 共用：眼中心 0.465、鼻底 0.30、嘴 0.17；眉線比眼中心高 0.07。眼寬為臉寬 0.25，兩眼之間一個眼寬；嘴寬為眼寬 0.60。女性大眼、男性較細長、老人較小且下垂；保留原來每人的眼型、虹膜色、雙高光、視線和性格表情。
- 鼻尖凸起縮到 0.006，鼻梁 0.0015；正面只留 0.0008 寬的暖色短筆。嘴唇體積縮到 0.0012；嘴線短而輕，微笑保持淺弧。張嘴片及上牙順著嘴周斜面，保留施法／受擊／倒地動畫。眼片貼面距離 0.0035、眉線 0.0042，用以避免眨眼／皺眉時穿進臉內。
- `Portraits` 的所有具體人類頭像直接用同一截面半寬及 FacePlan，不再各用一份尖顎多邊形。臉頰加入極淡粉紅，3D 為中心透明漸層薄片，2D 為淡色無描邊填色；縮小耳寬並讓耳上下緣跟隨眉線／鼻底。
- 老焰的濃眉、眼下紋、法令紋共用新座標；原長鬍鬚與八字鬍重新貼到嘴下，避免浮在臉前。海斗眉毛較粗直，稍寬圓顎；翠沒有套用老人紋路。
- 舊臉面的定位參考只供 `FittingVertices`／`HairSeat` 使用，**不顯示、不加入 Renderer**。這可避免自動頭部尺寸校正把新臉再次拉寬，也避免瀏海隨新臉面往後縮。原髮型、帽飾、頭部定位、身高和服裝保持。`AnimeHair`／`StoryHair`／`HeadwearArt` 的修改只改讀取這個原定位參考，沒有重新設計髮型。
- 角色臉側記號與眼鏡鼻橋改讀新臉面；城鎮小孩改用同一淡腮紅，不保留會浮出的球形腮紅。所有網格、眼圖集與材質仍快取；只有建立時增加臉部群組，沒有逐幀重建網格／材質或新增每幀臉面取樣。

### 檢查結果與範圍

41 組 × 5 個狀態，共 205 次表情幾何檢查；眼片、眉線、唇線、張嘴與上牙的可見取樣點對照同一個三角臉面，最小間距為正，最大約 0.00586（臉模本地單位）。建立後切換這些狀態，網格／材質快取數保持不變。頭模為 2,064 三角形，沒有新增逐幀幾何工作。452 個身體網格與 57 個髮型／帽飾網格和基底相同，頭部定位／縮放／朝向也相同。

`UNITY_IOS`、`UNITY_ANDROID` 的本機條件編譯均為 0 錯誤；本機使用 Unity API 替身，不等於實機建置。完整 Unity Android／iOS 建置交由本分支 Actions 執行。圖片是實際程序幾何的軟體投影，並非真機照片；仍需手機 AR 動態觀察。戰鬥判定、技能、數值、語音與連線訊息完全未改。

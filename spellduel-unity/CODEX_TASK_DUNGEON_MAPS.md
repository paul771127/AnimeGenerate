# Codex 任務：副本大地圖的美術（各主題）

## 使用者的要求

> 把副本全部都改成像翠蔭迷林的方式，讓玩家可以在一張大地圖探索、打怪，但副本強度一樣按照原本副本等級。

## Claude 已經做好的部分

- 地圖產生：`ExploreDungeon.cs` 的 `DungeonMaze.Build`。
  - 每個副本的每個地點，會變成地圖上的一塊區域：一般 5×5 格，最後的首領 7×7 格，一格 4m。
  - 區域之間用彎曲的走道連起來，走道旁邊有岔路，死路盡頭可能藏寶箱閃光點。
  - 長的副本會折成蛇形。
- 遊戲流程：`SoloBattle.DungeonExplore.cs`。
  - 清除一個區域，往下一站的門才打開。門是 `ExCell.Gate`，記在 `ExArea.exits`。
  - 連線多人也用大地圖。
  - 千機迴廊的每個房間都是機關房。
- 外觀目前只是程式換色頂著：牆、地面照副本主題換成現有的地形種類（`DungeonMaze.WallOf`／`GroundOf`）。

| 主題 | 牆（ExTerrain） | 地面（ExGround） |
|---|---|---|
| 熔岩 | Cave | Cave |
| 森林 | Thicket | Grass |
| 海上 | Rock | Shore |
| 角鬥場 | Palisade | Stone |
| 峽谷 | Rock | Dirt |

`ExploreMap.theme` 會是 `volcano`、`jungle`、`sea`、`arena` 或 `canyon`：取最後首領房的主題。各區域自己的主題用 `map.dungeon.ThemeOf(area.node)` 取得。

## 請 Codex 做的

整體原則：照翠蔭迷林（`ExploreArt*.cs`）的做法擴充，不改地圖資料和邏輯。

### 1. 各主題的牆、地面、景物

| 主題 | 牆 | 地面 | 景物 |
|---|---|---|---|
| 熔岩（灰燼礦坑、餘燼鑄鐘坊） | 黑曜岩壁、發光的岩漿裂縫 | 焦黑碎石、偶爾冒煙 | 礦車、鐵軌、坩堝 |
| 森林（腐根神殿、霧燈記名徑） | 照翠蔭迷林 | 照翠蔭迷林 | 霧、燈籠 |
| 海上（沉沒王座、白帆回聲礁） | 礁岩、珊瑚 | 濕沙、淺水漣漪 | 船骸、貝殼、海草 |
| 角鬥場 | 木樁圍牆、石砌看台 | 沙地、石板 | 旗幟、兵器架 |
| 峽谷 | 紅褐色斷崖 | 黃土、碎石 | 枯樹、風蝕岩柱 |
| 千機迴廊 | 黃銅齒輪牆、鉚釘鋼板 | 金屬格柵地板 | 管線、蒸汽 |

千機迴廊的主題照它房間的 theme 設定，但機關房要有機械風格，判斷方式是 `map.nodeAreas`。

### 2. 區域的標示

- 區域地面和走道要能分出來，例如換鋪面或加一圈邊框。
- 區域的種類：

| 種類 | 怎麼判斷 | 樣子 |
|---|---|---|
| 戰鬥 | 一般區域 | 營地感，例如篝火、帳篷 |
| 寶箱 | `IsChest` | 寶箱台 |
| 特殊事件 | `IsEvent` | 地上有符文圈 |
| 首領房 | `IsBoss` | 王座或大門 |

- 出口的門：清除前是封印，例如結界、柵欄、落石；清除時播打開的動畫。
  - 門的格子在 `ExArea.exits`。
  - 判斷開關用 `map.GateOpen(x, z)`。

### 3. 小地圖

- 區域用主題色塊表示，已清除的打勾，首領房用皇冠圖示。
- 進行中的區域要閃。

## 規格

- 效能照翠蔭迷林：只畫玩家附近 `ExViewCells` 格，貼圖、網格都要快取。
- 連線時每台手機的地圖一樣：地圖用副本 id 當固定種子。
- 美術不能改變走得到的範圍：碰撞照 `ExploreMap.Walkable`，景物障礙要用 `map.AddProp`。

## 驗收

- 原生預覽：每個主題各一張俯瞰圖、一張第一人稱截圖。
- 測試：加了景物之後，每個副本都還要能從起點依序清除各區域走到首領。可以用 `ExploreMap.Reachable` 檢查，景物不能擋住走道或門。
- Android、iOS 都要編譯通過。
- 推到 `claude/mobile-camera-mic-battle-game-v5nhfr`。

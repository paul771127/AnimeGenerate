## 美術

不透明的深藍紫黃昏天空、暖金地平線、新月與星光；五章地形分別呈現火山裂口、松林、海上反光、遠方角鬥場與黃土台地，近景是炎之里的木構鐘樓。六張卡片使用同一組深色半透明魔晶面板、細主題色邊線與金屬角飾，維持暖金／橘紅／紫／青藍／天藍／灰銀的順序。故事入口高 12%，標題用淡金，其餘用近白；版本號維持頁底。

下半部由背景貼圖內建的漸暗遮罩保持可讀性。光點緩慢往上漂浮，淡符文環反向緩轉；沒有逐幀建立貼圖。背景＋兩張九宮格面板共三張新增貼圖，RGBA 原始大小約 2.55 MiB，無 mipmap，Apply 後不保留可讀像素。卡片使用同一張背景的 UV 裁切還原玻璃後景，保留原 UiKit.Button 的點擊與音效，不新增互動控制項。

## 驗證

- 116 個 Runtime／Editor C# 檔案語法解析通過；實際首頁繪圖來源與 UiKit 使用 .NET 10＋Unity API 替身編譯並執行。
- 兩種直式尺寸，各在 0／8／16 秒重畫，皆有六張卡片，位於安全範圍內且沒有互相重疊；故事卡片保留更大的視覺層級。
- 暖機後重畫時，替身所觀察的 Texture2D 建立總數固定為 12（含既有 UiKit 與插圖貼圖）；新增首頁貼圖為三張。背景像素 alpha 全為 255，三格動畫有像素變化。
- 語法樹比對確認原首頁所有字串、按鈕處理分支、newbie 選取條件與插圖順序未變。其他既有方法（包含所有連線流程）保持原樣。
- 本機未安裝 Unity Editor，沒有宣稱 iOS／Android 原生編譯或手機效能已驗收。

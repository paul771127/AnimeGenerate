# 8591 手遊帳號市場分析(2026-09-24)

資料:`scan.py` 掃描 8591 全部 6,842 款手遊,取每款最近 200 筆「帳號」成交紀錄 + 目前在架數。
完整 95 款結果在 `out/deep.csv`(執行 `python tools/market8591/scan.py` 重新產生)。

欄位說明:
- **初始號**:8591 帳號分類「初始號」(account_tag=2),也就是抽卡首抽號
- **成交/天**:最近 200 筆成交換算的每日成交筆數
- **日成交額**:成交/天 × 平均價(台幣),代表這個市場每天有多少錢在流動
- **庫存天數**:在架商品數 ÷ 成交/天,越低代表供不應求、越好賣(一個賣場可能有多組庫存,實際競爭更激烈)

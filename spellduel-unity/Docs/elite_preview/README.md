呼叫BossRig.CreateWorld(id)，搭配SetPhase、SetPartBroken、Windup、Attack、Preview即可獨立預覽。Warning(move)回傳的物件由呼叫者銷毀。世界Boss沒有接入戰鬥、入口或掉落。

## 驗證界線

原生測試實際執行Battle的50條主機／隊友技能路徑、跳／蹲／退圈、冷卻、精魄擊殺鍵，以及180組副本固定出怪配置。這是同程序的主機／隊友模擬，沒有進行雙手機AR連線或六人實機FPS測試；iOS／Android平台編譯不能替代這兩項實機驗收。

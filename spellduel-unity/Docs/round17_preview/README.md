## 實作

8～11 秒切換一個角色專屬小動作，兩端平順淡入淡出；走路、招呼時降低待機權重。工作檯固定在城鎮座標，不跟居民滑行；居民離開時改為整理隨身物品或檢查刀刃。杯子、錢袋、弓、望遠鏡、名冊、票根、捲線器等都有實體程序網格。名冊頁與捲線器會轉，敲砧時啟用預先建立的火星。

四肢使用既有關節，新增踝骨、裙襬骨與翠的垂袖骨。蒙皮每頂點最多兩個骨權重，網格／材質只在建立時產生並快取，Tick 不建立網格或材質。支撐腳踝錨在世界座標，擺動腳抬起再落下；停步、原地轉身也用落腳處理。身高、臉、眼睛、髮型與服飾網格輪廓沿用原版。

第 4、5 章在拉取版本已經借用基本居民的關節，本輪保留原模板外觀，將動作改成自己的身分並補上踝部控制。沒有重複增加 HumanResidentMotion，也沒有更改 TownWalk 的移動、互動、速度或出現條件。塔守原本只有 2D，本輪沒有為他新增 3D。

## 驗證

23 位、52 種待機動作，完整稽核共 37,032 個取樣，零失敗。腳底最低值 -1.79e-07、支撐踝 XZ 最大偏移 7.54e-07（模型單位，為浮點精度級誤差）。所有手持物父節點與握點保持、工作檯固定、蒙皮網格與材質引用不變。

15 職業共 75 種戰鬥表情狀態，居民專用閉眼／開口覆寫值從 0 改到 1，戰鬥角色的臉部幾何與變形保持一致。121 個 C# 檔案語法解析通過；111 個原有非本輪美術來源檔逐檔確認未改。

Unity 可在 **Play Mode** 執行 `SpellDuel/Art/Validate Round 17 residents (Play Mode)`；會寫出 `unity_resident_audit.json`。本次執行同一驗證來源的 .NET 10＋Unity API 替身版本，結果為 offline_resident_audit.json。本機沒有 Unity Editor，尚未驗收原生 shader、GPU 蒙皮、裝置效能或所有衣物與道具的動態遮擋。

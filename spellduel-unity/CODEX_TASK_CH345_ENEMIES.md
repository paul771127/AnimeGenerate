# Codex 任務：第三～五大關的敵人改成 2D 圖（同第二大關的畫風）

## 使用者的要求

> 做完讓 Codex 把第 3～5 大關也做成 2D 的吧，風格都是這樣。

**順序**：請先把 `CODEX_TASK_NPC_SPRITES.md` 剩下的 NPC 交完（工頭老石、阿岩、黑衣鑄鐘匠、翠蔭迷林 7 位、受傷的旅人），再開始這一份。

**畫風**：跟第二大關森林敵人最後採用的版本一樣（`a56bf4d4`，使用者確認過的中等細節日式動畫風）。
- 剪影清楚、線條乾淨、表情是戰鬥中的兇狠或認真。
- 參考 `Docs/forest_2d_preview/` 的對照圖。

## 格式（跟森林、城堡敵人完全一樣）

- **檔名**：`Assets/SpellDuel/Resources/SpriteEnemies/{sheet}_{idle|walk|windup|attack|hurt|die}.png`
- **排法**：橫 8 格是方向，直的是第幾張，每格 256。
- **張數**：idle 4、walk 6、windup 2、attack 3、hurt 2、die 4。
- **位置**：腳底在格子底邊往上 6%。飛的、飄的身體離地，影子位置一樣在 6%。
- **`.meta`**：同森林。
- **表格的「一格高度」**：一格 256 對應的世界高度（公尺）。角色本身大約佔格子 75～80%。
- **出手動作**：照原本的 AI，見各表的說明。

## Claude 已經做好的部分（遊戲端）

- `Runtime/Combat.SpriteMonsters.cs` 加了 `Sea`、`Arena`、`Canyon` 三張表。**6 張圖都在才會換成 2D**，所以可以一隻一隻分批交。
- **一般小怪、菁英、小 Boss**：照「這一場的章節」選圖。
  - 角鬥場和山道會出現前面章節的怪，例如熔岩小鬼、毒液噴花，所以同一種怪在第四、五章各有一套換了打扮的圖。
- **稀有怪、人形敵人、輔助型**：照變種 id，哪一章都一樣。
- 3D 時代的各章打扮，畫 2D 時保留同樣的辨識特徵：
  - **第四章角鬥場**：魔物被抓來鬥場。脖子上是閉合的鐵項圈，中間鑲一顆黑晶，垂著一段斷掉的三節鎖鏈。
  - **第五章山道**：魔物被砂暴磨過。披著砂色編織圍巾（有一條垂尾），身上卡著砂粒，色調偏乾燥的土黃。

# 初心者設計 Brief（給 Codex）：外型、動作、技能

## 背景

SpellDuel 的每個新角色都從「初心者」（class id `novice`）開始，到 10 級才轉職。

- 開局時只會普攻「丟小石子」。
- 另外三招要到炎之里找居民解任務才學得到：
  - 小鐵 教「木棍揮擊」
  - 米菈 教「投石」
  - 老焰 教「急救」

這些功能目前都能玩，但外型、動作、特效、圖示都是暫代的：
- 外型：木棍、小布包、布衣。
- 揮擊：借用劍士的揮砍動作。
- 石頭：一顆會翻滾的球。
- 圖示：揮擊借斬擊的圖，急救借治癒的圖。

**這次請你重新設計初心者的外型、動作和技能表現**。要讓玩家一眼看出這是「剛出村的新手冒險者」：樸素、親切、有成長空間。也要和五個職業（劍士、獵人、法師、刺客、牧師）明顯不同。

## 設計方向（建議，可以發揮）

- **外型**：
  - 旅行布衣加簡單皮帶。
  - 背一個小背包或斜背布包。
  - 鞋子是旅行短靴，可以加一條隨身水壺或繃帶捲（呼應「急救」）。
  - 不要盔甲、不要披風、不要發光的武器。
  - 木棍要看得出是撿來的粗樹枝，或手削的短棍。
- **動作**：比職業角色「生疏一點」，例如揮擊時身體跟著晃、丟石頭時會先瞄一下。但要清楚好讀，手機上一眼看得出在做什麼。
- **技能表現**：
  - 丟小石子：小、灰白、會翻滾，命中時有一點碎石。
  - 投石：比小石子大一圈、帶一點橙紅色（熔岩碎石），命中有小小的碎裂和塵土。
  - 木棍揮擊：短促的弧線殘影，木頭色系，不要像劍光那麼亮。
  - 急救：綠色的繃帶纏繞感或十字光點，溫和、不華麗。
- **圖示**：四個招式都要有自己的圖。風格請和 `SkillIcons.cs` 裡現有的圖示一致（程式畫的徽章）。

## 不要動的地方

- **技能和職業的 id** 不能改：`novice`、`na_pebble`、`nv_swing`、`nv_stone`、`nv_aid`。這些 id 寫在玩家存檔和任務裡。
- **放招手勢** 不能改：木棍揮擊＝手刀揮砍、投石＝握拳→張開、急救＝手掌收回自己、普攻＝比 5。這些在 `HandGesture.cs`，新手教學和任務台詞都是照這個寫的。
- **木棍揮擊的判定**：它和劍士的「斬擊」共用近戰判定（`Combat.cs` 裡 `s.id == "slash" || s.id == "nv_swing"`）。請保留。
- **任務** 不要改：`Progression.cs` 的 `NoviceQuests`、`SoloBattle.NoviceQuests.cs`。
- **右手持物的節點名稱 `Sword`** 不要改，除非你另外處理揮砍動作找武器的地方。
- **不要加新的外部資源**（圖片、模型檔）。造型和特效都用程式產生，跟現有職業一樣。

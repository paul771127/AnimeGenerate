`Docs/SUPPORT_HUMAN_SKILLS_PROPOSAL.md` 已經由使用者確認，開頭的「使用者定案」優先於內文（143 戰鼓手保留「出手更快」）。請依序做：

     - 腳下保留紅色敵方環（Claude 已經在暫時模型上加了；做成美術版的也可以）。
     - 讀條、施法的光以紅、橘、暗紫為主；治療類（德魯伊、神官）用帶暗色調的綠或金，不要和玩家牧師的聖光一樣。
2. **`VariantRig.cs`**：照下面 A-3 的介面；`Windup(move, duration)`／`Strike(move)` 的 move 就是提案表的招式 id（例如 `eh_151_flankrush`），一般攻擊用該怪的第一招 id。
3. **`EnemySupportFx.cs`**：照 A-4 的介面。
4. **技能特效（`EnemySkillFx.cs`、`EnemyShotView.cs`）**：照提案每一招的預警與出手外觀。介面採用你建議的「每次預警一個 handle」：
   - `int EnemySkillFx.Telegraph(string skillId, Vector3 at, Vector3 dir, float seconds, float size)`：畫預警（紅線、扇形、圈、橘地環、藍胸口弧帶），回傳 handle；at／dir 由 Claude 給（鎖定時的位置與方向），size＝長度或半徑（公尺）。
   - `void EnemySkillFx.Cancel(int handle)`：讀條被打斷、施法者死亡時取消。
   - `void EnemySkillFx.Cast(string skillId, Vector3 from, Vector3 to)`：出手瞬間（揮砍弧光、地波、沙柱、治療綠線以外的效果）。
   - `EnemyShotView EnemyShotView.Create(string skillId)`：投射物外型（弩矢、木箭、標槍、火珠、水梭、泡彈、砂矢）；位置、方向、回收由 Claude 控制。
   - 背後突襲的螢幕方向楔標由 Claude 用 HUD 畫，不用你做。

## A. 外型（現在就做）

1. **造型**
   - 一眼看得出職能：補師、薩滿、神官帶法杖／聖徽／雨鈴；仙女有透明翅膀與泡泡；戰鼓手背大鼓；旗手扛大戰旗；召喚師背法陣石板；砂靈是砂子聚成、邊緣散沙。
   - 人形敵人：同一隊統一配色、徽章；職業武器清楚（劍、弩／弓／標槍、法杖、雙匕首、聖徽／藤杖）。要看得出是**敵人**，不能和玩家、隊友的角色撞造型。
   - 配合各章的場景色調（熔岩、森林、海上、角鬥場、黃土山道）。
   - 預算：每隻 ≤6000 三角形；共用材質；中階手機要順。
2. **動作**：待機、走、快跑（人形：繞側衝刺、後撤翻滾）、預備、出手、受擊、倒下；
   - 讀條（補師、輔助型、召喚師）：舉杖、搖鈴、灑光粉、擂鼓、揮旗；被打斷時光碎掉。
   - 人形回血：停下喝藥水（術士、神官改成躲在怪後面唸咒）；刺客逃跑時半透明。
3. **畫面介面**（新檔 `VariantRig.cs`）：
   - `static VariantRig Create(int variantId)`：上表 23 種。
   - `float MoveSpeed { get; set; }`
   - `void Windup(string move, float duration)`、`void Strike(string move)`：move 是 B 部分的技能 id；B 還沒定案前，Claude 先傳 `"basic"`。
   - `void PlayHit()`、`void SetDead(bool dead)`
   - `void SetChannel(bool on)`、`void ChannelBroken()`：讀條開始／結束、被打斷。
   - `void SetFleeing(bool on)`：人形敵人跑開回血中。
   - `void SetSneak(bool on)`：刺客繞背中（半透明，只剩眼睛或輪廓）。
   - Claude 會在 `SoloBattle.UpdateMinionVisuals` 看到這 23 種時改用 `VariantRig`，拿掉 `MinionLook` 和 `SoloBattle.Humans.cs` 的借用模型。
4. **輔助效果特效**（新檔 `EnemySupportFx.cs`，都是靜態方法，位置用場景座標）：
   - `Heal(Vector3 from, Vector3 to)`：綠光從施法者拉到被補的那隻。
   - `Shield(Transform target, float seconds)`：泡泡護盾，持續 seconds 秒，被打破時碎掉（Claude 另外呼叫 `ShieldBreak(Transform target)`）。
   - `Haste(Transform target, float seconds)`：加速的腳下風紋或鼓點光環。
   - `Rally(Vector3 center, float radius)`：戰旗插地的光圈；`RallyAura(Transform target, float seconds)`：被增益者身上的金色光。
   - `Summon(Vector3 at)`：召喚陣、砂塵爆開。

## B. 技能（先交設計提案，確認後再做特效）

目前這些敵人的「出手」都是借原本小怪的招式（例如弓手射出去的是火球、術士放的是藤蔓術士的招）。請**每一種重新設計技能**。

1. **提案**寫在 `Docs/SUPPORT_HUMAN_SKILLS_PROPOSAL.md`：
   - 每一種 1～2 招（人形敵人 2 招：一般攻擊＋一招職業招牌技；輔助型、補師可以只有一招保命或干擾技）。例如：
     - 傭兵劍士：側面突進斬；橫掃（蹲）。
     - 弩手／弓手／標槍手：三連射；後跳射擊（拉開距離同時射）。
     - 術士：地上的範圍法陣（離開圈）；追蹤法球。
     - 刺客：背刺（從背後，預警時手機震動＋畫面提示）；煙霧彈（一段時間看不清）。
     - 神官／德魯伊：治療之外，一招保命（例如短暫無敵、把傷害轉給盾）。
     - 戰鼓手：鼓聲震波（跳）；旗手：插旗區域（站在旗子附近的敵人受增益）。
   - 每一招寫：觸發條件（距離、血量、冷卻、跟誰一起）、預警（玩家看到什麼、幾秒）、躲法（跳、蹲、側步、離開圈、打斷）、傷害倍率（相對該怪目前的一般攻擊）。
   - 規則：這是 AR 體感遊戲，躲法要能用身體做到；每一招都要有明確預警，不能「看不到就被打」；側步不超過 1m；跳、蹲同一種動作至少隔 1.5 秒。
   - 不要用「普攻集氣加速、閃避率、爆擊率」相關的設計（使用者不要）。
   - 示意圖或動作描述放 `Docs/pending_preview/enemies2/skills/`。
2. **確認後的第二輪**（現在先不用做）：每一招的預警、出手、命中特效；投射物外型。介面預定為 `EnemySkillFx.Telegraph(string skillId, Vector3 at, Vector3 dir, float seconds)`、`EnemySkillFx.Cast(string skillId, Vector3 from, Vector3 to)`、`EnemyShotView.Create(string skillId)`；提案時可以建議修改。

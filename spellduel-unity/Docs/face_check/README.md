- 女性下顎以外鼓的貝茲弧線連到小尖端，沒有兩條直線的 V 字；男性／老人較寬。額頭以較低瀏海和上移眼線縮短，眼睛與膚色同步到 3D／居民／頭像。

- 與 `99847c3` 的 452 個身體網格相比，頂點位置及三角索引一致。裸露皮膚顏色依補充要求調整；服裝、身體比例、戰鬥、技能、語音與連線訊息未改。
- 澪的 3D 欄是共用臉模示例，並非新增居民。六位後續地區居民沿用既有居民模板；原本沒有具名頭像者仍保留原預設剪影。
- 本機 Unity API 替身的 `UNITY_IOS`、`UNITY_ANDROID` 條件編譯均通過；完整平台建置由本分支 Actions 驗證。幾何取樣不代替手機 AR 的動態觀察。

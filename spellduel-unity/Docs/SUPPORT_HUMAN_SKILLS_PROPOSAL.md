# 補師、輔助型與人形敵人技能設計提案

**狀態：待使用者確認；尚未實作。** 本輪交 B 技能提案與 A 造型概念圖。確認前不新增 VariantRig、EnemySupportFx、EnemySkillFx 或投射物，不改 Combat、技能資料、數值、存檔或網路。來源：`CODEX_TASK_SUPPORT_HUMANS.md`；對照分支基準 `85e5781` 的 `Combat.Variants.cs`。

共 **23 種、45 招提案**：121～124、141～144、151～165。砂靈一招，其餘各兩招；15 名人形都是「一般攻擊＋職業招牌技」。人形補職的招牌技本身包含治療，沒有暗藏第三招。逃跑回血是既有共通狀態，不另算技能。

## 使用者定案（2026-10-28，優先於下文）

1. **整份提案確認**：23 種造型方向、45 招全部照做。Codex 開始做造型、動作、特效；Claude 照表實作技能、排程、數值。
2. **143 戰鼓手保留「出手更快」**：使用者說明「不要普攻集氣加速」只限玩家的精魄；這幾隻都是敵人，戰鼓手替敵人加攻速是可以的。行軍鼓點＝同伴移動 +35%、出手冷卻加快（6 秒）。
3. **採用全場躲招排程**：同一玩家兩次跳的命中時刻至少隔 2 秒、兩次蹲也隔 2 秒；跳、蹲不同時，相反動作之間至少 1 秒；同時最多一個需要身體反應的進攻預警；人形三人隊輪流出招。

## 請先確認的設計重點

1. 保留補師、召喚、群補、護盾與旗手增益的核心職能；新增的保命／干擾技不能連續替自己補血形成無限拖延。
2. **戰鼓手只加移動速度，不加快普攻集氣、不縮短讀條、不提前攻擊冷卻。** 目前程式有「出手更快」效果，與需求禁止事項衝突；這是需要 Claude 在提案獲准後移除的效果，本輪沒有改程式。
3. 不設閃避率、爆擊率、機率秒殺或隱形期間無預警命中。所有倍率／CD都是待確認的初版建議，不是已上線數值。
4. 刺客有方向提示且出手前現形；煙霧只畫在敵人附近，不能遮住手機攝影機的真實地板、玩家中央視野或安全提示。
5. 跳／蹲題由全場排程避免衝突；多人以各玩家可見的預警為準，不能把敵人讀條結束直接當作客戶端已看足預警。

## 傷害、距離與時序的共同定義

- `A`＝該敵人現有一般攻擊在既有種族／波次／章節縮放後、其他臨時增減傷與防禦結算前的傷害基準。不要拿新招的倍率回頭重算 A；同一擊仍只走一次既有傷害管線。輔助型若現行沒有攻擊，Claude 需先指定其 A 基準，不得把回血量當傷害。
- 表中治療／護盾百分比一律取**受益者最大 HP**，不乘 A。0A 表示沒有玩家傷害；治療不復活、不溢補。相同來源護盾刷新較大剩餘值，不逐次相加；跨來源增益是否疊加由 Claude 統一裁定，建議同類只取最高。
- CD 從出手／效果結算後開始；取消／被打斷也進完整該招 CD，避免反覆瞬間重讀。每隻一次只做一招；收招至少 0.6 秒。新傷害招進場最早 2 秒後才可預警；輔助核心技能沿用原本首次讀條排程。
- 距離為地面中心距離；近戰「範圍」數值是攻擊幾何，不再額外加第二次人體半徑。實作仍以既有 bodyRadius 做一次碰撞膨脹。表內沒有 HP 條件的招式為 HP>0 即可；沒有隊友條件者可單獨使用。
- 「定點／鎖線」在**預警開始**鎖定目標當下位置／方向，之後不追著玩家修正。射線帶寬預設 0.25m、彈體半徑約 0.08m；投射物速度建議 3m/s、最長 6m、到期清除。出手前看足表內預警，飛行時間是額外反應時間，不能扣掉預警。
- 近戰的攻擊者可先完成繞側走位再讀條；讀條開始後不穿過玩家、不轉向追蹤。後跳／翻滾是**敵人的動畫與位移**，不要求玩家翻滾。
- 支援技能：單體治療、群療、護盾、加速、旗手與召喚的讀條都可被有效傷害／既有打斷規則中斷；是否有效仍由房主判定。增益生效後打斷下一次讀條不會抹掉舊增益。既有輔助數值採任務單與目前常數；新增技能與下文排程是提案。

## AR 的可躲性驗收規則（由 Claude 接邏輯）

- 所有必須移動的躲法，在校準多邊形內要有共同安全落腳點，距現在位置 **≤0.8m，硬上限1m**；先依人體半徑擴大危險區再檢查。不要用「往後退」暗示玩家走出真實邊界。
- 離開圈的定點術半徑最多0.4m；中心上的人也應能一個小側步離開。扇形／鎖線若把人逼到場邊，延後、換方向或取消，不能要求穿過牆或另一個危險區。
- 跳題＝橘色地波環＋向上箭頭＋到達提示；蹲題＝藍色胸口弧帶＋向下箭頭；側步／離圈＝紅斜紋危險區＋白色邊框箭頭指安全方向。不能只靠顏色。敵方治療綠線只連敵人、不冒充玩家安全環。
- **同一玩家兩次跳的命中時刻至少隔2秒；兩次蹲也至少隔2秒**（超過需求1.5秒底線）。跳與蹲不能同時要求，兩個相反動作間至少留1秒回正；排程涵蓋既有Boss、小怪、陷阱與本提案，不只這23種。
- 同一玩家同時最多一個需要身體反應的進攻預警；支援讀條最多另顯示兩個小圖示。人形三人隊不一起搶攻，先前危險解除與收招後才排下一個。遠射多連發鎖定同一條通道，一次側步即可躲完整組，不逐發重新追人。
- 輪到本招但沒有合法安全點時先延後，超過2秒仍無解則取消並進短等待，不硬發招。跳／蹲不能辨識或使用無跳躍模式時，替換為已預告的細鎖線／0.35m定點區；不可照原地波悄悄判傷害。
- 背後招在1.8秒預警開始就顯示螢幕固定方向楔標「後方突襲・側步」、音效與選配震動，敵人至少在出手前1.2秒現形。無須快速轉頭。無法顯示完整提示時取消；煙霧中危險邊框永遠可見。
- 所有會造成傷害的預警，在攻擊者死亡、讀條中斷、目標失效／斷線或階段結束時必須取消；已發射投射物是否保留由 Claude 明訂，建議只保留已清楚告知的飛行物。假身、沙痕、旗幟不是新的可傷害單位。

## 共通逃跑回血（沿用現有狀態）

人形 HP<35% 且逃跑冷卻到期才逃；達70%或5秒結束，冷卻15秒。對照目前常數為每秒最大HP的8%，本提案不加碼。近戰／遠射者停下喝藥；術士／補職躲後方唸咒；刺客撤離時半透明但保留輪廓。移動途中不畫喝藥姿勢。逃跑期間不啟動下列進攻或招牌技，不疊加招牌治療；正在生效的舊護盾可自然到期。這些狀態的傷害中斷／移動速度由 Claude 保留既有判定，動畫不能自行改HP。

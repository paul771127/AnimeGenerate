# 美術風格：日式賽璐珞（給 Codex／ChatGPT 調整用）

角色（玩家／對手）、小怪、Boss 的實心部位都用 `SpellDuel/Toon` 著色器：
兩階明暗（硬分界＋一點柔邊）＋邊緣亮光＋外框黑邊。人類角色另啟用下方所述的立體臉變體與部位深色外框。
發光、半透明的特效部位（火焰、魔法陣、泡泡等）仍是 Sprites/Default 或粒子，不會描黑邊。

## 要調的地方

1. **全域風格參數**：`Assets/SpellDuel/Runtime/ToonStyle.cs`

   | 參數 | 預設 | 說明 |
   |---|---|---|
   | `OutlineColor` | 近黑 (0.015,0.012,0.025) | 黑邊顏色 |
   | `OutlineWidth` | 2.8 | 黑邊粗細，單位是「1000 像素高畫面上的像素」；手機實際寬度依螢幕高度等比放大 |
   | `OutlineFar` | 3.2 | 距離鏡頭超過幾公尺開始變細（避免遠處小怪糊成一團黑） |
   | `ShadeColor` | (0.52,0.48,0.68) | 暗部＝原色 × 這個顏色；偏藍紫比較有動畫感 |
   | `ShadeThreshold` | 0.12 | 亮暗分界（N·L），越大暗部越多 |
   | `ShadeSoftness` | 0.018 | 分界柔邊寬，0＝完全硬邊 |
   | `RimColor` | 暖白, a=0.12 | 亮部邊緣的亮光，a＝強度（0＝關掉） |
   | `Ambient` | 0.22 | 環境光量 |

   改完數字不用改其他程式（第一次取用著色器時會 `ToonStyle.Apply()`）。執行中改數字要再呼叫一次 `ToonStyle.Apply()`。

2. **各部位顏色**：還是在原本的 Rig 裡
   - 玩家／對手：`CharacterRig.cs`（職業色在 `Skills.cs` 的 `ClassDef.color`）
   - 小怪：`MinionRig.cs`（variant 0～18，熔岩 0–6、植物 7–12、海洋 13–18）
   - Boss：`BossRig.cs`（`RockAC/BarkAC/HideAC…` 等常數）
   賽璐珞風格建議：顏色彩度拉高、明度分明，少用接近黑的底色（不然跟黑邊糊在一起）。

3. **著色器本體**：`Assets/SpellDuel/Shaders/Toon.shader`（內建管線，兩個 Pass：TOON 本體、OUTLINE 黑邊）。

## 已知限制
- 黑邊是「背面沿法線外推」：用 Unity 內建 Cube 等**硬邊**（同一角有多個法線）的網格，轉角處黑邊會有小缺口。要漂亮的話把那個部位換成圓角／平滑法線的程序網格。
- 只有一盞主方向光會影響明暗（ForwardBase）；其他點光源不影響。
- 不支援這個著色器的裝置會自動退回 Legacy Diffuse（沒有黑邊）。
- 必須保留在建置裡：`Editor/BuildScript.cs` 已加 `IncludeShader("SpellDuel/Toon")`。


## 人類角色的立體臉與部位描邊（2026-10）

戰鬥人形及城鎮居民使用 `AnimeFace.cs` 的截面頭模：後腦保留體積，前臉較平，顴骨轉折、V 形下顎和嘴周後收，鼻梁／鼻尖直接融入頭模。頭部高度、腳底與骨架不變，Persona 的臉寬、下顎、長度、眼型、視線、眉嘴、頭部角度仍決定個性。不是把所有人都換成同一張尖臉。

眼睛改成貼合頭模表面的曲面薄片：眼白、程序圖集漸層虹膜、瞳孔、雙高光、粗上眼線；眉嘴是曲面細線。`eyePaint`、`UpperLid`、`mouthOpen` 保持既有動畫契約。髮束有前脊與斷續的天使環高光。2D 人類頭像也使用暖色側頰、瀏海陰影和下顎線，怪物頭像不變。

### 調整位置

| 參數／位置 | 用途 |
|---|---|
| `AnimeFace.ys / widths / fronts / backs` | 各高度的半寬、前臉與後腦深度；不要任意改最上／最下高度 |
| `AnimeFace.Surface()` | 鼻梁／鼻尖凸起、顴骨側面與嘴周後收；五官薄片也用同一表面取樣 |
| `Portraits.PersonaFor()` | 每人的比例、表情、視線與姿勢，不影響戰鬥資料 |
| `SD_HUMAN` | 只有人類材質啟用的本地 shader 變體；一般 Toon 路徑與全域設定不變 |
| `_HumanFace` | 0＝人類衣物／頭髮，1＝解析式臉部陰影，2＝其他暖色皮膚 |
| `_HumanSkinShade` | 暖粉暗部倍率，預設 `(0.80, 0.54, 0.49)` |
| `_HumanOutline` | 人類描邊倍率；臉預設 0.60，其他部位 0.85，乘上全域寬度 |
| 頭模頂點色 R／G | R＝局部描邊倍率（前臉／下巴細）；G＝前臉解析陰影遮罩 |
| Toon 人類變體的 cheek / nose / fringe | 解析式側頰、鼻下小陰影、瀏海陰影帶；使用頭部朝向與 UV，不用圖檔 |

頭部陰影的座標跟隨頭部，而不是鏡頭；居民頭部與身體分別合批，避免姿勢烘焙後光向錯誤。人類外框採用部位底色的深色版本，眼睛／眉嘴薄片不擠出外框。沒有增加陰影攝影機或逐幀網格生成；眼睛另使用快取的程序圖集取樣；皮膚／衣物仍是本體＋外框兩個 Pass，薄片沿用 Sprites/Default 的一個 Pass。

原有著色器名稱 `SpellDuel/Toon`、`_Color`／`_MainTex` 名稱及 ToonStyle 全域值未改動；未啟用人類變體時的著色運算保持原樣。Boss、小怪、城鎮建築和粒子不啟用 SD_HUMAN，保留原本外觀。手機的實際 shader 編譯、幀率仍需 Unity 的 Metal／GLES3／Vulkan 建置驗證。


### 第二輪：正常人類的五官比例

`Portraits.FacePlan` 統一三處的比例，基準頭高 0.314：眼睛中心 `(±0.056, 0.013)`、眼寬 0.057、眼高約 0.0376、鼻底 −0.072、嘴 −0.106。嘴寬約 0.0616，與短 V 形下巴底寬接近。耳廓上緣在眉線、下緣在鼻底，脖子寬為頭寬約 45%，接點偏後。2D 頭像由同一份座標換算，不另寫一套比例。

Persona 表格已直接使用正常範圍：Width／Jaw 0.94～1.06、Length 0.97～1.03、Eye 0.85～1.15；眼角 Tilt 及頭部 Pitch／Yaw／Roll 不超過 ±6°。Lid／Pupil 用來表現瞇眼或銳利眼神，不要再把整顆眼睛縮成細縫、放成圓盤或靠大幅歪頭區別個性。

頭模 720 三角形，眼窩約後退 0.007、鼻尖突出約 0.021；嘴與下巴側面前後差約 0.004。五官、傷疤、睫毛都取樣同一實際三角面。修改時請一併檢視 [三視圖與比例線](Docs/face_preview/README.md)，不能只看正面。這些 PNG 僅供人檢查，遊戲不載入。

### 第三輪：眼睛與髮型共用表

`CharacterLook.cs` 是眼型／虹膜／瞳孔／眼尾與髮型／分線／長度／髮色的唯一美術表，`EyeArt` 產生兩眼 256×96 的 RGBA 圖集，`AnimeHair.cs` 產生開口髮殼與彎曲體積髮束。2D 頭像直接用同一眼像素和髮型網格的正面光柵結果；不要再另外加一層球形後髮或三角紙片瀏海。眨眼只改眼片／眼皮的私有視覺變形，職業 id、公開 API 與戰鬥狀態不變。

八種眼型的共同筆法是粗上眼線、獨立眼尾、上緣切過的大虹膜、直橢圓瞳孔、左上大／右下小高光，外側短下眼線；不封閉描一圈。`SD_HUMAN` 的 `_HumanHair` 啟用頭髮頂點漸層與同色系暗部；`_HumanPart`／`_HumanWave`／`_HumanFringe` 控制瀏海下陰影起伏，Boss／小怪未開啟此變體。對照表、成本與限制見 [第三輪結果](FACE_3D_BRIEF.md#第三輪結果眼睛與髮型2026-10-18)，查看 [眼睛總覽](Docs/face_preview/eyes_overview.png) 和 [無帽髮型剪影](Docs/face_preview/hair_silhouettes.png) 後再調整。

### 第四輪：分層街頭戰鬥服與掃掠髮束

`OutfitArt.cs` 是服裝的配色／裁剪表，衣物由多截面收放、厚裁片、翻領、袖口、分襟與細節織帶組成。`CharacterRig.Outfit.cs` 沿原骨架掛載每個關節的合批網格，保留原握把、武器、技能動作與顯隱／閃色介面。居民使用同一造型表，頭像同步衣領與髮型；舊 T 字護鼻和積木肩甲不再使用。三角形上限依第四輪調為第一輪前的 2×，不要再把第三輪的 1.5× 當成目前上限。

髮型由 23～30 束七段曲線、五邊扁透鏡截面的收尖髮束組成；髮殼蓬鬆量約 12.7%，內暗層、主色束與斷續天使環至少三階。短髮必須有外輪廓特徵，不能只改分線或顏色。眼睛圖集與第二輪比例維持不動。

合批衣物與頭髮共用人類頂點色表面（`_HumanHair` 模式）：頂點 alpha 的 0／0.5／1 分別標記裸露皮膚暖暗部／自發光符文／布髮，並非透明材質；受擊使用不透明暖白閃色材質，以免 sprite 閃色誤讀這些 alpha 標記，原閃色流程不變。外框改為固定深黑，避免白色合批材質造成灰白邊；符文僅縮小外框，不新增 Pass。一般 Toon、粒子和原本 Sprites/Default 特效不受影響。完整設計、三角形／Renderer 與驗證限制見 [第四輪結果](FACE_3D_BRIEF.md)，預覽見 [全身索引](Docs/outfit_preview/README.md) 及 [頭髮剪影](Docs/face_preview/hair_silhouettes.png)。

### 鼻嘴造型補充

人類鼻子由頭模截面形成窄鼻梁、鼻尖與鼻下回折，嘴周只留少量唇部體積與柔和唇線。正面鼻影使用小面積柔影，不畫矩形鼻影或黑框三角鼻；2D 鼻尖高光不加描邊。眼睛沿用第三輪，鼻底與嘴線高度沿用第二輪。最新近景見 `Docs/face_preview/nose_mouth/`。

### 遊戲模型側面參考修正

以遊戲移植版的實際幾何補充宣傳畫參考：鼻根先收，再到鼻尖；嘴周需有上下唇與唇下凹折，下顎往後收。保持已接受的眼片、五官高度與個性，不能用調整眼睛來掩蓋鼻嘴體積問題。外部 glTF／貼圖僅供 repo 外觀察，遊戲仍全程式產生。最新鼻嘴近景在 `Docs/face_preview/game_model_round/`。

### 第五、六輪：圓潤人體與有用途的服裝構件

人類軀幹與手臂使用 12 邊平滑掃掠，圓弧肩線往外下降約 18～20°，再轉入三角肌；上臂前後肌肉隆起、肘與扁腕收細。既有腿部肌肉輪廓、身高與腳底保持。外衣貼合人體曲線，下擺、領口、袖口仍有清楚剪裁。手使用 188 三角形的放鬆／握持／施法三型，保留原握把。

衣服不同顏色必須是可命名的構件：領口、內搭門襟、口袋與袋蓋、拉鍊、腰帶扣、護腕、護膝、鞋面鞋底、肩甲、披片、圍裙與帽帶。禁止按照頂點／截面序號畫假條紋；布料陰影由法線及原材質形成。主色保留色相並增加彩度，點綴色集中於實際五金與滾邊。完整清單見 `Docs/outfit_preview/components.json`。

帽飾依實際髮殼定位並包住頭頂，帽內髮頂另做受壓副本，原未戴帽髮束定義不變。3D、居民與頭像共用 HeadwearArt。人類頭像使用 3× 超取樣，外頰只留淡粉橘局部陰影；原眼睛、鼻嘴和比例保持。未修改全域 ToonStyle／shader 或 Boss／小怪。最新預覽與計數見 `Docs/outfit_preview/README.md`。

# 角色臉型改成影片裡的鵝蛋臉（給 Codex）

## 使用者的要求
遊戲裡角色的臉，要**貼近劇情影片的鵝蛋臉**，五官的位置、比例也要像影片，整體優美一些。

## 影片裡的臉的特徵（以艾琳為準，其他人照各自定裝圖）

**臉型：鵝蛋臉**
- 長寬比約 1 : 0.72～0.75（下巴到髮際線 : 顴骨寬）。最寬的地方在顴骨、眼睛下緣附近，不是在臉頰中段。
- 從顴骨往下，兩側是**平順的弧線**慢慢收到下巴。下巴略尖、帶一點圓，不是 V 字尖下巴，也不是方下巴。
- 腮幫子、下顎線不要有折角。側面看：額頭微微圓、鼻梁很低、嘴巴往後收、下巴有一點點往前。

**五官位置**（臉的高度＝下巴到髮際線＝1，由下往上量）
- 眼睛中線在約 0.45～0.48，就是臉的正中間略低。日系動畫的眼睛很低，不要放在上半部。
- 兩眼間距約一個眼寬；眼寬約臉寬的 0.25。
- 眼睛大、橢圓、上眼線粗而上揚，外眼角略翹。虹膜大，佔眼睛高度約 80%，有 2 個高光（大的在上、小的在下）。
- 眉毛細，在眼睛上方約 0.07；眉尾略低於眉頭。
- 鼻子在約 0.30，只用鼻尖的一點陰影或小線表示。
- 嘴巴在約 0.17，寬約眼寬的 0.6，短線，微笑時嘴角輕輕上揚。
- 下巴到嘴的距離短，人中短。
- 臉頰可以有淡淡的腮紅（粉色，半透明）。

**男性**（海斗）：下巴稍寬、一樣是平順弧線；眼睛較細長、眉毛較粗直。
**老人**（老焰）：同樣的臉型基礎，加法令紋、眼下紋、較長的鬍子和濃眉；眼睛較小、眼皮下垂。

## 要做的事
1. 調整 `AnimeFace` 的截面表，讓正面輪廓變成上面說的鵝蛋形：顴骨最寬、往下平順收到略圓的下巴。目前 `p.Story` 角色在 y < −0.03 時用冪函數硬收下巴，容易變成尖下巴，請改掉。
2. 依上面的比例重新擺放眼睛、眉毛、鼻、嘴（含大小、間距、高度），所有人類角色都套用；男性、老人用各自的參數變化。
3. 2D 頭像（`Portraits.cs`）的臉型與五官比例同步修改。
4. 每個角色（艾琳、澪、凪、翠、海斗、老焰、玩家角色、城鎮居民）都要對照定裝圖或截圖確認，正面與斜 45° 都不能穿模（眼睛不能浮出臉外、嘴不能陷進去）。
5. 盡量不要增加每幀的運算；網格、材質維持快取。

## 不要改
- 戰鬥判定、技能、數值、連線訊息。
- 身體比例、服裝、髮型（除非髮型因為新臉型穿模，才做最小幅度的調整）。

## Codex 說明（2026-10-24，含後續補充修正）

基底為 `99847c3`。已先看 Erin／Mio／Nagi／Cui／Haido／Laoyan 六張定裝圖及 `v0_s05`、`v3_s04` 等影片幀。依後續使用者補充，**女性以「尖端＋向外圓弧」的動畫瓜子臉取代單純圓下巴**；提高膚色明度、放大眼睛、降低可見額頭，並將髮型改為較多、較細的收尖髮束。完整 [41 組檢查](Docs/face_check/README.md)、[六人與定裝圖對照](Docs/face_check/reference_comparison.png)。所有圖檔只供 Docs 檢查，遊戲仍全程式生成。

### 臉型、五官與膚色

- 可見頭模的 `Section` 不再使用 Story 冪函數尖顎。女性下顎改由共同貝茲剖面取樣：起點 `(半寬 .103, y −.030)`、控制點 `(.103, −.082)`／`(.060, −.143)`、終點 `(.005, −.157)`；再用單調三次插值密化。下巴兩側向外鼓出，不能用兩條直線拼 V 字。男性／老人使用較寬的圓顎模板。
- 女性最下方截面的前後深度也收窄；側邊截面隨弧線向前收攏，避免正面尖、45° 卻變成厚而平的下巴底。下巴、頭頂高度仍是 `±.157 × Length`，未改身體骨架比例。
- 髮際線比例基準仍為 `.123 × Length`。顴骨半寬約 `.103`，Width 差異收在 `.984～1.012` 倍，並在建立後僅對臉部群組抵消原頭部非等向縮放。實際寬／高仍落在約 `.72～.75`。
- 共用 `FacePlan`：眼中心由 `.465` 上移至 `.480`，鼻底 `.30`、嘴 `.17` 保持。眼寬從臉寬 `.25` 放大至 `.285`，眼中心間距為臉寬 `.52`，女性眼高另提高；男性較細長，老人較小且垂眼。保留每人的眼型、虹膜色、雙高光與視線個性。眉線至少高於眼中心 `.07`，並保留放大上眼線以上的間隙，避免眉眼黏在一起。嘴寬仍為眼寬 `.60`。
- 鼻尖／鼻梁保持小幅凸起 `.006／.0015`，鼻底只留 `.0008` 暖色短筆；唇部體積 `.0012`。張嘴片與牙齒沿嘴周斜面，施法、受擊、倒地表情仍在。
- `SkinFor()` 統一臉、裸露身體與 2D 頭像的皮膚色：艾琳 `#f7d8cc`、凪 `#f7d8ca`、翠 `#f3ddcf`、海斗 `#f1cebb`、老焰 `#edc6aa`；一般職業 `#f4d2bf`，澪保留淡藍 `#cdebf5`。降低原本偏橘／偏深的感覺，同時保留角色間暖冷差異；手臂與臉不會使用兩套膚色。兩處仍有極淡腮紅。
- 老焰保留濃眉、法令紋、眼下紋、垂眼及長鬍鬚，鬍鬚重新貼在嘴下；海斗眉毛粗直、圓顎較寬。翠依參考保留沉靜閉眼，不套用老人的皺紋。

### 髮型、額頭與同步

- `StoryHair`／`AnimeHair` 把原髮束分為兩束：根部單束半寬為原來 50%，深度 80%，末端用單一頂點收尖而非小圓環平封；兩個尖端稍微分開。髮束沿原分線和長短曲線，仍合成一個網格，不為每束新增 Renderer。減少每束的截面／取樣數以控制成本，並保留原髮頂高度。
- 降低瀏海：劇情人物一般尖端從 `.038／.050` 降至 `.014／.024`，老焰保留較高髮際線但由 `.105` 降至 `.090`；一般職業瀏海下移 `.020`、下限 `.013`，推短／後梳也降低可見髮際線。眼線略上移，縮短可見額頭，不靠改身高達成。
- 前髮殼稍向前留出安全間距，避免髮束變細後，45° 從縫隙看見頭皮穿出。帽飾、衣著和原有身份配件不重做。舊定位參考 `FittingVertices／HairSeat` 只供尺寸／原髮根座標使用，沒有 Renderer；可見頭模用新弧線。
- `Portraits` 的人類臉輪廓讀取同一截面；五官、閉眼弧線、膚色和髮型直接共用。居民也使用同一套臉型。臉側記號、煤灰與眼鏡鼻橋讀取新臉面，不保留浮出的球形腮紅。
- 放大眼睛後，半眨眼不能只把原眼片壓扁：建立時快取九段貼面深度、待機／戰鬥兩種眼片，以及相應閉眼線。動畫只切換快取並延續平順 XY 變形；不逐幀建立網格／材質、取樣臉面或重算法線。張嘴／閃白／倒地契約及公開 API 不變。

### 驗證

41 組 × 39 狀態＝1,599 次：五種表情，加上 17 個閉眼進度各在待機／戰鬥的檢查。對可見眼片、眉嘴與牙齒的頂點／三角面中心取樣，對照同一實際三角臉面，最小間距為正；網格與材質快取數在動畫前後一致。詳細數值、髮束／三角形數與膚色見 `Docs/face_check/checks.json`。頭模仍為 2,064 三角形；452 個身體網格的頂點位置及三角索引與基底相同，沒有改戰鬥、技能、數值、語音、連線訊息或存檔。

本機 `UNITY_IOS`／`UNITY_ANDROID` 條件編譯均為 0 錯誤（使用 Unity API 替身）；完整 Unity 手機建置由分支 Actions 執行。Docs 圖為程序網格軟體投影，不是真機截圖；幾何檢查不代替手機 AR 的動態觀察。

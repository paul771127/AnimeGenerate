# Codex 任務：場上 NPC 改成 2D 圖（8 方向，站著、走路、小動作）

## 使用者的要求

> 把 NPC 也都做成這種風格吧，但可以不用戰鬥姿勢（多數 NPC 都只要站著或走路，可以偶爾有點小動作）。

「這種風格」指的是 2D 敵人：月影古堡（`45d6e976`）和第二大關的森林敵人。
- 日式漫畫或動畫風的 JRPG 角色插畫，8 個方向。
- NPC 是自己人或路人，表情正常、溫和就好，不需要兇狠。
- **比例：2.5 頭身**（使用者後來直接跟 Codex 指定，取代原本的「正常頭身」；第一批艾琳 `1a5d39a2` 已照這個畫）。之後每一批都照艾琳的比例。

## Claude 已經做好的部分（遊戲端）

- **顯示元件**：`Runtime/SpriteNpcView.cs`。一片永遠正對鏡頭的圖，依面向選 8 方向之一。
  - 有在移動就播 walk。
  - 站著時播 idle，每 6～12 秒播一次 gesture（小動作），播完回到 idle。
  - 受傷閃紅、倒下淡出由程式做，不用畫。
- **圖放進 Resources 就自動換成 2D**：3 張都在才用，沒交的人物照舊用 3D 模型，所以可以分批交。
- **用到的地方**：
  - 戰場上的人物：副本的劇情人物、護送的同伴、護送事件的旅人（`SoloBattle.DungeonMap.cs` 的 `UpdateNpcRigs`）。
  - 翠蔭迷林大地圖上的居民（`SoloBattle.Explore.cs`）。

## 檔案格式

- **檔名**：`Assets/SpellDuel/Resources/SpriteNpcs/{id}_{idle|walk|gesture}.png`
- **排法**：跟敵人一樣。
  - 橫的 8 格是方向 0～7，直的每一列是第幾張，最上面是第 0 張。
  - 每格 256×256，圖寬 2048。

| 動作 | 張數 | 圖的大小 | 內容 |
|---|---|---|---|
| idle | 4 | 2048×1024 | 自然站姿、呼吸、衣服或頭髮微動（循環） |
| walk | 6 | 2048×1536 | 走路循環（不是跑步），步伐自然 |
| gesture | 4 | 2048×1024 | 一個符合個性的小動作，第 0 張和第 3 張要接近 idle 的姿勢（播完回到 idle 不跳格）。例：點頭、揮手打招呼、整理帽子、看手上的東西、伸懶腰、撥頭髮 |

- **方向**：跟敵人相同。

| 方向 | 角色面向 |
|---|---|
| 0 | 正面 |
| 1 | 右前 |
| 2 | 面向畫面右邊 |
| 3 | 右後 |
| 4 | 背面 |
| 5 | 左後 |
| 6 | 面向畫面左邊 |
| 7 | 左前 |

- **大小與位置**：
  - 一格對應 **2.4m**。腳底在格子底邊往上 6%，水平置中。
  - 成人身高（頭頂到腳底）約佔格子高度的 **70%**（約 1.7m）。小孩、矮個子照比例縮小，高大的照比例放大，但不要碰到格子邊。
  - 飄浮的（森林之靈、殘影）影子位置一樣以格子底邊往上 6% 為地面。
- **透明背景**，邊緣乾淨。
- **`.meta`**：同 2D 敵人。Default、sRGB、alphaIsTransparency、關 mipmap、Clamp、Bilinear、maxTextureSize 2048、壓縮 Normal quality。

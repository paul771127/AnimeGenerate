# A. 新副本「天穹飛毯」

### 一句話
玩家站在一張高速往前飛的魔法飛毯上。前方不斷飛來大型障礙物，要靠左右側步、跳、蹲閃開；同時敵人會搭著飛行載具追上來，跳上飛毯近身打。一邊閃、一邊打，最後在飛行中打倒 Boss。

### 原則：這一關全部都是新設計
敵人、Boss、場景、精魄、掉落物全部重新設計，**不要沿用現有怪物的骨架、模型、配色換皮**，也不要沿用現有場景。

### 共通規則
- Unity 2022.3，Android、iOS 都要編譯通過。
- 照 `DUNGEON_FORMAT.md` 在 `Resources/dungeons.txt` 加一個新的 `[dungeon]` 區塊。
- 預覽圖放在 `Docs/pending_preview/carpet/`。

### 1. 玩法規則（已經定好，設計請照這個走）

**飛毯＝玩家的 AR 場地**
- 開打前校準好的場地，就是飛毯的大小。
- 飛毯畫在玩家腳下的地板上，周圍的景物都是虛擬的。

**「正面」只有一個方向**
- 以開打時玩家面對的方向為「前方」，整場不變。
- 所有障礙物只從前方飛來，Boss 戰也一樣。
- 敵人可以從前方或兩側上飛毯，但飛來的障礙物只有前方。

**障礙物有 4 種躲法**，每一種在距離很遠時就要看得到，抵達前至少 1.2 秒有清楚的預警：

| 種類 | 躲法 | 預警（飛毯前緣與場地上的標示） |
|---|---|---|
| 低空掃過（貼地的柱子、橫木、浪頭） | ⬆ 跳起來 | 腳踝高度的橘色橫線 |
| 高空掃過（橫樑、樹枝、橫向的光束） | ⬇ 蹲下 | 胸口高度的藍色橫線 |
| 半邊衝撞（巨石、浮島碎塊佔左半或右半） | ↔ 側步到另一半 | 被撞的那半邊地上變紅 |
| 整片＋缺口（整面牆只留一個洞） | 站到缺口的位置 | 整片紅、缺口亮綠 |

**AR 的安全限制**
- 側步的距離不能超過 1 公尺。
- 跳、蹲不能連續太密：同一種動作之間至少隔 1.5 秒。

**敵人搭飛行載具跳上飛毯**
1. 遠方出現載具，飛到飛毯旁邊（前方或兩側），和飛毯並排飛一下。
2. 落點先在飛毯上亮出預警圈，約 1 秒。
3. 敵人跳上來，落地時有塵土和布料的波動。
4. 載具掉頭飛走。
5. 上來之後就用一般小怪的方式戰鬥。

**Boss：空賊飛艇**（已經定好）
- 一直飛在飛毯前方，所有大招都從正面打過來，躲法也是上面 4 種。
- 整場（第一階段開始）都會不時有空賊從飛艇上跳下來，落到飛毯上。
- 近戰職業要有機會打到 Boss：飛艇會週期性壓低到飛毯前緣，停留 3～4 秒。這段時間是近戰的輸出窗口，遠程則隨時都打得到。
- 第二階段：飛艇正面射出大量子彈（彈幕），像每日訓練的「閃避訓練」——
  - 一波子彈從正面一起射來。
  - 有高有低（低的跳、高的蹲），左右散開，前後錯開。
  - 一波接一波，越來越快、越來越多。

### 2. 要 Codex 設計的內容

#### 2-1 關卡流程（提案）
建議 5 個地點，每一站換一種天空景色，難度逐步上升。每一站都要寫：
- 障礙物的密度、種類比例。
- 每一波上來幾隻敵人、搭什麼載具。
- 這一站的時間長度。

建議的路線（可以改）：
1. **起飛・晨曦雲海**：教學性質。只有低空、高空兩種障礙，敵人一次 1～2 隻。
2. **浮島群**：加入半邊衝撞的浮島碎塊，敵人從兩側上來。
3. **峽谷穿越**：峽谷岩壁快速掠過，出現「整片＋缺口」；敵人搭滑翔翼成群上來。
4. **雷雲帶**：閃電先在飛毯前緣預警再劈下來，天色暗，看不清遠方；可以選擇加入夜晚的刺客。
5. **首領：空賊飛艇**。

#### 2-2 場景：要有「高速往前飛」的感覺（最重要）
- **飛毯本體**
  - 有花紋的布、會被風吹動的流蘇和邊角。
  - 速度越快，飄動越大；布面有微微的起伏。
- **四周的景物不斷往後退**，分三層視差：
  - 近景：雲絮、鳥群、碎石、光點，非常快地掠過飛毯兩側和下方。
  - 中景：浮島、岩柱、峽谷壁，中等速度往後。
  - 遠景：山脈、夕陽、雲海地平線，幾乎不動。
- **速度感的輔助**：
  - 風線粒子：從前方往後拉長的白線。
  - 兩側的雲氣流。
  - 飛毯下方往後流過的雲海。
  - 加速時可以有輕微的徑向模糊或風線變密。
- 每一站的天空、光線、景物都要明顯不同。
- **效能**：
  - 景物用物件池循環：從前方生出、往後移出視野就回收，不要一直新建。
  - 中階手機要維持 60fps。
- 提供一個速度參數，例如 `CarpetScene.Speed`，讓戰鬥邏輯可以控制快慢：Boss 俯衝時慢下來，衝刺段加速。

#### 2-3 障礙物美術
- 每一站 3～4 種，造型配合那一站的主題，例如：
  - 雲海：雲鯨的尾巴、飄浮的鐘樓殘骸。
  - 浮島：斷裂的浮島、鎖鏈。
  - 峽谷：岩橋、風蝕石柱。
  - 雷雲：雷柱、黑雲牆。
- 從很遠的地方飛近時，體積要大、輪廓要清楚，一眼看得出是「高的、低的、哪半邊、缺口在哪」。
- 撞到玩家時要有碎裂或衝擊特效；被閃過時從玩家身邊或頭上掠過再消失。

#### 2-4 敵人與飛行載具
建議 4 種小怪、1 種菁英（每一種都要有「搭載具 → 跳上飛毯」的動作）：

| 敵人 | 載具 | 上飛毯的方式 | 戰鬥 |
|---|---|---|---|
| 風箏盜賊 | 大型風箏 | 從側面滑過來，放手跳下 | 近戰、短刀 |
| 雲鷹騎兵 | 巨鷹 | 從前方俯衝，在飛毯上方鬆開 | 近戰、長槍突刺 |
| 滑翔翼兵 | 滑翔翼（成群） | 兩三隻一起滑翔降落 | 遠程、吹箭 |
| 浮游魔偶 | 自己會飄 | 從飛毯下方浮上來 | 坦克、慢 |
| 空賊隊長（菁英） | 小型飛艇 | 飛艇放下繩索，順繩跳下 | 菁英招式 |

- 載具要做「接近 → 並排 → 敵人起跳 → 載具飛走」整段動畫，玩家要看得出來敵人是從哪裡跳上來的。
- 落地前在飛毯上亮落點預警圈。

#### 2-5 Boss：空賊飛艇
- 一艘巨大的空賊飛艇，一直在飛毯前方、船頭對著玩家。
- 甲板上看得到空賊；船身有砲門、側面有放人下來的繩索或跳台。
- **整場都會不時有空賊跳下來**：從甲板跳出，落點先在飛毯上亮預警圈，落地後就是一般小怪。要做跳下來的動作。
- 招式全部從正面來，至少 4 招，分別對應 4 種躲法，例如：
  - 低掃的砲彈列 → 跳。
  - 橫掃的雷光 → 蹲。
  - 左或右半邊的砲擊 → 側步。
  - 一整排砲火只留一個缺口 → 站缺口。
- 每 20～30 秒壓低到飛毯前緣停 3～4 秒，這是近戰的輸出窗口，要有明顯的「靠近了，快打」表現。
- **第二階段（彈幕）**：
  - 船身冒煙，正面所有砲門打開。
  - 一波大量子彈從正面一起射來，像每日訓練的閃避訓練：有高有低、左右散開、前後錯開。
  - 一波接一波，每一波更快、更多。
  - 波與波之間仍然有空賊跳下來，要一邊閃彈幕一邊打。
  - 請設計子彈的樣子：發光砲彈。要做出高的、低的兩種一眼分得出來的外觀，例如低的拖橘色尾巴、高的拖藍色尾巴，和預警線的顏色一致。
  - 請設計砲門開火的動作。
- 倒下時：墜落、爆炸，飛毯從煙霧中穿過去。

#### 2-6 精魄（每一種新敵人、Boss 各一顆，全部新設計）
現有精魄的規則（`Souls.cs`）：
- 每顆只有一種效果，或「好處＋副作用」。
- 分武器、防具、飾品三類，鑲在對應部位的裝備上。
- 小怪約 0.3～1%，菁英約 1%，Boss 0.5%。

請為這一關提案：
- 風箏盜賊、雲鷹騎兵、滑翔翼兵、浮游魔偶、空賊隊長（菁英）、空賊飛艇（Boss）各一顆。
- 每顆寫：名字、效果與數值、鑲在哪一類、掉落率。
- 主題要跟「天空、風、飛行、空賊」有關，例如：
  - 側步後短暫加速。
  - 跳躍中受到的傷害降低。
  - 打倒跳上飛毯的敵人回 MP。
- 現有效果種類在 `SoulOp`；可以提新的效果種類，新效果由 Claude 實作。
- 不要用「普攻集氣加速、閃避率、爆擊率」這三種（使用者不要）。
- 每顆精魄要一個圖示（照現有精魄圖示的畫風）。

#### 2-7 掉落物（全部新設計）
- **新素材 3 種**：例如雲絲、風晶、空賊徽章。寫名字、圖示、哪幾種敵人掉；畫圖示，照 `SkillIcons.Supplies.cs` 的素材圖示畫風。

# B. 寵物系統

使用者要的新系統：玩家用特殊物品當誘餌，引誘對應的怪物、收服成寵物；寵物陪玩家戰鬥，有等級、會放技能；餵飼料有機率學會新技能。

**已經定好的規則**（設計請照這個走）：
1. **收服方式**：
   - 戰鬥中丟出對應那種怪的誘餌，那種怪會被吸引過去吃，約 3 秒，這段時間不攻擊。
   - 吃餌時把牠打到 30% 以下 HP，就會擲收服。血越低、幸運越高越容易成功；失敗就掙脫，誘餌用掉。
2. **一場只帶 1 隻寵物出戰**；寵物可以養很多隻，在角色畫面切換出戰的那隻。
3. **寵物在戰鬥中倒下，這一場就不能再出**，下一場才回來。
4. **可收服的範圍**：
   - 一般小怪（第 1～5 章，0～18 號）和菁英（23～47 號）。
   - 菁英的誘餌很稀有、收服比較難，寵物也比較強。
   - Boss、特殊敵人（19～22）、補師、召喚師、刺客、天候怪、寶箱怪不能收。
5. **寵物有等級**：跟著出戰拿經驗，能力隨等級成長；會自動攻擊、自動放技能。
6. **餵飼料**：每次餵食加經驗，並有機率學會新技能。每隻寵物的技能有上限。

**現有可以沿用的東西**（給你參考，邏輯由 Claude 接）：
- 召喚師的「魔物捕捉」（`Combat.Npc.cs` 的 `Capture`）：會把小怪變成友方單位（`SpawnNpc`＋`tamedKind`），在戰場上自動戰鬥，合作時也會同步給隊友（`localFriend`）。寵物出戰會沿用這套。
- 小怪模型：`MinionRig`；菁英：`MinionRig.Elite.cs`。

**請 Codex 做：**
1. **設計提案** `Docs/PET_SYSTEM_PROPOSAL.md`：
   - **誘餌表**：每種可收服的怪對應哪一種誘餌——名字、取得方式（掉落、商店、調配）、價格或掉落率。菁英的誘餌要稀有。
   - **寵物成長**：等級上限、每級的 HP／攻擊成長、出戰拿多少經驗；菁英寵物比一般寵物強多少。
   - **技能**：
     - 每種寵物一開始會的招式。
     - 可以學的技能池，每種 3～5 招，依種族或屬性分組。
     - 每招寫效果、冷卻、數值建議。
     - 每隻最多學幾招，學滿了怎麼辦（例如可以遺忘）。
   - **飼料**：2～3 種（普通、高級……）——取得方式、加多少經驗、學新技能的機率。
   - **畫面流程**：角色畫面的「🐾 寵物」分頁（寵物列表、等級、技能、餵食、設為出戰），戰鬥中丟誘餌的按鈕與提示。
   - 示意圖放在 `Docs/pending_preview/pets/`。
2. **美術**：
   - 寵物版外觀：沿用那隻怪的模型，加上一眼看出是「我方寵物」的配件，例如項圈、緞帶，腳下有友方光圈。菁英寵物要更顯眼。
   - 吃誘餌的動作；收服成功、失敗的特效。
   - 誘餌、飼料的圖示，照 `SkillIcons.Supplies.cs` 的素材圖示畫風。誘餌可以依章節或種族分組，不一定每種怪一張。
   - 寵物分頁的版面設計。
3. **分工**：寵物的戰鬥邏輯、收服判定、存檔、數值、技能效果由 Claude 照你的提案實作；你不用改戰鬥邏輯。

先交設計提案，確認後再做美術。

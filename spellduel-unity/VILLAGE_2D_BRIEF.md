# 村莊 2D 俯瞰圖＋各建築的介面（給 Codex）

## 使用者的要求
- 把村莊的 2D 介面（現在的「📋 清單」畫面：居民一排卡片、設施一排按鈕）改成**大型 2D 村莊 45 度俯瞰圖**。
- 每個建築上面標明**建築名稱**；**點建築名稱就進入那個建築的功能選單**。
- 每個建築進去後都要有**自己的背景**和**設計過的功能選單**（不是現在的一排按鈕）。
- 例子：鐵匠鋪（詳細規格在下面）。
  - 背景要像鐵匠鋪。
  - 左上寫「要強化的裝備」，下方方框裡是半透明、直排的裝備列表，可以上下拖曳。
  - 選了裝備後，右上角按「強化」。
  - 右下角有鐵匠的表情圖和鐵砧動畫，會敲幾下。
  - 成功時鐵匠變得意的表情，說幾句炫耀技術的話；失敗時尷尬地出現一些解釋的文字。
- **所有建築都要有一些介面設計。**

這張單請做：**美術素材**（俯瞰圖、建築內部背景、人物表情、動畫影格、UI 框）以及**每個建築的版面設計圖**（mockup，標出每個按鈕／列表的位置）。
程式由我這邊接（`Runtime/WorldUI.cs`、`WorldUI.Village.cs`），素材放好、版面圖給了就能接上。

> 注意：新手指引（`SoloBattle.Walkthrough.cs`）會一個按鈕一個按鈕帶玩家按。
> 它是用按鈕上的文字找按鈕的（例如「⚒ 鐵匠鋪」「⚒ 強化（…」「📋 清單」），所以版面圖上**請保留這些按鈕文字**，或在圖上註明新的文字。

## 一、村莊俯瞰圖

### 規格
- **檔案**：`Assets/SpellDuel/Resources/Village2D/map_{town}.png`
  - town＝`flame`（炎之里，**優先做**）、`forest`（森之里）、`harbor`（潮騷港）、`desert`、`snow`（第 4、5 章的城鎮，最後做）。
- **尺寸**：寬 2048 × 高 3072（直式手機）。
  - 地圖可以比螢幕大：程式可以上下左右拖曳、雙指縮放。
  - 所以**請另外附一張 1080×1920 的「整張縮小也看得清楚」版本**：`map_{town}_fit.png`。
- **視角**：45 度俯瞰（等角／斜上方俯視）。
  - 建築是立體的：看得到屋頂和正面。
  - 道路、廣場、樹、小河、裝飾等。
- **畫風**：和故事 2D 背景（`Story2D/bg/village.jpg`，已經通過）一致：日系動畫手繪、溫暖、乾淨。
- **炎之里的特色**（照故事設定）：
  - 山村，晨鐘塔。
  - 鍛爐的煙，灰燼色的石頭路，暖橘色燈籠。
  - 村口往東連到山路。

### 建築與位置（炎之里）
每個建築的屋頂上方都要留一塊空白，給程式畫**名牌**（名稱由程式畫，圖上不要寫字）。

| 建築 | 功能 key | 說明 |
|---|---|---|
| ⚒ 鐵匠鋪 | smith | 強化裝備（小鐵、師父） |
| 🧪 道具店 | shop | 買藥水、賣裝備 |
| 🏛 職業工會 | guild | 轉職試煉、選職業 |
| 🏰 副本入口 | dungeon | 地城（可以組隊） |
| 📅 訓練場 | training | 每日挑戰、再上一次教學、重看導覽 |
| 🔥 討伐告示板 | bounty | 單人挑戰 Boss |
| 👀 觀戰席 | watch | 輸入房間代碼看朋友比賽 |
| 🌀 傳送陣 | warp | 傳送到去過的城鎮 |
| 🚪 村口 | gate | 這一章的故事關卡 |
| 🔔 晨鐘塔 | （裝飾，可以點但只有對話） | 故事地標 |
| 🏠 村長家 | （老焰站的位置） | |

- 居民也畫在地圖上：老焰、小鐵、米菈等，小小的站姿，每人一張透明 PNG。
  - 檔案：`Village2D/npc_{id}.png`，約 160×240，id 同 `Story2D.Cast`。
  - 程式把他們放在建築門口，點了就聊天或接任務。

### 交付物
1. `map_{town}.png`、`map_{town}_fit.png`。
2. `map_{town}.json`：每個建築的位置。
   - 格式：`{ "smith": {"x":..,"y":..,"w":..,"h":..,"label_x":..,"label_y":..}, ... }`
   - 座標以 2048×3072 的像素為準。
   - x, y, w, h 是可以點的範圍；label 是名牌中心。
3. 居民的位置也寫在 json：`"npc": { "laoyan": {"x":..,"y":..}, ... }`。

## 二、建築內部（每個建築一個畫面）

### 共同規格
- **背景**：`Village2D/in_{key}_{town}.jpg`，1080×1920（直式）。
  - 例如 `in_smith_flame.jpg`。
  - 其他城鎮可以先共用炎之里的版本，之後再換。
- **畫面結構**（每個建築都一樣，比較好學）：
  - **上方**：建築名稱、金幣。
  - **中間**：功能區（列表、按鈕）。
  - **右下**：這個建築的 NPC 半身像＋對話泡泡。
  - **下方**：「🏘 回村子」。
  - 列表一律用**半透明直排的方框**，可以上下拖曳（跟鐵匠鋪一樣）。
- **NPC 表情**：沿用 `Story2D/chars/{id}_{表情}.png`（已經有的就不用重畫）。
  - 還沒有的店員、公會長、嚮導、教官、懸賞官、播報員：請照 `STORY_2D_BRIEF.md` 的立繪規格補，表情至少 `normal`、`smile`、`surprised`。

### 1. ⚒ 鐵匠鋪（使用者指定的版面，最優先）
- **背景**：鍛爐火光、牆上掛著工具和武器、地上有煤灰；暖橘色調，右下留給鐵匠和鐵砧。
- **左上**：標題「要強化的裝備」。
- **左側中下**：半透明直排裝備列表（約佔左邊 60% 寬，可以上下拖曳）。
  - 每一列：稀有度顏色的邊框、裝備名、+幾、「👕 穿著中」標記。
  - 選中的那一列會亮起來。
- **右上**：「⚒ 強化（💰 費用・成功率）」大按鈕。
  - 下面是選中裝備的強化前→強化後數值。
- **右下**：鐵匠（小鐵或師父）的半身像＋鐵砧。
  - **鐵砧動畫**：`Village2D/anvil_{0..5}.png`，6 影格，約 512×384，透明背景。
    - 內容：鎚子舉起 → 敲下 → 火花四濺。
    - 程式會播 3 輪（約 1.5 秒），再顯示結果。
  - **火花特效**：`Village2D/spark_{0..3}.png`（可選），程式疊在鐵砧上。
  - **鐵匠表情**：

| 表情 | 用途 |
|---|---|
| `xiaotie_focus` | 敲打中，專心 |
| `xiaotie_proud` | 成功，得意、叉腰、挑眉 |
| `xiaotie_awkward` | 失敗，尷尬、抓頭、冒汗 |

  - 檔案放 `Story2D/chars/`，規格同立繪。
  - 師父也要一套：`smith_focus`、`smith_proud`、`smith_awkward`（壯年男性，圍裙，燒焦的手套）。
- **台詞**：寫進 `Village2D/lines_smith.txt`，每行一句，各寫 8 句以上，程式隨機挑。
  - **成功**：炫耀技術，例如：
    - 「哼哼，看到沒？這火候，全村只有我抓得準！」
    - 「+5 以前算什麼，我閉著眼睛都能敲！」
  - **失敗**：尷尬地解釋，例如：
    - 「呃……這塊鐵今天心情不好。不是我的問題喔！」
    - 「剛剛那一下……風太大了。裝備沒壞，再來一次一定行！」

### 2. 🧪 道具店
- **背景**：木櫃上擺滿藥瓶，暖黃燈。
- **左上**：「買道具／賣裝備」分頁。
- **中間**：直排列表。
  - 買：藥水圖示、名稱、說明、價格按鈕。
  - 賣：裝備列表＋賣價。
- **右下**：店員，表情 `normal`、`smile`（成交）、`surprised`（錢不夠）。
- 台詞：`lines_shop.txt`（成交、錢不夠、賣東西時）。

### 3. 🏛 職業工會
- **背景**：石造大廳，五個職業的旗幟（劍士紅、獵人綠、法師藍、刺客黑紅、牧師金白）。
- **中間**：
  - 轉職試煉的卡片（✔ 已通過／挑戰）。
  - 五個職業的大卡片：職業 2D 頭像、名稱、一句介紹、「選這個」。
  - 頭像用已經在做的 `Story2D/classes/`。
- **右下**：公會長（`normal`、`serious`、`smile`）。

### 4. 🏰 副本入口
- **背景**：山壁上的石門、火把、往下的階梯。
- **中間**：副本卡片的直排列表：名稱、等級、人數、「⚔ 單人進入」、組隊按鈕。
- **右下**：嚮導。

### 5. 📅 訓練場
- **背景**：沙地空地、木頭人、靶子。
- **中間**：
  - 4 種每日挑戰卡片（閃避、輸出、跑步、綜合），附獎牌圖示。
  - 「🎓 再上一次教學」「🧭 重看村子導覽」。
- **右下**：教官。

### 6. 🔥 討伐告示板
- **背景**：木製告示板，貼滿通緝單。
- **中間**：通緝單樣式的 Boss 卡片（Boss 頭像、懸賞金額、「接下懸賞」）。
- **右下**：懸賞官。

### 7. 👀 觀戰席
- **背景**：小看台、旗子。
- **中間**：輸入房間代碼的大框＋數字鍵盤。
- **右下**：播報員。

### 8. 🌀 傳送陣
- **背景**：發光的魔法陣。
- **中間**：去過的城鎮卡片（城鎮小圖、名稱、「🌀 傳送」）。

### 9. 🚪 村口
- **背景**：村口木門、往東的山路。
- **中間**：這一章的關卡卡片（✔／▶／🔒、關卡名、推薦等級、「⚔ 出發」「📖 故事」）。

## 三、UI 框（共用）
放 `Village2D/ui/`：
- `name_plate.png`：建築名牌（木牌或布旗），9-slice，約 384×96，中間留文字空間。
- `list_frame.png`：半透明直排列表的外框，9-slice。
- `list_row.png`、`list_row_sel.png`：列表的一列（平常、選中）。
- `speech_bubble.png`：NPC 對話泡泡，9-slice，尾巴朝右下。
- `btn_big.png`、`btn_big_press.png`：右上角的大按鈕（例如強化）。

## 四、交付順序
1. 炎之里俯瞰圖＋json＋居民小圖。
2. 鐵匠鋪：背景、鐵砧動畫、小鐵／師父表情、台詞、版面圖。
3. 道具店、職業工會。
4. 其他建築。
5. 其他城鎮的俯瞰圖。

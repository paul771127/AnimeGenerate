# SpellDuel（Unity 版）— 共用房間座標的 AR 對戰

網頁版（`spellbattle/`）每支手機各自用 2D 畫面判斷，兩邊看到的法術位置對不上。
這個 Unity 版改成**兩支手機共用同一套房間座標**：

1. **6DoF 追蹤**：ARKit（iPhone）／ARCore（Android）即時知道手機在房間裡的位置與朝向。
2. **共同標記圖**：兩支手機都掃描地上同一張印出來的圖，以它為世界原點 → 座標對齊。
3. **法術用世界座標模擬**：發射時只送「起點、方向、速度、半徑、發射時間」，兩邊用同一公式算位置，所以兩邊看到的一定是同一個點、大小也符合透視。
4. **攻擊方鏡頭輔助定位**：攻擊方的鏡頭偵測畫面中對手的骨架，腳踝射線與地板的交點＝對手站的位置，再和對手手機回報的位置融合；鏡頭看到對手時會鎖定（顯示框和距離）；沒鎖定也能施法，朝準星方向飛。
5. **攻擊方判定命中**：用融合後的世界座標計算，再廣播結果 → 不會一邊中、一邊沒中，也和對手手機轉向哪裡無關。

## 一次性設定

### 1. Unity 授權（免費個人版）
雲端編譯需要你的 Unity 授權檔。Unity 已經不能在雲端直接啟用免費授權，所以要在自己電腦上做一次：

1. 安裝 [Unity Hub](https://unity.com/download)，登入 Unity 帳號。
2. Unity Hub → 偏好設定（Preferences）→ Licenses → Add → **Get a free personal license**。
3. 找到授權檔 `Unity_lic.ulf`：
   - Windows：`C:\ProgramData\Unity\Unity_lic.ulf`
   - macOS：`/Library/Application Support/Unity/Unity_lic.ulf`
4. 到 GitHub → 這個 repo → Settings → Secrets and variables → Actions → New repository secret，新增三個：
   | 名稱 | 內容 |
   |---|---|
   | `UNITY_LICENSE` | `Unity_lic.ulf` 的**完整檔案內容**（用記事本打開全選複製） |
   | `UNITY_EMAIL` | Unity 帳號 email |
   | `UNITY_PASSWORD` | Unity 帳號密碼 |

> 帳號若開啟兩步驟驗證或用 Google/Apple 登入，雲端啟用可能失敗；建議用 email + 密碼登入的帳號。

### 2b. 用 Codemagic 編 iOS（不需要 Unity 授權）
在自己電腦用 Unity 匯出 Xcode 專案（`export_ios.ps1`），推到 `spellduel-ios-xcode` 分支，Codemagic 會自動用那個分支的 `codemagic.yaml` 編成未簽署 IPA。
**每次程式更新後都要重新匯出一次**，否則 Codemagic 編到的是舊版；開始畫面標題下的「版本 時間 · commit」可確認裝到的是哪一版。

### 2. 雲端編譯（GitHub Actions）
設定好 Secrets 後，推送 `spellduel-unity/` 的變更會自動編譯（也可以在 GitHub → Actions → **SpellDuel Unity build** → Run workflow 手動執行）。
第一次約 40～60 分鐘（之後有快取會快很多）。完成後在該次執行頁面最下方的 **Artifacts** 下載：

| Artifact | 用途 |
|---|---|
| `SpellDuel-Android-APK` | Android 安裝檔，傳到手機直接安裝（要允許「安裝未知來源 App」） |
| `SpellDuel-iOS-unsigned-IPA` | iPhone 安裝檔（未簽署），用 Sideloadly 安裝 |
| `SpellDuel-iOS-XcodeProject` | iOS 的 Xcode 專案（之後要上 TestFlight 時用） |

### 3. iPhone 安裝（Sideloadly，免費）
1. 電腦安裝 [Sideloadly](https://sideloadly.io/)（Windows 需先裝 iTunes 與 iCloud 的**官網下載版**）。
2. iPhone 用傳輸線接電腦，信任這台電腦。
3. 把 `SpellDuel-unsigned.ipa` 拖進 Sideloadly，輸入你的 Apple ID，按 Start。
4. iPhone：設定 → 一般 → VPN 與裝置管理 → 信任你的 Apple ID。iOS 16 以上還要開啟 設定 → 隱私權與安全性 → **開發者模式**。
5. 免費 Apple ID 簽的 App **7 天後失效**，到時用 Sideloadly 再裝一次即可。

### 4. 列印標記圖
列印 [`marker/spellduel_marker_A4.pdf`](marker/spellduel_marker_A4.pdf)，**用 100% 實際大小列印**（不要「縮放至頁面大小」）。
印好後量一下圖的寬度應為 **20 公分**（不是的話，對齊的距離會等比例偏差）。
平放在兩人中間的地上，不要反光、不要皺。

## 單人模式：畫遊戲場地（不需要標記圖）

開啟 App 選「**單人練習（畫場地）**」：

1. **找地板**：慢慢移動手機讓鏡頭掃過地板，畫面上方顯示「地板已找到」後，地上會出現白色小圓圈（準星落在地板的位置）。
2. **建立場地**（二選一）：
   - **方形 3／6／10／15m**：一鍵在你前方放一個正方形場地，你站在靠近自己那一側、邊界內 0.5 公尺。
   - 技能射程最遠 15 公尺（狙擊），建議用 **10m 以上**的空地、球場或戶外；電腦獵人會想拉開到約 8m、法師約 6m（場地小時自動縮短）。
   - **手繪場地**：**按住螢幕**，把畫面中央的準星沿著想要的場地邊緣在地板上畫一圈，**放開就完成**（像 Quest 用手把畫邊界）。至少要 1 平方公尺。
3. 地上會出現藍色的場地邊框，**場地中心就是世界原點**。
4. **邊界提醒**：離邊界 1 公尺內會浮出半透明格子牆（越近越明顯）；走出場地時整圈牆都會出現、畫面提示「回到場地內」並每秒震動。
5. **選職業**：我的職業與 3 個技能、敵人職業（或隨機），按「開始戰鬥」。

### 單人對戰

敵人出現在場地內、你面對的那一側，**全部用場地座標（公尺）計算**——你在房間裡看到的就是它的真實位置：

- **敵人會走動**：依職業保持距離（刺客、劍士逼近；法師、獵人拉開），並繞著你左右移動；蓄力中的技能打不到時會走近或退開；永遠留在場地內。
- **敵人會主動攻擊**：照同樣的規則（MP、冷卻、蓄力、射程），血少時補血，看到你的攻擊飛來有機率開格擋／鐵壁／反擊。
- **操作**：點下方技能按鈕開始詠唱 → 蓄力完成後**點畫面**朝那個方向發射（陷阱設在你點的地板，要在 3 公尺內；治療／防禦點畫面任何地方發動）。
- **閃避是真的**：敵人的法術在空間中朝你當下的位置飛，**你實際走開就閃得掉**；慢的（火球、冰槍、隕石）容易閃，快的（箭）和近身的（斬擊、刺殺）幾乎閃不掉——對付刺客要拉開距離。
- 敵人法術逼近時畫面邊框閃紅；**被打中時手機震動、整個畫面閃一下紅色、扣血**（中毒扣血時閃淡紅）；被煙霧彈打中畫面會被遮住。
- **鎖定（和雙人模式相同）**：敵人出現在畫面中會出現綠色「🎯 鎖定」框；**蓄力完成就一定放得出去**（不管有沒有瞄到敵人、距離遠近都不擋），但放出不一定命中，法術一律朝畫面中央準星飛（打不打得到看瞄準），隕石術沒鎖定時落在準星指的地面（最遠到射程）。敵人不在畫面中時會提示「◀ 敵人在左邊／敵人在右邊 ▶」。
- **AR 追蹤中斷時戰鬥暫停**（對著白牆／天花板、太暗、晃太快、遮住鏡頭）：敵人、法術、判定全部停住，畫面顯示原因；追蹤恢復並穩定 0.5 秒後自動繼續。只是把鏡頭轉開、看不到敵人時**不會**暫停，敵人照樣從畫面外攻擊。（雙人模式不暫停，見下方。）
- 技能數值（`Assets/SpellDuel/Runtime/Skills.cs`）從網頁版移植，單位改成真實空間：速度 m/s、判定半徑 m、射程 m。法術最多飛到射程 +1 公尺就消失。

模擬測試（3.5m 場地、各職業敵人各 5 局 × 60 秒）：站著不動時敵人法術幾乎全中；會側移閃躲時，火球 39/39 → 6/33、冰槍 36/36 → 3/34；敵人在所有測試中都沒有走出場地。

> 單人模式只靠 AR 追蹤，不需要列印任何東西。雙人模式仍然用標記圖，因為兩支手機要對齊到同一個原點，各自畫框無法精準對上。

## 語音詠唱與手勢放招

**語音（單人、雙人）**：戰鬥中**直接唸技能名稱**（例如「火球術」「冰槍」）就開始詠唱，不用錄音。
- 用手機內建語音辨識：iOS＝Apple Speech（支援時在手機上辨識），Android＝系統語音辨識（裝有中文離線語音包時可離線，否則需要網路）。
- 比對容錯：簡體字、同音／近音字（火球數→火球術、冰強→冰槍）、句子中間出現（「我要火球術」）都能辨識；兩個技能分不清時不觸發。
- Android 每句話之間會有短暫的提示音，這是系統語音辨識的行為。
- 手機不支援內建辨識時，改用下面的「錄咒語」方式：選技能畫面按「錄「技能名」」，把咒語唸 2 次（任何語言、任何說法都可以）。
- 完全在手機上比對（MFCC＋DTW，比對的是你自己的聲音），不需要網路、不需要 Google／Apple 語音服務。
- 不夠像、兩個咒語分不清、或聲音太小（可能是對手）都不會觸發，畫面上方會顯示原因。點技能按鈕詠唱仍然可以用。

**選技能＝唸技能名稱（單人、雙人）**：每次放技能前都一定要先唸出技能名稱才會開始詠唱（語音固定開啟；手勢不能選招）。沒有系統語音辨識的手機要先在選技能畫面錄好 3 個技能的咒語才能開打。

**手勢（放招）**：把手伸到後鏡頭前（只要拍到手腕和手指）。
  選技能畫面和戰鬥畫面下方的技能格都會畫出手勢圖示；手正比著某個手勢時那一格會亮起來。
- **瞄準一律用畫面中央的準星**（轉動手機對準敵人；蓄力完成時準星用技能顏色脈動）。手勢只負責「觸發」放招；陷阱設在準星指到的地板（太遠就放在同方向的最遠設置距離）。
- **放招動作依職業不同**：
  | 職業 | 放招動作 | 瞄準 |
  |---|---|---|
  | 法師（唸咒語） | 唸完技能名稱開始詠唱，**接著唸出該招的咒語，再把手伸到鏡頭前比 5（五指張開）**就放招（技能名稱和咒語可以一口氣唸完；咒語沒唸完比 5 不會放；比著 5 等蓄滿也會自動放）：**越強的技能咒語越長**，而且要幾乎唸完整才算：風刃「撕裂吧風」、冥想「沉靜吧心靈」、火球術「奔騰吧火焰」、冰槍「凍結吧永恆寒冰」、抗拒法環「退散吧邪惡」、隕石「天上的星辰啊化作烈焰墜落吧」。咒語寫在 `Skills.cs`（`All["fire"].chant = …`）。手機不支援語音辨識時，改回比數字：火球 2、風刃 2、冰槍 3、抗拒法環 4、隕石 5、冥想 3 | 畫面中央準星 |
  | 牧師（比數字） | 唸完技能名稱、蓄滿後**比出該招的數字並維持 0.25 秒**：聖光彈 2、治療術 3、淨化 3、守護 4、祈禱 4、審判 5（2＝食指＋中指、3＝再加無名指、4＝四指伸直拇指收起、5＝五指張開）。比著數字等蓄滿也會自動放 | 畫面中央準星 |
  | 獵人（握拳→比五） | 先握拳，再張開五指（比五）就放箭；所有獵人技能（含陷阱）都一樣 | 畫面中央準星（陷阱設在準星指的地板） |
  | 劍士（揮砍） | 張開的手掌在 0.5 秒內往任何方向移動一小段（畫面短邊的 12%）就出招，不用大幅橫劈（斬擊、劍氣不用蓄力） | 畫面中央準星 |
  | 刺客（突刺） | 手刀快速往前刺（手遠離手機，畫面上 0.35 秒內縮小 25% 以上） | 刺出的位置 |
- **（舊版）法師畫符文**——目前法師改成比數字，以下保留供參考（火球、冰槍、雷擊、風刃、隕石）：詠唱時畫面中央出現符文軌跡（大圓點是起點），伸出食指在空中照著畫；
  畫對＝詠唱完成，接著把**畫面中央的準星**對準目標，**食指往前指（戳一下）**就發射。
  | 技能 | 符文 |
  |---|---|
  | 火球術 | 圓（任意起點、任一方向） |
  | 冰槍 | 三角形 |
  | 雷擊 | 由上往下的閃電折線 |
  | 風刃 | 橫向波浪 |
  | 隕石 | V 字 |
  辨識：單筆畫比對（重新取樣、正規化、點距離＋筆畫方向），且必須是所有符文中最像的；大小、位置不拘。握拳＝提筆、清除軌跡。
- **特定技能有自己的放招動作**（其餘用職業動作）：
  | 技能 | 放招動作 |
  |---|---|
  | 捕獸夾、爆裂陷阱、煙霧彈、雷擊 | 往下壓／往下劈：手 0.4 秒內往下移動畫面高 18% 以上（陷阱設在手的位置指到的地板） |
  | 格擋、鐵壁 | 舉盾：張開手掌停住 0.6 秒 |
  | 反擊 | 握拳 → 張開 |
  | 飛刀 | 揮砍（快速甩出） |
  | 劍士突刺 | 突刺 |
  選技能畫面每個技能都標示「唸名稱 → 放招動作」；詠唱中畫面中央會提示要做的放招動作。
- 準星跟著手：方向＝手腕 → 中指根部，畫面上會畫出手的關鍵點和準星。
- 手部偵測：Android 用 Google MediaPipe Hand Landmarker（模型在 `Assets/StreamingAssets/hand_landmarker.task`），iOS 用 Apple Vision（iOS 14 以上）。點畫面發射仍然可以用。

**刺客的近身技能（刺殺、影襲、毒刃）＝伏擊**：
- 唸技能名稱後，**手掌要伸在鏡頭前**才會蓄力（敵人貼身也能蓄力；蓄滿時敵人已經在身邊就直接出手）。刺殺流派（暗殺術）離開敵人視線累計 1 秒（可以分好幾次，被看見只是暫停）就算蓄力完成。刺客技能樹的「近身本能」（刺殺流派，最高 5 級）：2m 內有敵人時受到的傷害 −4%／級、閃避 +3%／級。
- 蓄滿自動進入「伏擊」狀態 5 秒（不用放招動作）：5 秒內靠近任一敵人 1.5m（直徑 3m）內就自動出手。**伏擊中被打到就取消，要重新蓄力**（冷卻立即重置）。
- 5 秒內走到離敵人小於技能射程 → 自動出手一次（傷害＋效果），技能完成；沒靠近就落空（MP、冷卻照算）。
- 畫面顯示「🗡 伏擊中：靠近到 Xm 內自動出手（目前距離・剩餘秒數）」；被伏擊的一方看到「⚠ 敵人伏擊中！保持距離」。電腦刺客放伏擊後會衝過來；雙人時由刺客方判定。

**隕石與風刃**：
- 隕石：從敵人（施放當下的位置）正上方 6 公尺砸下（約 0.9 秒，可以閃），砸中有直擊傷害；落地留下**直徑 3 公尺、持續 10 秒的火海**，敵人在裡面每秒灼燒 5 點。雙人時火海由施放方判定、雙方都看得到。
- 風刃：隨機從左或右側繞弧線（側向最多約 1 公尺）飛向準星方向。

**技能圖示與法術造型**：每個技能有自己的發光圖示（`docs/skill_icons.png`）；飛行中的法術依技能有不同造型（箭矢、火球、冰錐、雷光、風刃、隕石、匕首、飛刀、暗影球、毒液、煙霧、新月劍氣、劍氣波、槍尖）。

**木頭人練習**：選技能畫面的敵人職業選「木頭人」。木頭人站在 3 公尺外不會動、不會攻擊、打不死，上方顯示命中次數與累計傷害，適合練手勢和瞄準。

**敵我距離**：單人模式顯示在敵人頭上血條下方（詠唱中的技能射程到得了＝綠色「射程內」，太遠＝紅色「超出射程」；超出射程也能放，只是飛不到）；雙人模式顯示在鎖定框旁。

## 雙人模式：畫場地（不需要標記圖）

1. 兩支手機都選「**⚔ 多人（同一個地方・畫場地）**」，慢慢移動手機讓它找到地板。**不用同一個 Wi-Fi、不用打 IP**（用 Unity Relay 房間代碼，要能上網）。
2. 一支按「建立房間」，畫面出現 6 碼房間代碼；另一支輸入代碼按「加入」（或用「📋 複製代碼」／「📋 貼上朋友的代碼並加入」）。房主掃到地板會**自動建好 10m 場地**（對戰場地固定 10m 方形，建在你前方）。
2.5 **📱 並排對齊（最簡單，建議）**：並排對齊完成、場地也有了，**會自動進入選職業畫面**。兩人站在一起，兩支手機並排拿好、鏡頭朝同一個方向（例如都對著同一面牆），**各按一次「📱 並排對齊」**，然後各自走開。不用鏡頭辨識對手（光線、衣服、只拍到手腳都不影響）；對齊後只要對手在畫面裡就能鎖定。開打後，鏡頭看清楚對手（含腳）時會**自動慢慢微調**（每 0.5 秒最多挪 3cm、轉 1°，認錯人時不採用），修正並排時的角度誤差與 AR 漂移。下面第 4 步的「面對面讓鏡頭拍到對方全身」是沒按並排對齊時的備用方法。
3. **其中一人畫場地**（方形 3／6／10／15m 或手繪）。畫的人＝「場地主」，他的座標就是世界座標；場地會自動傳給另一人。
   - 雙方都畫了的話，以房主的為準。場地主之後重畫，只會更新邊界，不會打亂對齊。
4. **對齊**：兩人面對面站、相距 2～5 公尺，讓鏡頭互相拍到對方**全身（含腳）**。
   - 兩支手機都用鏡頭偵測對方站的位置（腳踝射線打到地板），配上對方自己回報的位置，得到成對的點；
     解出兩支手機 AR 座標之間的「水平旋轉＋平移」（地板都是水平的，不需要其他資訊）。
   - 收集到約 8 組、誤差 35 公分以內就完成對齊，畫面顯示「✅ 誤差 xx cm」，場地邊界出現在對齊方的畫面上。
5. **開打後持續互相校正**：戰鬥中只要鏡頭看到對方，就持續加入新樣本、每 0.5 秒重算一次，慢慢修正 AR 累積的偏移（只用最近 45 秒，越新的權重越高；拍到路人等離群點會自動剔除）。
6. 對齊完成前不能施法，對方的身體判定框也不會顯示。

## 用身體閃避

- **蹲下**：手機比站立高度低 32 公分以上＝蹲下，**橫向攻擊（斬擊、劍氣、風刃、三連矢、Boss 橫掃）會從頭上飛過**。蹲太久（約 2 秒以上）基準會慢慢跟著降，就不算了。
- **快速側跨**：0.35 秒內移動 55 公分以上＝側跨。**沒有無敵時間**：要真的移開，讓法術碰不到身體才算閃過（側跨的偵測只用來觸發遊俠的翻滾射擊）。
- **預警**：敵人攻擊蓄力過半時，地上出現從敵人到你的紅線（橫向攻擊是寬的橘線），畫面提示「↓ 蹲下躲！」或「快速側跨閃開！」；隕石、審判、落石下落時地上有落點紅圈。
- 雙人模式也同步蹲下／閃避狀態（攻擊方判定時會算進去）。

## Boss 模式：熔岩巨像

- **單人**：選技能畫面的敵人選「🔥 Boss」。Boss HP 400。
- **雙人合作**：連線後在職業對戰畫面選「🤝 合作打 Boss」（一邊切換，另一邊會跟著切），兩人都準備好就開打。
- **依參與人數加強**（Boss、無盡模式）：每多一位玩家，敵人的血量與攻擊力 +30%（兩人＝×1.3）。
- Boss 約 3.2 公尺高，站在真實地板上，會慢慢逼近；**合作時會在兩人之間換目標**。血量低於一半會**狂暴**（蓄力快 30%、走得更快）。
- 攻擊有近有遠，都有預警（近：地裂重擊、橫掃；遠：熔岩彈、落石雨；離得遠時用熔岩躍擊跳過來）：
  - **熔岩彈**：三顆扇形 → 快速側跨。
  - **橫掃**：胸口高度的橫向衝擊波 → **蹲下**。
  - **地裂重擊**：Boss 周圍出現紅圈 → 在砸下前**走出紅圈**。
  - **落石雨**：四顆巨石落在你周圍，地上有紅圈 → 看紅圈閃開。
  - **熔岩躍擊**（目標在 5.5m 外時）：蓄力 1.4 秒時你腳下出現紅圈，然後 Boss 在 0.6 秒內跳到那裡砸下（半徑 2m、傷害 20）→ 離開紅圈；落地後很快接近身攻擊。
  - **召喚小怪**：在身邊召喚 4 隻「熔岩小鬼」（合作時 5 隻，最多同時 10 隻），場上少於 2 隻時常常召喚。小鬼（HP 40）會追最近的玩家，靠近後舉爪預備 0.7 秒再抓（7 傷害，側跨可閃）；擋在 Boss 前面的小鬼會先吃到你的法術。Boss 倒下時小鬼一起消失。合作時小鬼由主機控制，隊友打到小鬼會送給主機扣血。
- 合作模式由主機跑 Boss：Boss 的位置、血量、蓄力每 0.1 秒同步；隊友打到 Boss → 送主機扣血；Boss 打到隊友 → 主機判定後送給隊友。一人倒下戰鬥繼續，兩人都倒下才算失敗。
- 模擬測試（單人、120 秒）：完全不閃的玩家每秒約受 4.4 傷害；會蹲／側跨／走出紅圈的玩家每秒約 1。

## 獵人蓄力要站穩
獵人所有技能蓄力時（包含蓄滿後拉著弓）都不能離開唸技能的位置直徑 1m，否則蓄力失敗。

## 投射物速度
所有遠距技能（射程 3m 以上的投射物，玩家與敵人都一樣）飛行速度是原本的 70%（`Skills.ProjectileSpeedScale`）；普通攻擊再減半（`Skills.BasicSpeedScale` = 50%）；獵人的普通箭再減半（`Skills.ArrowSpeedScale` = 50%）。算完之後所有飛行中的法術／技能（玩家、敵人、Boss、召喚物）一律不超過 3 m/s（`Skills.MaxProjectileSpeed`）；近身揮砍、伏擊與小怪的衝刺移動不受影響。職業特色（`Skills.ClassSpeeds`）：獵人的箭全部 3 m/s（最快）；法師奧術飛彈、火球 1.4、冰槍 1.8（隨機左右弧線）、風刃與雷擊 2.2、隕石 2.0；牧師的法術約 1.4；劍氣 2.0、突刺 2.5；刺客飛刀 2.5、煙霧彈與火遁 2.0。劍士初始 HP 160。

命中判定（身體＝直立膠囊）：飛行法術是 3D 球對膠囊，劍氣與風刃是新月形（沿新月弧取樣，只有碰到新月本體才算中，風刃跟著弧線切線轉向）；三連矢只有箭碰到才算；蹲下只躲得過 Boss 胸口高度的橫掃；近身普攻、斬擊與伏擊是攻擊者胸口朝前的半球；飛超過技能射程的法術會再飄 0.8m 並縮小淡出，淡出中不會打到人；範圍技能依特效做成 3D 圓柱（神聖制裁 2.2m 高、旋風斬 1m、冰封領域 0.9m、毒霧 1.5m），元素爆裂是球形；陷阱、火海、毒液區、抗拒法環是地面型，對飛在空中／漂浮的怪物（`Battle.OnGround`）無效。

## 遠端連線（不同地方的人，2～6 人）
- 選模式畫面選「🌐 遠端連線（不同地方）」。不用同一個 Wi-Fi、不用輸入 IP：
  1. 慢慢移動手機掃地板，**掃到地板就自動建好 10m 方形場地**（固定 10m，建在你前方；要換位置就面向空地按「↺ 重新放置」）。
  2. 一人按「建立房間」→ 按「📋 複製代碼」，貼到 LINE 傳給朋友。
  3. 朋友複製那段訊息 → 在遠端連線按「📋 貼上朋友的代碼並加入」（也可以自己輸入代碼按「加入」）。
  4. 連上後**自動進入選職業畫面**，大家按準備就開打。
- 其他人以**職業角色**出現在你的場地裡，跟著他本人的走動、閃避移動；可以職業對戰（2 人）或合作打 Boss／無盡（2～6 人）。
- **座位**：**開戰那一刻你面向的方向，就是對手（多人時是圓心）的方向**；不管站在自己房間的哪裡，開戰時都會被放到座位上：兩人相距約 3 公尺面對面，多人時圍成一圈、Boss 在中間。之後在自己房間怎麼走，虛擬角色就怎麼動。開戰前請面向自己場地裡最空的方向。
- 連線走 Unity Relay（Unity 官方中繼）：高頻的位置／狀態走不可靠通道，其他（放招、命中、血量）走可靠通道。程式：`Runtime/RelayLink.cs`（和區域網路的 `NetLink` 共用 `ILink` 介面）。

### 一次性設定（遠端連線用）
1. 到 <https://cloud.unity.com> 用你的 Unity 帳號登入 → 建立一個專案（名稱隨意，例如 SpellDuel）。
2. 在專案裡打開 **Multiplayer → Relay**，按啟用（免費額度足夠自己和朋友玩）。
3. 在專案設定頁複製 **Project ID**（一串 xxxxxxxx-xxxx-… 的 ID）。
4. GitHub repo → Settings → Secrets and variables → Actions → New repository secret：名稱 `UNITY_CLOUD_PROJECT_ID`，值貼上 Project ID。
5. 重新建置（推送或在 Actions 手動執行）。（目前的專案 ID 已經寫在 `BuildScript.cs` 的 `DefaultCloudProjectId`，不設定 Secret 也能用；設定 Secret 會覆蓋它。）沒設定時遊戲照常可以玩，只有遠端連線會顯示「沒有設定 Unity Cloud 專案」。

## 多人合作（2～6 人）
- 一支手機「建立房間」當房主，其他人輸入房主的 IP「加入」，**最多 5 人加入（共 6 人）**，都要在同一個 Wi-Fi（不同地方請用「🌐 遠端連線」）。房間滿了會顯示「房間已滿」。
- 連線方式：星狀，加入的人只連房主，房主轉送訊息（每則訊息帶發送者編號 pid、收件人 to）。
- 多人時只能玩**合作**（🤝 合作 Boss、♾ 無盡合作；故事模式之後再接）；⚔ 對戰仍然只能兩個人。
- 選好模式、職業、技能後每個人按「準備好了」，**全部人都準備好**才開打；選擇畫面會列出每個人的準備狀態。
- 敵人依人數加強：每多一人，Boss 血量與攻擊力 +30%；無盡模式每多一人，每波小怪 +50%、同時在場上限 +4、出現得更快。
- **仇恨值**：Boss 打「仇恨最高」的人。對 Boss 造成的傷害 1:1、治療量（每補 1 HP，自己＋隊友都算，牧師補全隊＝治療量 × 人數）1:1 累積成仇恨；每秒衰減 3%，換一隻 Boss 時清空。分數＝仇恨＋15＋距離加成（越近越高，最多 +25），新目標要比現在的高 20% 才換、Boss 蓄力中不換。畫面上方顯示「🎯 盯上你！」或「🎯 盯著某某」，隊友列表中被盯上的人前面是 🎯。小怪仍然打最近的玩家。
- **劍士「嘲諷」**（握拳→張開放招）：6 秒內受到的傷害 -35%，並把自己的仇恨設成「目前最高的人＋150」，Boss 沒在蓄力就立刻轉向劍士。無盡／故事模式在技能樹右欄最下面（點滿「不屈」後）學會。
- 畫面右上列出每位隊友的血量。
- 場地對齊：房主畫場地，每位加入的人**輪流**面對房主、讓鏡頭拍到房主全身來對齊（同時有好幾個人還沒對齊時，房主看到的人分不出是誰，就只靠加入者那邊的鏡頭）。
- 有人斷線：那位隊友算倒下，其他人繼續；房主斷線則全部結束。

## 雙人職業對戰

連線並對齊座標（畫場地或標記圖）後，按「**⚔ 職業對戰**」：兩人各自選職業、3 個技能、錄咒語，按「準備好了」，雙方都準備好就開打。
- 操作和單人相同：唸技能名稱詠唱，再做該技能的放招動作；對手在鏡頭中被偵測到會鎖定；沒鎖定也能朝準星發射。
- **攻擊方判定**：我的法術／陷阱打到對手（用鏡頭偵測＋對手回報融合的位置）→ 送給對手，由對手自己套用格擋、護盾、反擊（反擊會把法術打回來給你）、中毒、定身等效果並回報血量。
- 對手的法術、陷阱、詠唱光效、格擋護盾都會同步顯示在你的畫面上。
- 追蹤中斷時不暫停：只是暫時不能施法，對手以你最後的位置判定。

## 怎麼測（雙人模式）

1. 兩支手機連上**同一個 Wi-Fi**，打開 SpellDuel，選「**雙人對戰（標記圖）**」。
2. **對齊座標**：蹲低把鏡頭對準地上的標記圖（約 30～80 公分距離），等上方顯示「座標：✅ 已對齊」。標記圖上會出現綠色方塊和箭頭，應該剛好蓋在圖上。
3. **連線**：一支按「建立房間」，上方會顯示它的 IP；另一支在輸入框填這個 IP，按「加入」。
4. 對齊後，兩人站開 2～3 公尺。你應該會看到對手身上套著一個**半透明的藍色膠囊**——這是對手手機回報的位置，應該跟真人重疊。
5. **鎖定對手**：鏡頭偵測到對手時，畫面上會出現黃色（身體）／綠色（腳踝）的骨架點、地上一個綠色圓盤（鏡頭算出的站位），對手身上出現綠色「🎯 鎖定」框；鏡頭沒看到對手也能施法（朝準星方向）。上方會顯示「鏡頭偵測」狀態、站位距離、與對手回報位置的差距。
6. **點螢幕發射**：橘色球從你手機往點擊方向飛。對手畫面會看到紫色球飛來；被打中的一方會震動、閃紅並扣 HP，閃開則顯示「閃過了！」。
7. 單人測試也可以不連線按「假人:開」，標記圖上會站一個橘色假人。
8. **只有一支手機也能測鏡頭定位**：不連線、假人關閉時，鏡頭拍到的真人就是靶（看得到腳才算）。可以請朋友站在不同距離，拿捲尺比對畫面上「站位 x.xx m」的準確度。

**要確認的重點**

| 項目 | 看什麼 |
|---|---|
| 對齊準不準 | 綠色方塊是否貼合標記圖；走動後再回來看是否還貼合 |
| 雙方位置對不對 | 藍色膠囊是否跟對手真人重疊（誤差幾公分～十幾公分屬正常） |
| 法術是否一致 | 兩邊同時錄影：同一顆球在兩邊的位置、命中與否是否一致 |
| 延遲 | 上方「時鐘差／來回」：來回時間一般 20～80ms |

**位置偏掉時**：按「重新對齊」再掃一次標記圖。靠近標記圖（1.5 公尺內）時會自動持續修正。

**被攻擊方把手機轉開時**：不影響判定。判定只用雙方在房間裡的世界座標，攻擊方用鏡頭看到的位置（加上對手回報的位置）計算；對手手機朝向哪裡、甚至 AR 追蹤中斷（對著白牆、鏡頭被擋），都照樣會被打中——攻擊方鏡頭看得到他就用即時位置，看不到時用他最後的正確位置（判定框變灰）；他自己暫時不能施法。

### 鏡頭定位的準確度

腳踝射線打到地板的方法：左右方向很準（角度誤差約 0.5°），前後距離的誤差隨距離變大。手機拿在胸前約 1.4 公尺高的估算：

| 對手距離 | 前後誤差 | 左右誤差 |
|---|---|---|
| 1.5 m | ±4 cm | ±1 cm |
| 2 m | ±6 cm | ±2 cm |
| 3 m | ±10 cm | ±3 cm |
| 4 m | ±15 cm | ±4 cm |
| 5 m | ±21 cm | ±4 cm |

身體判定半徑是 28 公分，4 公尺內都夠用。所以融合時**左右以鏡頭為主**；**前後距離近時多信鏡頭、遠時多信對手回報**。
手機平拿時，對手在約 2.3 公尺內腳會出畫面——這時只用鏡頭的「方向」，距離用對手回報的。畫面裡有別人時，離對手回報位置超過 1 公尺的人不採用。

人體偵測：Android 用 Google ML Kit Pose Detection（Gradle 自動下載），iOS 用 Apple Vision（**需要 iOS 14 以上**；iOS 13 會退回只用對手回報的位置）。都在手機上執行、免費、不需要網路。被打中時震動＋全畫面閃紅＋扣血。

## 已知限制

- 兩支手機必須在同一個 Wi-Fi（區域網路直連）。之後可改用網路配對伺服器。
- 標記圖要平放在地上（身體判定框沿重力方向往下延伸，與標記圖方向無關，但地板高度以手機下方 1.45 公尺估算）。
- AR 追蹤在太暗、白牆、快速晃動時會暫時失效；長時間遊玩可能累積幾公分到十幾公分的偏移，靠近標記圖會自動修正。
- 這個 repo 是公開的，所以 GitHub 的 macOS 編譯免費；若改成私人 repo，iOS 編譯步驟可改用 Codemagic（只編 Xcode 專案，不需要 Unity 授權）。

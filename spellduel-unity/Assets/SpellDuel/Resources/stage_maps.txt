# 故事小關的地圖（SoloBattle.StageMaps.cs；格式同 dungeons.txt）
# 使用者要求：第一大關太長，拆回 1-1～1-4 的小關；每一關都是一張短地圖（像短一點的副本），
# 有 NPC 支線、隱藏彩蛋（3 顆星星＋石碑）、小遊戲試煉、劇情（參考守望傳說的關卡設計）。
#   ・[dungeon stage_關卡] 對應 story.txt 的 [stage 關卡]；style = stage；level 不重要（照故事關卡）。
#   ・wave = 1～3：這一關的第一～最後一波（照 story.txt 的 waves 換算）。最後一個地點＝終點（清完過關）。
#   ・支線：side＝任務名稱、giver＝NPC、giverlook＝外觀（swordsman／archer／priest／mage）、offer、thanks、sidedesc、gold、xp、rarity。
#     支線地點是死路（不擋主線），跟 NPC 說話接任務才開始，沒過可以再接。
#   ・secret／secret2＝石碑（標題｜內容，／換行），藏在地點的角落。
#   ・首領關（1-4、2-6、3-6、4-6、5-6）和特殊玩法（生存、護送、賽跑、潛入）不在這裡。

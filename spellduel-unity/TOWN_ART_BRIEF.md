# 可走動城鎮的美術（給 Codex）

使用者的要求：**城鎮改成可以走動的 3D 地圖；居民（NPC）、城鎮建築與佈景由美術來畫。**
走路、打招呼、對話、碰撞等程式 Claude 已經做好（`Runtime/TownWalk.cs`）。目前畫面是方塊、圓柱的**佔位外觀**，全部集中在 **`Runtime/TownArt.cs`**，請只改這個檔案（必要時可以新增 `TownArt.*.cs` 的 partial／輔助檔）。

## 座標與規則
- 單位公尺；`y = 0` 是地面。所有東西放在傳進來的 `Transform` 底下，用 `localPosition`／`localRotation`。
- 玩家進城站在 **(0, 0)**，面向 **+z**。廣場中心在 **(0, 5)**，半徑約 3.5m。城鎮可走範圍：離廣場中心 13m 內。
- 建築與居民的位置、碰撞半徑由 `TownWalk.Enter()` 決定（見下表）；**外觀不要超出碰撞半徑太多**，不然玩家會走進牆裡。
- 純程式產生（Primitive、程式產生的 Mesh／Texture），**不能用圖檔或外部模型**。風格：日式賽璐珞（見 [`ART_STYLE.md`](ART_STYLE.md)），可以用 `ToonStyle.LitShader()` 得到黑邊＋兩階明暗的材質。
- 手機效能：每座城鎮總共約 300 個 Renderer 以內；能共用材質就共用（`TownArt` 已有材質快取）。
- 不要加 Collider（`TownArt.Prim` 會刪掉 Primitive 的 Collider）。

| 物件 | 城鎮座標（中心） | 碰撞半徑 | 方向 |
|---|---|---|---|
| ⚒ 鐵匠鋪 `smith` | (-7, 8) | 2.1 | 門（建築的 -z）朝廣場 |
| 🧪 道具店 `shop` | (7, 8) | 2.1 | 同上 |
| 🏛 職業工會 `guild` | (0, 13.5) | 2.9 | 同上 |
| 民房 `house` ×2 | (-9.5, 1.5)、(9.5, 1.5) | 2.1 | 同上 |
| 地標 `landmark` | 炎之里、森之里 (-9, 13)；潮騷港 (9, 13) | 1.4 | 同上 |
| 居民 ×3 | (-3.2, 3.6)、(3.4, 4.2)、(-1.2, 8.4) | 0.45 | 程式會讓他們轉頭看玩家 |
| 店員 ×3（鐵匠、店員、公會長） | 各設施門前 3.1m | 0.45 | 面向廣場 |

## 要做的三個函式（`TownArt.cs`）

### 1. `BuildScenery(int town, Transform root)`：地面、遠景與裝飾
- 三座城鎮要一眼分得出來：
  - **炎之里**（town 0）：山村，晨鐘與鍛爐、灰燼，暖色調。
  - **森之里**（town 1）：古樹聚落，葉燈、記名林的木牌，綠色調。
  - **潮騷港**（town 2）：港口，南邊（z < 0）是海、棧橋，舊燈塔，藍色調。
- 包含地面（石板廣場、道路通往三個設施）、外圍的樹／岩石、路燈、遠景（可以參考 `VolcanoScene`／`ForestScene`／`SeaScene` 的圓柱背景做法）、飄浮粒子（火星、落葉、海鳥…）。
- 裝飾不能擋在路上：玩家會在廣場與三條路上走。

### 2. `BuildBuilding(int town, string kind, Transform parent)`：一棟建築
- `kind`：`smith`、`shop`、`guild`、`house`、`landmark`。門在 **-z** 那面。
- 設施要從遠處就認得出來：鐵匠鋪有煙囪、火光、鐵砧；道具店有遮雨棚、藥水架；職業工會有柱子、旗幟、氣派。
- 建築風格隨城鎮改變（熔岩石屋／木屋樹屋／白牆藍頂的港口屋）。
- `landmark`：炎之里＝晨鐘塔，森之里＝古樹（樹王的分枝）＋木牌，潮騷港＝舊燈塔。

### 3. `CreateNpc(string name, Transform parent)`：一個居民
- 腳底在 parent 原點、面向 +z，身高約 1.6～1.8m（小孩約 1.2m）。回傳根物件。
- 名字（`name`）就是 `WorldUI.Towns[].npcs` 的名字（例如「村長・老焰」），`Portraits.Key(name)` 去掉職稱得到「老焰」。
- 外觀要和頭像（`Portraits.cs`）一致：髮型、髮色、服裝、配件。
- 目前借用 `CharacterRig`（職業角色）當居民；可以改成專門的居民模型。若要動作，可以加一個 `MonoBehaviour` 做待機呼吸、揮手等（打招呼時揮手更好）。
- 要畫的 12 人：

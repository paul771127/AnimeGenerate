# SpellDuel 玩法清單（設計備忘）

這款遊戲的特色是用身體玩：
- AR 場地、衝刺。
- 身體動作：蹲、跳、側步閃避。
- 手勢施法、語音詠唱。
- 手機震動、麥克風音量。
- 多人連線。

下面的玩法盡量用到這些特色，之後可以放進故事關卡（`story.txt` 的 `mode =`）、副本地點（`dungeons.txt` 的 `event =`）、任務或活動。

**難度**：
- ★：現有系統改一點就能做。
- ★★：要寫一個新的模組。
- ★★★：要新的系統或美術。

## 已經做好的

| 玩法 | 內容 | 在哪裡用 |
|---|---|---|
| ⚔ 死鬥 | 10m×10m 場地清怪 | 故事 `battle` |
| 🗺 探索 | 小地圖，加上場景互動（符文、圖騰）和陷阱 | 故事 `explore`（2-1、2-5） |
| 🛡 護送 | 同伴跟著走，敵人優先打她，她倒下就失敗 | 故事 `escort`（2-3）；副本 `escort` |
| ⏳ 生存 | 怪越出越多，撐過時間就贏 | 故事 `survive`（2-2）；副本 `survive` |
| 🏁 賽跑 | 跟 3 個對手比賽：岔路、擋路物、泥沼、加速球、互相暈眩 | 故事 `race`（3-1） |
| 🥷 潛入 | 不被巡邏的敵人看見，走到終點 | 故事 `stealth`（3-3） |
| 副本事件 | 守護、狩獵目標、圖騰、符文順序、語音謎題、元素雕像、寶箱怪、崩塌、黑暗 | 副本 `event =` |
| 飛毯 | 站在飛毯上閃障礙：跳、蹲、側步 | 副本天穹航路 |

## 新點子

### A. 跟身體、裝置有關（這款遊戲才玩得到）

| 玩法 | 怎麼玩 | 用到 | 適合 | 難度 |
|---|---|---|---|---|
| 🤫 **噤聲潛行** | 潛入的進階版：麥克風聽得到現實的聲音，太大聲（說話、腳步、碰撞）怪就會被吸引過來。畫面上有音量計 | 麥克風 | 故事、副本的潛入地點 | ★★ |
| 🪞 **鏡像試煉** | NPC 示範一串動作（蹲、跳、左跨、手勢、唸咒），玩家照順序做出來，越後面越長、越快 | 身體動作、手勢、語音 | 轉職試煉、任務、小遊戲 | ★ |
| 🌀 **彈幕閃避** | 不能攻擊，60 秒內躲過 Boss 的彈幕：低的跳、高的蹲、橫掃側步。被打中扣分不扣血，分數決定獎勵 | 身體動作 | 副本中場、每日挑戰 | ★ |
| 🥁 **節奏戰鬥** | 敵人照音樂節拍出招，玩家在拍點上出招有加成、在拍點上閃避會反擊 | 手勢、身體動作 | 角鬥場章節、活動 | ★★ |
| 🍶 **運送易碎品** | 拿著一罐聖水，手機晃太大力（突然轉身、跳）就會灑出來；要穩穩走到終點，路上還有怪 | 手機的陀螺儀 | 任務、護送的變化 | ★★ |
| 🗣 **詠唱接龍** | 語音謎題連發：唸出答案開門，答錯出怪；兩人連線時要輪流唸 | 語音 | 副本解謎地點、圖書館場景 | ★ |
| 🛡 **只能反擊** | Boss 只能用格擋或反擊打傷，一般攻擊無效。看準紅線時機擋下來 | 格擋、反擊 | Boss 試煉、職業任務 | ★ |
| 🎯 **靶場** | 場上冒出各種靶子（有的會跑、有的要繞到背後），限時打越多越好；誤打平民扣分 | 手勢施法、瞄準 | 小遊戲、每日挑戰 | ★ |

### B. 地圖與移動（沿用探索、副本大地圖）

| 玩法 | 怎麼玩 | 適合 | 難度 |
|---|---|---|---|
| 🌋 **崩塌逃脫** | 地圖從後面一格格崩塌（或岩漿往前淹），一路往出口衝，被追上就失敗。路上有擋路的怪和岔路 | 故事、副本的最後一段 | ★ |
| 👻 **鬼抓人** | 一隻打不死的鬼一直追你，點亮地圖上的燈籠可以逼退牠；點亮全部燈籠就贏 | 月影古堡、萬聖節活動 | ★★ |
| 🗝 **鑰匙尋寶** | 地圖上藏著 3 把鑰匙（閃光點），靠近時手機會震動提示；找齊才能開最後的門。可以加限時 | 副本、任務 | ★ |
| 💣 **限時拆彈** | 地圖上有幾顆計時炸彈，跑過去照指示做動作（唸出密語或比手勢）來拆除；炸了就扣血、毀掉一條路 | 故事、副本 | ★★ |
| 🧱 **推箱機關** | 衝刺撞箱子，把箱子推到壓力板上開門。有些門要兩個板子同時壓（連線時要合作） | 副本解謎 | ★★ |
| 🕯 **黑暗探索** | 只有身邊幾公尺看得到，要撿油燈、點火把；怪從暗處撲出來 | 礦坑、古堡 | ★ |
| 🦶 **追蹤狩獵** | 順著地上的足跡、血跡追一隻稀有魔物，追到後牠會逃跑，要在牠回巢前打倒 | 任務、稀有怪 | ★★ |
| 🏃 **追捕盜賊** | 盜賊搶了東西在地圖上逃，用技能把他暈住再追上去（賽跑的反過來） | 故事、任務 | ★ |

### C. 戰鬥的變化（沿用 10m×10m 場地）

| 玩法 | 怎麼玩 | 適合 | 難度 |
|---|---|---|---|
| ⏱ **Boss 連戰** | 連打 3 隻 Boss，中間不回血，只能撿掉落的藥水 | 高難度副本、挑戰塔 | ★ |
| 💎 **玻璃大砲** | 玩家和敵人都一擊就倒，比反應和走位 | 每日挑戰 | ★ |
| 🏰 **據點爭奪** | 場上 3 個據點，佔住越多越久得分越快，敵人也會搶點 | 角鬥場、連線 | ★ |
| 🗼 **塔防** | 唸咒在場邊召喚砲塔（要花 MP），擋住 3 路來的怪，守住大門 | 副本、活動 | ★★ |
| 🐾 **捕獲大賽** | 限時用誘餌、削血收服指定的魔物，抓越多越稀有分數越高 | 寵物系統活動 | ★ |
| 🎰 **鬥場賭局** | 開打前選一張「詛咒卡」（敵人加速、我方不能衝刺…），選越難獎勵倍率越高 | 角鬥場章節 | ★ |
| 🌗 **守夜** | 撐到天亮：場上的燈會慢慢熄滅，要唸咒重新點亮，燈全熄就一直出強怪 | 森林、古堡 | ★★ |
| 🧩 **元素調和** | 敵人有屬性護盾，要用對應的屬性打破，打錯反而回血 | 副本、Boss 機制 | ★ |

### D. 多人連線專用

| 玩法 | 怎麼玩 | 難度 |
|---|---|---|
| 🤝 **分工合作** | 一個人只能防禦（擋 Boss），一個人只能攻擊；或者一個人看得到地圖、一個人看得到敵人，要互相講話溝通 | ★★ |
| 🎯 **對戰賽跑** | 真人玩家一起跑，互相暈對方 | ★★ |
| 👑 **奪旗** | 兩隊各一面旗，搶到對方的旗跑回自己的陣地 | ★★★ |

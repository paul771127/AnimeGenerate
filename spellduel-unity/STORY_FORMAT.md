# SpellDuel 故事模式劇本格式（給 Codex／編劇）

劇本只有一個檔案：`spellduel-unity/Assets/SpellDuel/Resources/story.txt`（UTF-8 純文字）。
遊戲啟動時讀取這個檔案，產生「📖 故事」模式的章節地圖、關卡與對話。改劇情只要改這個檔案，不用改程式。

## 基本規則
- 一行一筆。空行、以 `#` 或 `//` 開頭的行會被忽略（可以寫註解）。
- 區塊用方括號開頭：`[chapter 章節編號] 章節標題`、`[stage 關卡編號] 關卡標題`。
- 關卡底下用 `key = value` 寫設定，再用 `<before>`（開戰前的對話）與 `<after>`（通關後的對話）寫劇情。
- 章節／關卡標題下面、還沒寫 `key =` 或 `<before>` 之前的普通文字，會當成「簡介」顯示在地圖上。

## 關卡設定
| 設定 | 說明 | 範例 |
|---|---|---|
| `theme` | 場景主題：`volcano`（熔岩火山）、`forest`（森林）、`sea`（海上礁石） | `theme = forest` |
| `waves` | 這個主題的第幾波到第幾波（1～10）。波數越後面敵人越強、種類越多；**包含第 10 波＝最後打該主題的 Boss**（熔岩巨像／腐化樹王／深淵海妖）。只打 Boss：`waves = 10` | `waves = 1-3` |
| `xp` | 通關獎勵經驗（另外打怪本身也有經驗） | `xp = 150` |
| `req` | 需要先通關哪一關才會解鎖（不寫＝前一關；`none`＝一開始就開放） | `req = 1-2` |

每一波會出現的敵人由主題決定（例如熔岩：熔岩小鬼、火焰射手…；森林：食人花、毒液噴花…；海上：跳躍魚、俯衝海鳥…），越後面的波次解鎖越多種類。

## 對話
- 一行一句：`說話的人：台詞`（全形或半形冒號都可以）。
- 說話的人後面可以加括號標記，決定名牌顏色：職業 id（`swordsman` `archer` `mage` `assassin` `priest`）或職業名稱（劍士、獵人、法師、刺客、牧師），或 `boss`／`敵人`（紅色）。例：`艾琳（mage）：前面就是熔岩之地。`
- 沒有冒號、或說話的人寫「旁白」＝旁白。
- `{玩家}` 會被換成玩家目前選的職業名稱（例如「劍士」）。
- 每句不要太長（手機直式畫面，建議 60 字以內）；長段落請拆成多行。

## 範例
```
[chapter 1] 第一章　熔岩之地
被火山吞沒的王國邊境，熔岩巨像在地底甦醒。

[stage 1-1] 灼熱的入口
熔岩小鬼出沒的山腳。
theme = volcano
waves = 1-3
xp = 100
<before>
旁白：大地開始震動，岩縫裡冒出橘紅色的光。
艾琳（mage）：{玩家}，小心！那些小鬼是從熔岩裡爬出來的。
<after>
艾琳（mage）：入口清乾淨了，往山頂前進吧。

[stage 1-5] 熔岩巨像
theme = volcano
waves = 10
xp = 400
<before>
熔岩巨像（boss）：渺小的人類，竟敢踏進我的國度！
<after>
旁白：巨像崩塌成一地冷卻的黑石。
```

## 建議的結構
- 3 章（熔岩 → 森林 → 海上），每章 4～6 關，最後一關是該章 Boss（`waves = 10`）。
- 前面的關卡用較少、較前面的波次（例如 `1-2`、`2-4`），後面的關卡用較後面的波次（`6-9`）。
- 玩家可以用任何職業遊玩，劇情請不要假設主角是特定職業（用 `{玩家}` 稱呼）。

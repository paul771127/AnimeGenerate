# Codex 任務：特殊裝備（配方製作）的外型與圖示

使用者要求：「製作出來的裝備外型要夠搶眼或 kuso」。邏輯 Claude 已經做好（`Blueprints.cs`）；這份只要美術。

## 背景
- 15 張配方，只有人形敵人（151～165）會掉，交給鐵匠鋪的工匠學會後才能做。裝備等級固定 Lv50～90。
- 做出來的裝備 `Item.special`＝配方 id（下表），穿上後 `GearLook.Piece.special` 也是這個 id（連線會同步給隊友、觀眾）。
- 目前角色身上只用 `Blueprint.main／accent` 換色，造型還是一般裝備的造型。

## 要做的
1. **3D 外型（最重要）**：在 `CharacterRig.GearArt.cs` 看到 `piece.special` 是下表的 id 時，掛上專屬造型（取代那個部位的一般裝備）。
   - 要一眼看得出來、越 kuso 越好；可以有小動畫（滴油、冒煙、咕咕叫、跑馬燈、駝峰晃動…）。
   - 每件 ≤1500 三角形、共用材質；武器要配合各職業的持法（劍／弓／杖／匕首／盾都能拿；不行的話做一個「抱著」的版本）。
   - 神話（rarity 5）加一點常駐光效。
2. **圖示**（`SkillIcons.Get` 取得）：
   - 配方卷軸：`rcp_bp_xxx`（15 張；卷軸上畫裝備的剪影）。
   - 裝備圖示：`bp_xxx`（背包、製作清單用）。
   - 新材料：`mat_band_crest`（人形團徽）、`mat_storm_gem`（天候結晶）、`mat_night_edge`（夜影刃片）、`mat_aid_sigil`（援護聖印）。
3. **預覽**：`GearPreview` 每件穿在 2～3 個職業身上的截圖，放 `Docs/pending_preview/blueprint_gear/`。

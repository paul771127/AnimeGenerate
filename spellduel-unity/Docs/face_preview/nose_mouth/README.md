# 鼻嘴追加修正預覽

此為前一版存檔；最新結果見 [遊戲模型對照追加](../game_model_round/README.md)。

27 個角色的共用五官裸模，依序正面、3/4、正側面；移除髮型、鬍鬚與帽子遮擋以檢查鼻唇輪廓。眼睛與五官高度沿用已接受版本。每列對應戰鬥角色或城鎮居民實際使用的 AnimeFace 網格。

這是 C# 網格資料的軟體投影，近似人類 shader 的陰影，不是 Unity 或手機截圖。2D 頭像見 [總覽](../../outfit_preview/portraits.png)。

LINE 沒有提供匯出好友名單的功能,請在 LINE 好友列表看著打,或從 Excel / Google 試算表複製貼上。

在 LINE 打開跟某人的聊天室 → 右上角 ≡ → 設定 → 傳送聊天記錄(iPhone 叫「傳送聊天紀錄」)→ 存成 .txt 傳到電腦。 會自動建立聯絡人並把舊對話搬過來,重複匯入同一份不會重複。

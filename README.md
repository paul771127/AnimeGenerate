# HomeChat 家用聊天室

架在**自己家中電腦**的聊天室。對話紀錄全部存在你的電腦,不經過 LINE 或任何雲端。

- 朋友**不用裝 App**:用 LINE 傳一條邀請連結,對方點開按「開始聊天」就能聊
- 在家、在外面(4G/5G、別的 Wi-Fi)都能用,手機和電腦都可以
- 匯入聯絡人名單,也能匯入 **LINE 匯出的聊天紀錄**,把舊對話一起搬過來
- **帳號密碼像 LINE 一樣自動記住**:登入一次就一直保持登入,換手機用帳號密碼登入
- **每台裝置也存一份聊天紀錄**:家裡電腦關機或沒網路時也能看舊訊息,打的訊息會在連上後自動送出
- 😊 表情符號、📷 照片 / 影片、📎 檔案、🎙 語音訊息、🎤 語音輸入(講話變文字)、🔗 網址自動變連結
- ⭐ **自己的貼圖**,還能在手機上**自己做動畫貼圖(GIF)**:畫畫、照片動起來、文字動畫;可以下載、整組分享給朋友
- 📷 **共同相簿**:每段對話可以建好幾本相簿,兩個人一起放照片,整本下載成 zip
- 即時收訊息、已讀、未讀數、通知,主人和朋友都能下載聊天紀錄 .txt
- 只要 Python,不用裝任何套件

## 安裝(點兩下就好)

1. 登入 GitHub 後下載 zip 並解壓縮:
   <https://github.com/paul771127/animegenerate/archive/refs/heads/claude/homechat-self-hosted-chat.zip>
2. 點兩下安裝程式:
   - **Windows**:`install-windows.bat`
     (如果出現「Windows 已保護您的電腦」,按「其他資訊」→「仍要執行」)
   - **Mac**:`install-mac.command`
     (如果說「無法打開」,按右鍵 →「打開」→「打開」)
3. 照畫面問題按 Enter 就好。安裝程式會自動:
   - 沒有 Python 的話自動安裝
   - 安裝並登入 **Tailscale**(讓你在外面、朋友在任何地方都能連;可用 Google 帳號登入)
   - 把 HomeChat 裝到 `使用者資料夾/HomeChat`,建立桌面捷徑,設定**開機自動在背景執行**
   - 詢問要不要讓電腦插電時不要睡眠(睡眠時大家都連不上)
4. 瀏覽器會打開 HomeChat,**設定你的名字、帳號和密碼**(只有在這台電腦上才能設定)
5. 第一次使用 Tailscale 時會再打開一個網頁,按 **Enable** 啟用 Funnel(只要一次)

完成後:

- **電腦**:點桌面的「HomeChat」
- **手機**:在 HomeChat 的「設定」看「在外面用手機開」的網址(像 `https://你的電腦.xxxx.ts.net`),
  用手機打開、用帳號密碼登入,再按「加入主畫面」。**在家在外面都用這個網址**
- 要更新 HomeChat:下載新版,再點一次安裝程式(聊天紀錄會保留)

> HomeChat 在背景執行,沒有視窗。電腦要開著(不能關機或睡眠)朋友才連得到。

## 加好友

**方法 1:邀請朋友(推薦)**

1. 按左上角「＋」→ 輸入朋友的名字 →「產生邀請連結」
2. 按「用 LINE 傳送」,選那位朋友傳出去
3. 朋友點開連結 → **設定自己的帳號和密碼** → 按「開始聊天」,就加入了。你這邊會跳出「○○ 已經加入」

邀請連結**只能用一次、7 天內有效**。朋友加入後連結就失效,就算被轉傳、被別人看到也沒用。
朋友換手機、或把網站「加入主畫面」後,直接打開網站用**自己的帳號密碼登入**就好。
朋友忘記密碼:在聊天室右上角 ⋯ →「邀請連結」→「產生新連結」傳給他,他點開就能設定新密碼。

**方法 2:「加我好友」連結**

⋯ →「加我好友」連結 → 開啟。這條連結可以給很多人(例如貼在 LINE 群組),
朋友點開輸入名字送出申請,你在聊天列表按「接受」才能聊天。不需要時請關掉。

**匯入名單 / LINE 聊天紀錄**

LINE 沒有開放匯出好友名單,所以有兩種做法:

- ⋯ →「匯入聯絡人名單」:一行一個人,可以只寫名字,或 `名字,LINE ID,備註`(從 Excel 複製貼上也可以)
- ⋯ →「匯入 LINE 聊天紀錄」:在 LINE 打開跟某人的聊天室 → 右上角 ≡ → 設定 → **傳送聊天記錄** → 存成 .txt 傳到電腦再選它。
  會自動建立聯絡人並把舊對話搬過來,重複匯入不會重複

匯入的聯絡人還沒加入,要再按「邀請連結」傳給他們。

## 聊天功能

輸入框旁邊的按鈕:

| 按鈕 | 功能 |
|---|---|
| ＋ | 📷 照片 / 影片(手機可以直接拍照)、📎 檔案、🎙 錄語音訊息、🎨 做動畫貼圖 |
| 😊 | 表情符號,會記住你最常用的;只傳 1~3 個表情時會放大顯示。第一個分頁 ⭐ 是你自己的貼圖 |
| 🎤 | 語音輸入:按下去講話,自動變成文字,講完再按一次(手機或瀏覽器支援時才會出現) |

- 電腦上也可以直接 **Ctrl+V 貼上截圖**,或把檔案**拖曳**到聊天室
- 大照片會先在手機上縮小到最長邊 2048 像素再傳,省流量也省家裡電腦的硬碟
- 每個檔案最大 100 MB;點照片可以全螢幕看、下載
- 訊息裡的網址會自動變成連結(在新分頁打開)
- 照片、檔案、語音都存在家裡電腦 `HomeChat/data/files`;刪除聯絡人時一起刪除

### ⭐ 自己的貼圖

- 😊 → ⭐ 分頁 →「＋ 加圖片」:從相簿選圖片當貼圖(GIF 會保留動畫,去背的 PNG 會保留透明背景)
- 點一下貼圖就傳出去,像 LINE 貼圖一樣大大一張、沒有對話框
- 朋友傳來的貼圖點一下 →「加到我的貼圖」;照片放大後也有「加到我的貼圖」
- 「選取」後可以一次選好幾張:
  - **分享給對方**:聊天室出現一張貼圖組卡片,對方按「全部加到我的貼圖」就一次收下
  - **下載**:存到自己的手機 / 電腦(一張是原檔,多張打包成 zip)
  - **刪除**(已經傳出去的不受影響)
- 聊天裡的貼圖點一下也可以「下載」。每人最多 300 張、每張 2 MB 以內
- 你和每位朋友各有自己的貼圖庫,別人看不到你收藏了哪些

### 🎨 做動畫貼圖

＋ →「做動畫貼圖」,或 ⭐ 分頁 →「做動畫」,有三種做法:

| 分頁 | 怎麼做 |
|---|---|
| 🖌 自己畫 | 用手指或滑鼠畫。「＋ 複製這格」做下一格、稍微改一點,連起來就是動畫;「淡影」會淡淡顯示上一格當參考。最多 24 格 |
| 📷 照片動起來 | 選一張照片(去背的人物、寵物最好看),套用 彈跳 / 搖晃 / 旋轉 / 心跳 / 漂浮 / 放大縮小 / 果凍 / 鐘擺,可以裁成圓形 |
| 🔤 文字動畫 | 打字(可以換行),選顏色和效果:波浪 / 彈跳 / 閃爍 / 彩虹 / 打字機 / 放大 / 發抖 |

調整「速度」後,按「存成貼圖」、「存起來並傳送」,或「下載 GIF」存到自己的手機 / 電腦。GIF 是在你的手機 / 電腦上直接產生的,不會傳到任何外部網站。

> 🎤 語音輸入用的是手機 / 瀏覽器內建的語音辨識:iPhone 由 Apple 處理,Chrome 會把聲音送到 Google 辨識。
> 介意的話就不要用這個按鈕;🎙 語音訊息是錄好直接傳到你家電腦,不經過其他公司。

## 📷 共同相簿

每段對話都有自己的相簿,你和對方都能看、都能放照片(像 LINE 聊天室的相簿)。

- 打開:聊天室右上角 ⋯ →「相簿」,或點聊天裡的相簿卡片
- 「＋ 建立相簿」→ 取名字(例如「2026 日本旅行」)
- 加照片:
  - 「從手機 / 電腦加照片」(可以一次選很多張,照片和影片都可以)
  - 「從聊天選照片」:把聊天裡傳過的照片挑進相簿
  - 聊天裡的照片放大後 →「加到相簿」
- 有人加了照片,聊天室會出現「新增了 N 張照片到相簿」的卡片
- 相簿右上角 ⋯ →「下載整本(zip)」存到自己的電腦 / 手機;也可以改名、刪除
- 每個人只能移除自己加的照片;相簿只有建立的人能刪(主人都可以)。
  從相簿移除或刪掉相簿,聊天裡的照片不受影響

## 帳號密碼與登入

- 主人和每位朋友都有自己的帳號密碼。登入後這台裝置會**一直記住**(每次使用都會延長,一年沒用才會登出)
- 瀏覽器會詢問要不要儲存密碼,請按「儲存」。之後:
  - Chrome / Edge / Android:登入失效時會**自動登入**,完全不用輸入
  - iPhone / iPad / Mac Safari:密碼存在 iCloud 鑰匙圈,登入框會自動填入,按一下就好
- 朋友可以在聊天室右上角 ⋯ 改密碼、登出;主人在「設定」改帳號密碼

## 聊天紀錄存在哪裡

| 位置 | 內容 |
|---|---|
| 家裡電腦 `HomeChat/data/homechat.db` | **完整的正本**,所有人的所有對話 |
| 每台登入的手機 / 電腦(瀏覽器的儲存空間) | 這個帳號看過的對話副本。家裡電腦關機時可以看,打的訊息先排隊,連上後自動送出(不會重複) |
| 每台裝置(看過的照片和語音) | 看過一次就留在裝置上,電腦關機時也能看 |
| 下載的 .txt | ⋯ →「下載聊天紀錄」,主人和朋友都可以存一份到自己的電腦或手機(照片和檔案會寫成 `[圖片] 檔名`) |

登出時,那台裝置上的副本會一起刪除。

## 加密與資安

**傳輸過程**

| 連線方式 | 加密 | 誰看得到內容 |
|---|---|---|
| Tailscale 網址 `https://….ts.net`(預設) | ✅ HTTPS,在**你家電腦上**才解密 | 只有你的電腦。Tailscale 的轉送伺服器只看到加密資料 |
| Cloudflare 臨時網址(沒裝 Tailscale 時) | ✅ HTTPS | Cloudflare 會在它的伺服器解密再轉給你,技術上看得到 |
| 同 Wi-Fi 的 `http://192.168…` | ❌ 沒加密 | 同一個 Wi-Fi 的人有機會攔截 |

所以**手機一律用 https 的 Tailscale 網址**,不要用 192.168 那個。

**存在電腦裡的資料**

- 聊天紀錄存在 `HomeChat/data/homechat.db`,資料夾權限只有你自己能讀
- 密碼用 PBKDF2(20 萬次)雜湊;登入憑證只存 SHA-256 雜湊,資料庫外流也不能拿來登入
- 資料庫本身沒有另外加密。如果擔心電腦被偷,請開啟系統的磁碟加密:
  Windows「裝置加密」或 BitLocker、Mac「FileVault」(設定 → 隱私權與安全性)
- 每台裝置上的副本存在瀏覽器裡,跟 LINE 存在手機裡一樣:**手機要設螢幕鎖**。
  手機遺失時,從電腦把那台裝置移除;不想在某台裝置留副本(例如公用電腦),用完記得登出

**為什麼不是端對端加密(E2EE)?** 端對端加密是為了防「伺服器」偷看。HomeChat 的伺服器就是你自己的電腦,
資料本來就只在你和朋友之間,再加一層只會讓匯入、搜尋、換手機變複雜,實際上沒有多保護到什麼。

**防護機制**

- 第一次設定密碼只能在家裡這台電腦上操作,而且**設好密碼之前不會開放外部連線**
- 主人密碼至少 8 個字、朋友至少 6 個字;同一來源 10 分鐘錯 10 次就鎖住(全部來源合計 30 次也鎖)
- 帳號不存在時也花一樣的時間回應,別人沒辦法用回應速度猜出有哪些帳號
- 邀請連結只能用一次、7 天過期;打開連結(包含 LINE 自動抓預覽)不會用掉,要按「開始聊天」
- 朋友只能看到和你的對話,看不到你的聯絡人和別人的訊息
- 「登入的裝置」:可以看到你和每位朋友在哪些裝置登入,不認得的直接移除;一年沒用自動登出
- 「設定」可以改密碼,改完其他裝置全部登出
- 好友申請、訊息、上傳檔案都有頻率限制,防止洗版;家裡電腦硬碟剩不到 500 MB 時停止收檔案
- 照片和檔案只有對話中的兩個人拿得到;HTML、SVG 之類可能夾帶程式的檔案一律只能下載,不會在瀏覽器裡打開
- 貼圖只接受 PNG / GIF / WebP / JPG;自己的貼圖庫只有自己看得到,傳出去時會另外複製一份到那個對話
- 相簿屬於一段對話,只有你和那位朋友看得到;只能放這段對話裡的照片
- 網頁有 CSP、禁止被嵌入其他網站(防點擊劫持)、HSTS 等安全標頭

**你要注意的**

- 主人密碼請設長一點,不要跟其他網站一樣。網址是公開的,任何人都看得到登入頁
- 手機遺失:用電腦登入 → 設定 →「查看裝置」移除那支手機,然後改密碼。
  朋友手機遺失:點開他的聊天室 → ⋯ →「登入的裝置」移除
- 朋友的邀請連結只私訊給本人,不要貼在群組(要給多人請用「加我好友」連結 + 你按接受)

## 進階

手動執行(不用安裝程式):

```bash
python homechat.py --open
```

| 參數 | 預設 | 說明 |
|---|---|---|
| `--open` | | 啟動後打開瀏覽器 |
| `--tunnel` | `auto` | 外部連線:`auto` 有 Tailscale 用 Tailscale,沒有就用 cloudflared;`tailscale`、`cloudflare`、`off` |
| `--public-url` | | 自己有固定網域時填這個,就不會自動開通道 |
| `--port` | 8800 | 埠號 |
| `--db` | `data/homechat.db` | 資料庫位置 |
| `--set-password` | | 忘記密碼時,在終端機重設 |

**忘記密碼**:Windows 在 `使用者資料夾\HomeChat` 開 cmd 執行 `python homechat.py --set-password`;
Mac 在終端機執行 `python3 ~/HomeChat/homechat.py --set-password`。

**不想裝 Tailscale**:裝 cloudflared(Windows:`winget install --id Cloudflare.cloudflared`;Mac:`brew install cloudflared`)
也會自動拿到一個 `https://xxxx.trycloudflare.com` 網址。缺點是每次重開網址都會變,邀請連結要重傳。

**移除**:刪掉 `HomeChat` 資料夾(聊天紀錄在裡面的 `data`,要留的話先備份)、桌面捷徑,以及
Windows 的「啟動」資料夾(Win+R 輸入 `shell:startup`)裡的 HomeChat;Mac 執行
`launchctl unload ~/Library/LaunchAgents/tw.homechat.plist && rm ~/Library/LaunchAgents/tw.homechat.plist`。

**記錄檔**:`HomeChat/data/homechat.log`,出問題時把內容貼給開發者。

**備份**:複製整個 `HomeChat/data` 資料夾。單一對話也可以從 ⋯ →「匯出聊天紀錄 .txt」。

**測試**:`pip install pytest && python -m pytest tests`

# 角色造型精緻化（給 Codex）

**方向（使用者已決定）：維持目前的幾何圖形風格**（球、膠囊、圓柱拼成的 Q 版人偶，賽璐珞著色＋黑邊），
不改成寫實或漫畫比例；只要**加上精緻的配件、物品、裝備細節**，讓角色看起來精緻、有質感。

程式：`Runtime/CharacterRig.cs`。目前的樣子：Actions →「SpellDuel snapshots (character renders)」的 artifact（`all_classes.png` 等；程式在 `Editor/Snapshot.cs`）。

## 這些角色用在哪
- 單人模式的電腦對手。
- **遠端連線**時的隊友／對手（以他的職業角色出現在你的場地）。
- 10 個進階職業目前沿用基本職業的外觀，**請各自加上區別**。

## 要加的細節（舉例，可自由發揮）
- **共通**：衣服的鑲邊與腰帶扣、肩甲／護腕／護膝、靴子的翻邊與鞋扣、小飾品（項鍊、耳飾、腰包）、背後的披風或飄帶；臉上加眉毛與眼睛高光。
- **法師**：法袍上的符文紋路、腰間的魔導書與捲軸、法杖頂端的水晶托架與漂浮的小光點、帽子的星星或月亮徽章。
- **獵人**：箭袋上的羽毛與皮帶扣、護手、腰間小刀、斗篷的葉片裝飾、弓身的纏繩與弓梢裝飾。
- **刺客**：多條交叉皮帶、腿上的飛刀套、腰後的煙霧彈小包、圍巾飄帶、匕首的護手與刀刃光澤。
- **劍士**：肩甲層疊、胸甲紋章、盾牌的鉚釘與紋章、劍的護手與劍穗、腰間的副武器。
- **牧師**：法袍的金色刺繡十字、腰間的聖典與念珠、肩上的披肩、權杖的寶石、更明顯的光環。
- **進階職業**（新增 `CharacterRig.Create(classId, advId)`，advId 可為 null；呼叫端由 Claude 接）：

  | 進階職業 | 建議外觀 |
  |---|---|
  | 聖騎士 | 金白盔甲、紅披風、十字紋章大盾 |
  | 狂戰士 | 紅黑配色、獸皮肩甲、雙手斧 |
  | 神射手 | 單眼瞄準鏡、長披風、更長的弓 |
  | 遊俠 | 綠褐配色、肩上停一隻小鷹、腰間陷阱 |
  | 大魔導士 | 更高的帽子、浮在身邊的魔導書、大水晶法杖 |
  | 召喚師 | 橘色長袍、腰間契約書、身邊漂浮的小元素球 |
  | 忍者 | 灰藍忍裝、面罩、背上的忍刀、手裏劍 |
  | 影舞者 | 紫紅舞衣、飄帶、彎刀 |
  | 主教 | 更華麗的主教冠與披肩、大十字權杖 |
  | 審判者 | 琥珀色盔甲、聖光長槍、天秤徽章 |

## 技術限制
- 仍用 Unity 基本形狀＋程式生成網格（不能匯入模型檔）。
- **不要改動作系統的介面**：`CharacterRig.Create(classId)`、`SetPose`、`MoveSpeed`、`Charge`、`PlayCast`、`PlayHit`、`SetDead`、`SetVisible`、`Guarding` 都要保留；新配件要掛在對應的關節樞紐上，走路、詠唱、出招、被打中、倒地時跟著動。
- 手機效能：每個角色約 8,000 個三角形以內（球體可以用較低的細分）。
- 不要動 `Battle`／`Fighter`／網路相關程式。

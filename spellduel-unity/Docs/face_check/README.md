- 女性下顎以外鼓的貝茲弧線連到小尖端，沒有兩條直線的 V 字；男性／老人較寬。額頭以較低瀏海和上移眼線縮短，眼睛與膚色同步到 3D／居民／頭像。
- 每個原粗髮束拆成兩個細束，單束根部半寬降至原來 50%，末端用單一頂點收尖；髮束仍在同一合批網格。中央穹頂和髮頂隆起為連續曲面，避免整片平頂；2D／3D 使用相同快取變體。眉毛改為可辨識的弧形漸細筆畫，淺髮眉加深、年長白眉有深色邊；男女眼尾分別有三束／兩束上睫毛，閉眼也保留睫毛。頭模 2,064 三角形，眼睛／閉眼線使用建立時快取的貼面姿態，沒有逐幀生成網格或重算法線。
- 與 `99847c3` 的 452 個身體網格相比，頂點位置及三角索引一致。裸露皮膚顏色依補充要求調整；服裝、身體比例、戰鬥、技能、語音與連線訊息未改。帽飾、後加頭部裝備及光環只做貼合新髮頂的定位修正，未改裝備條件；16 個職業的裝備幾何／快取／隱藏替換檢查通過。
- 澪的 3D 欄是共用臉模示例，並非新增居民。六位後續地區居民沿用既有居民模板；原本沒有具名頭像者仍保留原預設剪影。
- 本機 Unity API 替身的 `UNITY_IOS`、`UNITY_ANDROID` 條件編譯均通過；完整平台建置由本分支 Actions 驗證。幾何取樣不代替手機 AR 的動態觀察。

加好友

輸入朋友的名字,會產生一條專屬邀請連結,用 LINE 傳給他。他點開按「開始聊天」就加入了,不用裝 App。

一條可以給很多人的連結(例如貼在 LINE 群組)。朋友點開輸入名字送出申請,你按「接受」後才能聊天。

用 LINE 傳送

不需要時請關掉。換新連結後舊的立刻失效。

LINE 沒有提供匯出好友名單的功能,請看著 LINE 好友列表打,或從 Excel 複製貼上。匯入後再一個一個按「邀請連結」傳給他們。

在 LINE 打開跟某人的聊天室 → 右上角 ≡ → 設定 → 傳送聊天記錄 → 存成 .txt 傳到電腦。 會自動建立聯絡人並把舊對話搬過來,重複匯入同一份不會重複。

邀請連結

用 LINE 私訊傳給本人。對方點開後按「開始聊天」就加入了,不用裝 App。

目前沒有可用的邀請連結(已經用過、過期或取消了)。要讓對方在新手機上登入,請產生一條新的。

這個網址只有在同一個 Wi-Fi 才連得到。要讓朋友從外面連進來,請照 README 安裝 Tailscale,然後重新啟動 HomeChat。
這是 Cloudflare 臨時網址,HomeChat 重開後會變,到時要重傳連結。改用 Tailscale 就會是固定網址(見 README)。

🔗 跟朋友的 HomeChat 互通

朋友也在自己電腦裝了 HomeChat 的話,兩台可以連在一起:你們各自用自己的 HomeChat 聊天, 每則訊息、照片都會在兩邊的電腦各存一份。一邊電腦關機時,訊息會先排隊,開機後自動補送。

請朋友在他的 HomeChat:⋯ →「跟朋友的 HomeChat 互通」→「輸入朋友的互通碼」貼上。
